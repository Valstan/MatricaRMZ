## Базовый рецепт (что нужно почти на каждой сессии)

```powershell
# зависимости в новом worktree — свои (~2 мин, всё из локального store)
corepack pnpm install --frozen-lockfile

# тесты — пакетами по отдельности (`pnpm -r test` на этой машине роняет процесс)
corepack pnpm -F @matricarmz/shared test
corepack pnpm -F @matricarmz/backend-api test
corepack pnpm -F @matricarmz/electron-app test
corepack pnpm -F @matricarmz/android-app test
```

- **Тесты требуют Node-ABI, смоук — Electron-ABI** (`better-sqlite3`): свап делается копированием
  бинаря, **файл сначала сносят** (он — hard link на pnpm-store, запись сквозь ссылку портит store
  для всех воркаутов, M209). Рецепт — [`parts/toolchain.md`](parts/PC79/toolchain.md).
- **Обычный `corepack pnpm install` здесь не проходит** — причины и обход — [`parts/toolchain.md`](parts/PC79/toolchain.md).
- **Пуш:** helper `gh` в конфиге репо (`git config --local credential.helper "gh auth git-credential"`) —
  иначе Git Credential Manager открывает диалог, которого нет, и пуш виснет молча. Проверять
  результат фактом (`git ls-remote --heads origin <branch>`), а не текстом ошибки.

## ⚠️ Локальный гейт прав

Гейт не умеет задавать вопросы и на опасные команды отвечает `HOST_CAPABILITY_UNAVAILABLE`.
Отказ зависит от того, есть ли **явное разрешение владельца в том же ходе** — с разрешением
проходят и запись, и удаление. Проверять: попробовать один дешёвый шаг, а не объявлять блок
непроходимым по памяти. Подробности (что пропускает, что режет, обходы) — [`parts/gates.md`](parts/PC79/gates.md).

## Правила этой машины

- **Рабочая копия одна** — `D:\valstan\REPO\MatricaRMZ`; параллельная линия берёт **свой
  worktree** (`.claude/worktrees/<имя>`), иначе две линии делят ветку и порты.
- **Порты стенда общие.** Свой стенд — именованный (`lane1..3`); имя брать свободным, иначе
  две линии сядут на одну БД (см. [`parts/stand.md`](parts/PC79/stand.md)).
- **Не лезть в чужое:** чужая ветка с незакоммиченной работой не удаляется и не стушится.
- **PowerShell 5.1 калечит аргументы:** режет `|`, снимает кавычки и обратные слэши, `-Encoding utf8`
  пишет BOM, а `Get-Content -Raw` читает файл как ANSI ⇒ кириллица в скриптах бьётся. Рабочие
  формы — в [`parts/gates.md`](parts/PC79/gates.md) и [`parts/toolchain.md`](parts/PC79/toolchain.md).
