## CDP-смоук карточки номенклатуры (2026-08-13)

Драйвер — `.verifier-electron/_nomenclature-tabs-smoke.mjs` (gitignored). Что стоило времени:

- **Список «Номенклатура» — аккордеон по группам, а не таблица.** Сразу после перехода в раздел `document.querySelectorAll('table').length === 0`; таблица появляется только после клика по кнопке группы («Детали443▸», «Подшипники12▸» — свёрнутая оканчивается на `▸`). Драйвер, который ждёт `tbody tr` сразу, крутит поллинг до упора и **выбивает CDP-таймаут внутри одного `Runtime.evaluate`** — со стороны выглядит как зависший смоук без единой строки вывода. Приём: сначала кликнуть группу (`buttons.filter(b => b.textContent.trim().endsWith('▸'))`), подождать ~2 с, потом искать строки.
- **Всегда вешай таймаут на `send()` CDP-драйвера.** Без него промах селектора = вечное ожидание вместо внятной ошибки: `setTimeout(() => rej(new Error('CDP timeout ' + method)), 45000)` в `pending`. Плюс печатать шаг перед каждой фазой — иначе непонятно, где встало.
- **Heredoc `<<'EOF'` съедает экранирование регулярок.** Написанный в bash-heredoc `/^Детали\\s*\\d+/` попадает в файл как есть и в JS означает «литеральный бэкслеш» — совпадений нет, а смоук молча репортит «не найдено». Драйверы писать файловым инструментом, а не heredoc'ом; в спорных местах — `startsWith`, не регулярка.
- **Строку нужного класса брать по колонке «Тип».** Шапка списка — `["Наименование ↑","Артикул","Тип","Группа","Ед.","Дата изменения"]`; вкладка «Деталь» в карточке появляется только у part-класса, поэтому строку выбирать по ячейке типа, а не «первую попавшуюся».

## Office / проверка сгенерированных документов (2026-08-17)

- **На этом компе стоит Word 2007 (COM `Word.Application`, Version 12.0)** — та же версия, что у части операторов завода. Это **инструмент приёмки**, а не помеха: сгенерированный `.docx`/`.xlsx` можно валидировать тем самым потребителем, не открывая окно. Готовый скрипт-обход папки — `try-open.ps1` в скретчпаде сессии; ядро:

  ```powershell
  try { $d = $w.Documents.Open($path, $false, $true); "OK " + $d.Paragraphs.Count; $d.Close(0) }

  $w.Quit()
  ```
  Сообщения об ошибке приходят по-русски и в консоли Git Bash превращаются в кракозябры — в скрипте ставить `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`.

## Запуск разовых TS-скриптов вне репо (2026-08-17)

Скрипты приёмки удобно держать в скретчпаде (общая рабочая копия — memory `avoid-temp-files-in-shared-repo`), но `tsx` из другого каталога не находит зависимости пакета:

- `corepack pnpm exec tsx <script>` **обязательно из каталога пакета** (`cd backend-api`), иначе `Command "tsx" not found`.
- Импорт зависимости пакета из скрипта вне репо резолвится от **файла скрипта**, а не от cwd → `ERR_MODULE_NOT_FOUND` на `import 'docx'`. Рабочий приём — `createRequire` с якорем на package.json пакета:
  ```ts
  import { createRequire } from 'node:module';
  const require = createRequire('D:/GitHubReps/MatricaRMZ/backend-api/package.json');
  const { Document, Packer } = require('docx');
  ```
  Исходники самого проекта при этом грузятся абсолютным `file:///D:/...` -импортом (tsx компилирует TS на лету).
- **Python здесь Windows-нативный:** пути из Git Bash (`/c/Users/...`) он не понимает — передавать Windows-путь (`C:\Users\...`). Правка файлов питоном — только с проверкой перед записью (GOTCHAS **M82**: упавший посреди `write` скрипт обнулил файл).

## Новые репо на этом компе (2026-08-18, урок бутстрапа Matrica4)

## Стенд verifier-electron и прод: грабли 2026-08-19

- **Electron-клиент надо запускать ОТЦЕПЛЁННЫМ процессом.** `corepack pnpm --filter @matricarmz/electron-app dev` из фонового шага инструмента возвращается с кодом 0 и **убивает vite** — Electron остаётся жив, CDP на 9222 слушает, но renderer пустой (`document.body.innerText === ''`, `#root` длиной 0, консоль молчит), и смоук репортит «login form not found». Рабочий запуск:
  ```powershell
  Start-Process cmd.exe -ArgumentList '/c','corepack pnpm --filter @matricarmz/electron-app dev > D:\GitHubReps\MatricaRMZ\.verifier-electron\dev.log 2>&1' -WorkingDirectory 'D:\GitHubReps\MatricaRMZ' -WindowStyle Hidden
  ```
  Признак живого стенда — слушают **оба** порта, 5173 и 9222. Только 9222 = осиротевшее окно, перезапускать.
- **Левое меню — сворачиваемое дерево:** пункты свёрнутой группы в DOM отсутствуют вовсе. Перед поиском `span.v2-menu-btn-label` надо раскрыть группу (кнопка с «▸»).
- **Заголовки групп меню в разметке в обычном регистре** — ПРОПИСНЫМИ их делает `text-transform`. `innerText` отдаёт «ПРОИЗВОДСТВО», `textContent` — «Производство»; поиск по верхнему регистру тихо не находит ничего. Искать `/производство/i`.
- **`curl` на этом компе валится `CRYPT_E_REVOCATION_OFFLINE`** (schannel не может проверить отзыв сертификата) — добавлять `--ssl-no-revoke`. Симптом: `curl: (35) schannel: next InitializeSecurityContext failed`.
- **Прод рвёт SSH при частом переподключении.** Поллинг `until ssh …; do sleep 20; done` через несколько минут получает `Connection reset by peer` / `Connection timed out`; после паузы 1.5–3 мин всё работает. Опрашивать прод **не чаще раза в 60–90 с**, длинные операции гнать `nohup … &` с логом в файл и читать лог отдельным заходом.
- **`pgrep -f <шаблон>` через ssh самоматчится:** удалённая команда сама содержит шаблон, поэтому «процесс запущен» показывается всегда. Проверять `ps -eo pid,etime,cmd | grep "[n]ightlyBackup"` (скобочный трюк) — иначе поллинг «пока работает» не завершается никогда.
