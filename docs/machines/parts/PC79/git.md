- **Проверить, что висит:** `git worktree list` (воркауты), `git branch -vv` (локальные ветки; `[gone]` = upstream удалён), `git branch -r` (что видно от `origin`).

Разово — `git remote prune origin`.

- **⚠️ `git push` зависает молча — Git Credential Manager открывает диалог, которого нет в неинтерактивной сессии (21.11.2026):** `credential.helper = manager`, команда висит минутами без единой строки вывода (не «неверный пароль», не отказ — просто тишина). **Рабочий путь — helper `gh` в конфиге репо:** `git config --local credential.helper "gh auth git-credential"` (токен `gh` из keyring, диалога нет) и дальше обычный `git push` с `$env:GIT_TERMINAL_PROMPT='0'; $env:GCM_INTERACTIVE='never'`. - **⚠️ Папку `m3` (2,4 ГБ, с `node_modules`) не берёт даже корзина (24.11.2026):** `rm -- <путь>` через mavis-trash падает с «The system call level is not correct» (VisualBasic `DeleteDirectory`) — глубина путей в `node_modules` упирается в Windows API. **Рабочий путь:** не тратить попытки — `git worktree prune` убирает регистрацию, а папка остаётся безвредным мусором (в `.gitignore`, `git` из неё ведёт в главный репозиторий — туда не лезть). Снести вручную/сторонним инструментом — отдельная затея, не блокер сессии.
- **Пишущий воркаут держи ВНУТРИ каталога сессии** (например `.claude/worktrees/m3/wt`): гейт разрешает запись через shell только внутри каталога, который рантайм считает своим рабочим ⇒ воркаут уровнем выше записывать нельзя.
- **Лишний пустой воркаут** `.claude/worktrees/m3b` (ветка `chore/pc79-profile-split-2026-11`, работа не велась) — снести `git worktree remove .claude/worktrees/m3b`.
- **⚠️ `gh pr merge --delete-branch` ЛОМАЕТ воркаут на Windows (24.11.2026):** после мержа PR gh пытается удалить локальный воркаут и падает с `failed to delete '…': Filename too long` (путь глубокий: `.claude/worktrees/m3/wt/...`) ⇒ **файл `.git` воркаута уже удалён, а папка осталась** ⇒ `git` из этой папки попадает в **главный** репозиторий (там может быть чужая ветка с незакоммиченной работой!). Рабочий путь: мержить **без** `--delete-branch` (`gh pr merge <n> --squash`), а локальный воркаут и ветку убирать руками (`git worktree remove <путь>` из главного репозитория). Проверка после мержа: `git worktree list` — воркаут должен остаться в списке.
