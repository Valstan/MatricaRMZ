# Completed — done-индекс (Tier-1)

> **Token economy:** одна строка на завершённую **нитку/релиз** — название + итог + релиз/PR. Granular-история (коммиты, row-counts, диагностика) — в `git log` и телах PR, **сюда не дублируется**. Это ledger «не гонять повторно»: грепнул по понятию — увидел, что и когда сделано. `/start` его **не** читает; читается по требованию («это уже сделано?»).
>
> Открытое — в [`PENDING_FOLLOWUPS.md`](PENDING_FOLLOWUPS.md). Грабли — в [`GOTCHAS.md`](GOTCHAS.md). Архив планов — [`plans/_archive/`](plans/_archive/).
>
> _Наполнен при сливе PENDING (PR-2, 2026-06-16): крупнейшие нитки — строками ниже; **полный список закрытых планов** — в [`plans/_archive/`](plans/_archive/), granular — в `git log`/PR. План реорга: [`plans/_archive/memory-reorg-2026-06.md`](plans/_archive/memory-reorg-2026-06.md)._

> **Правило «одна строка» (D-097, фаза 3; форма уточнена 08.11.2026):** запись = одна строка таблицы: **тезис** (что изменилось) + **релиз/PR** + итог **до 240 знаков**, двумя фразами. Простыня диагностики живёт в теле PR и `git log`, сюда не дублируется. Раньше правило было, а форма ему не следовала: строки выросли в абзацы (медиана 1 259 байт), и индекс упёрся в потолок 300 КБ. Теперь форму держит сторож.
>
> **Ротация по возрасту — место свежему.** Записи старше ~90 дней уходят в закрытый архив поколения 3.x ([`_archive/COMPLETED-3x-2026Q3.md`](_archive/COMPLETED-3x-2026Q3.md) — август-сентябрь 2026), живой файл держит последние ~3 месяца. Операция механическая и повторяемая: `node scripts/docs/rotate-completed-index.mjs --cut <дата> --max 240` (сухой прогон — `--dry`); она же сжимает форму строк.
>
> **Живой файл держит только поколение 3.x.** Записи старше (CalVer `v2026.*`, `v1.*`, до 2026-08-15) — в закрытом архиве [`_archive/COMPLETED-2026H1.md`](_archive/COMPLETED-2026H1.md) (только чтение, не пополняется).
