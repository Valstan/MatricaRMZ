## Что не сработало

- **Числа из AI-отчёта дважды приняли за замер.** Первый раз 06.09 («~200 конфликтов за 12 часов»), второй — 08.09 («200 сетевых сбоев за 12 часов» при 28 фактических). Оба раза это была **длина выборки**, поданная в промпт рядом со словами «за окно». Починено в #831, но урок шире инструмента: величину, которую собираются цитировать человеку, надо проверять на вопрос «отвечает ли она ровно на то, чем названа».
- **Автомерж съедает коммит, досланный после вооружения** (ловилось дважды). PR показывает «слит», а второй `git push` молча воссоздаёт ветку с коммитом, которого в `main` нет. Ловится только сверкой по **содержимому** `main` (`git show origin/main:<файл> | grep …`), не по статусу PR. Вооружать автомерж последним действием.
- **Длинный текст с кавычками через `git commit -m` / `gh pr create --body`.** Двойные кавычки рвут строку в Git Bash, и `git add` получает куски текста как пути. Только через файл (`-F`, `--body-file`).
- **Ожидание «процесса нет» вместо «работа закончена».** Условие «процесса нет» истинно и до старта работы — ждать надо появления записи о завершении, а не отсутствия процесса.
- **Вывод «значит, снаружи» из тишины в собственном логе.** Отрицательный результат — не улика, пока не проверен заведомо присутствующий сосед (M103).
- Грабли этой сессии вынесены в [`GOTCHAS.md`](GOTCHAS.md): **M116** (лечение, отменённое соседней функцией), **M117** (гейт считает попытки, а называет строки).
