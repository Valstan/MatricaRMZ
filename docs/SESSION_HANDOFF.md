## Замер P3 (закрыт)

Порядок старта был: ключ → SQLite → миграции → **сверка схемы (2×20 с)** → настройки (8 с) → **`runAutoUpdateFlow` (3×8 с + загрузка)** → и только потом окно. На мёртвой сети это до минуты без единого окна — отсюда «запускается и молчит».

Что изменилось (PR #1381): окно создаётся **до** сетевой проверки обновлений (`applyPendingUpdateIfAny` — локальный — остался до окна); сверка схемы при старте — 1 попытка 4 с (у синка остались прежние 2×20); сверка с настройками не менялась (8 с, один запрос). Трей — всегда, крестик → `hide()`, «Выход» только в меню трея через подтверждение рендерера со сторожем 25 с, `app:close-response` → `app.quit()` (иначе трей не давал приложению умереть). Тихий автозапуск больше не взводит окно этапов. Каждый этап пишется в лог строкой `startup-stage: <мс> -> <этап>`.

Замер стенда (PC79, Electron 43): окно через **4.5 с** от старта, фоновые проверки при этом ещё идут; этапы: база 173 мс, миграции 75 мс, сверка 47 мс (локальный сервер), настройки 2070 мс. Тихий старт — главное окно `IsWindowVisible=false`, окна этапов нет, `tray: created`. `WM_CLOSE` → `window closed to tray`, процесс жив; второй экземпляр возвращает скрытое окно; выход гасит все процессы с `quit-flush: done`.

## Замер P5b-2 (акты и требование в Word, закрыт)

Форма акта берётся у печати (`actHtml`), требование — у `buildEngineRequirementHtml`: второго описания нет. Разбор в `cardExportService.ts` дорос до **целого печатного листа** (билдеры актов возвращают документ со `<style>`, `<title>` и кнопкой «Печать / PDF»): служебные узлы пропускаются, сущности декодируются — иначе в Word уезжал бы текст стилей. Геометрия — данные формы, а не догадка: `<th style="width:34%">` переводятся в DXA (`w:gridCol`), `colspan` держится (`w:gridSpan`), без ширин — автораскладка; `h1` печатается 17 px по центру, классовые подсказки `muted`/`num`/`ctr` дают выравнивание, одиночный пустой `span` остаётся линией для росчерка (билдеры актов объявили это инлайном — печать рисует классами). Двери — в панели актов карточки двигателя («Акт в Word» ×3 и «Требование в Word»); бланки (для руки) не выгружаются. **Снимок версии пишет только печать**: выгрузка проходит мимо `engineActSnapshot`/`requirementSnapshot` — границу держит `RepairChecklistPanel.guard.test.ts` по исходнику (на пустом журнале смоук её не докажет: 0 до = 0 после).
