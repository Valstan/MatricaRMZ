Исправлено: теги переставлены на `95e99b81`, прогоны от старых тегов отменены, а созданный ими релиз `android-v3.102.0` удалён и пересобран. **Правило: перед тегами — `git fetch origin main` и проверка `git show origin/main:VERSION`.**
- **Два реестра синка — не три.** Пропуск любого из трёх (`SERVER_MIRROR_TABLES`, `PG_SYNC_TABLES`, `pullChangesSince`) даёт свою поломку: дубли в журнале / клиент без модуля / строки не доезжают никогда.
- **Сторож не значит «проверено на живом».** Дубли на проде копились два часа, пока миграция `0120` ждала мержа.
- **Применённую миграцию не правят** — `0117`/`0118` уже катили, изменения ушли в `0119`/`0120`.
- **psql на Windows не печатает кириллицу** — читать прод-БД через node `pg`; на самом боксе `psql` в консоли через ssh читается нормально.
- **Локальные тесты electron-app на этой машине роняет ABI `better-sqlite3`** (модуль собран под Electron, vitest идёт под Node) — 36 файлов; в CI модуль ставится под Node, там тесты зелёные. Обход: `cd electron-app && pnpm exec vitest run`.
