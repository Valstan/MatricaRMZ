## Что не сработало / грабли сессии

- **Прод рвёт SSH при частом переподключении** — поллинг раз в 20 с через несколько минут даёт `Connection reset`. Опрашивать не чаще раза в 60–90 с, длинные операции гнать `nohup` с логом.
- **`pgrep -f <шаблон>` через ssh самоматчится** на собственной команде: «процесс запущен» показывается всегда, поллинг не завершается никогда. Скобочный трюк `grep "[n]ightlyBackup"`.
- **Electron-стенд надо запускать отцеплённым процессом** — иначе vite умирает, окно сиротеет с пустым renderer'ом, а смоук репортит «login form not found».
- **Цикл кликов внутри одного `Runtime.evaluate` вешает смоук насмерть** без ошибки и без вывода; keep-alive вкладки подсовывают таблицу чужой вкладки. Всё — в `docs/machines/PC40.md`.
- Прямой push в `main` отбит branch protection (правильно) — closeout-доки пошли через PR.
