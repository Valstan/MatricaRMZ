## Что не сработало

- **Тонкая UI-проверка «поле показывает новое значение» — ложный гейт.** Откатил фикс и прогнал смоук: упали только проверки payload'а, а проверка отображения осталась зелёной. `EntityReferenceField` держит своё отображаемое значение и не сверяется с моделью. Гейтом может быть только чтение `workOrders.get(id)` после сохранения (записано в **M53**).
- **Драйвить карточку BOM жестами на PC40 не удалось** (потрачено ~6 подходов, вывод в `docs/machines/PC40.md`): виртуализированные списки дают 0 строк в DOM при честном «Всего: 7»; `MultiSearchSelect` не открывается синтетическими focus/click (`ComponentSuggestionsHintButton` перехватывает первый фокус — нужен trusted `Input.dispatchMouseEvent`); открытая вкладка карточки убирает из DOM кнопки страницы списка. Итог — смоук переведён на IPC-мост, а рендер чекбокса остался непокрытым (хвост №3).
- **Цикл закрытия вкладок до отрисовки оболочки** давал ложно-зелёное «вкладок 0» (закрывать нечего ≠ закрыто). Порядок: дождаться меню → закрывать вкладки.
