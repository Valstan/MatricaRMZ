## Следующий шаг

**Этап 5 — «Рабочий стол» одним экраном с чатом** (правка владельца 2026-08-19, записана в план, §«Этап 5»):

- singleton-вкладка `desktop`, **открывается первой после входа**; отдельной вкладки чата больше нет — чат живёт в левой зоне (колонка собеседников + лента + композер из этапа 2);
- **две подвижные границы** мышкой: чат ↔ рабочий стол (дефолт ⅓ / ⅔) и внутри чата участники ↔ переписка; проценты — в roaming-настройках;
- корзина с «Очистить корзину» по ПКМ, папки с открытием окном на ¾ зоны, перетаскивание ярлыков, удаление ярлыка сначала в корзину;
- **хранение** — ключ `desktop` в `ui_profile_json` через merge-LWW этапа 1; толерантность к неизвестным id, как у пинов меню (id-чурн релизов не должен стирать чужой рабочий стол).

Хвосты этапа 4 (можно попутно): запись правок для остальных типов карточек (сейчас развёрнуто у двигателя и заявки снабжения); `ui.report_build` с санитизированной картой фильтров — он же сырьё для этапа 7.

## Контекст

- Решения владельца: «Рабочий стол» = стартовый экран после входа **и** один экран с чатом; отчёты по двигателям объединить + убрать мёртвый `engine_movements`; журнал — выдаваемое право.
- **`audit.view` Сапегину Николаю выдать через админку** — право уже на проде, но с ролью `admin` не приезжает (по просьбе владельца — поимённо). Записано в `PENDING_FOLLOWUPS` §Операционные раскаты.
- ИИваныч жив на проде через DeepSeek, function calling развёрнут — этапы 6–7 реализуемы без новой инфраструктуры.
- EAV-freeze действует; расширение `ui_profile_json` — не новая EAV-сущность.
- Релиз v3.6.0 миграций не вёз: на проде только пересборка серверных пакетов + подмена артефактов + рестарт.
