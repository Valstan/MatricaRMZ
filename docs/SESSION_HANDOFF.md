## Что не сработало

- Gitleaks-гейт не чинится «удаляющим» коммитом: экшен сканирует диапазон коммитов ветки, находка в середине держит красный. Лечится только схлопыванием (`reset --soft` + force-push). Записано как GOTCHAS **M154** — не повторять fix-forward.
- Условный JS внутри `ensureClientSchemaParity` (`electron-app/.../migrate.ts`, `android-app/src/db/migrate.ts`) нельзя вставлять в середину гигантского `sqlite.exec(`…`)`-литерала: бэктики рвут строку, esbuild падает `Expected ")"`. Правило: чистый SQL — внутрь литерала, условный JS (ADD COLUMN под PRAGMA, DROP INDEX через sqlite_master, пересборки) — отдельными `sqlite.exec` ПОСЛЕ закрытия литерала. Та же ловушка в обоих файлах-зеркалах.
- `is_duty: z.boolean()` (required) в zod-ряде ронял бы из pull строки журнала, записанные до фазы 2: обязательные поля контракта обязаны быть мягко-опциональными, отсутствие читается дефолтом. Доктрина «мягкие намеренно» в шапке `dto.ts`.
- Тест-квиз «пустые строки, сбой создания и сбой проводки» падал на CI: мок-состояние `createdDoc` протекало между сценариями одного `it` — перед третьим сценарием нужен сброс `createdDoc = { ok: true, id: DOC }` (фейл CI run 38743411835, починен `13b2c6a3`).
- Новый ключ `totals` отчёта без строки в `REPORT_TOTAL_LABELS` (`shared/src/domain/humanLabels.ts`) — красный тест-сторож CI «каждый ключ строки „Итого“ имеет подпись»; локально vitest не гоняется, ловится только на CI (PR-5: `deficitQty`, `covered`, `coveragePct`, `annualQty`, `annualAmountRub` — дописаны `31946af5`).
