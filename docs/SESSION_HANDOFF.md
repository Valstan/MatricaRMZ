## Что не сработало

- «Прод-путь лежит» → не лежал: в команде был перепутан алиас ssh (`matricrmz` вместо `matricarmz` — на букву), а «TCP-22 открыт» относится к чужому sshd (прод слушает нестандартный порт). Проверять алиас через `ssh -G <алиас>`.
- «Кнопка не сохраняет» по проверке на экране → экрану врёт: значение меняется, а в базе пусто. Сверять с сервером (`engines.get`, `checklists.engineGet`), а не с DOM.
- Поле карточки искалось по подписи через `parentElement.querySelector('input')` → попадало в ПЕРВОЕ поле грида, а не в своё (так «Примечание» переписало «Номер двигателя»). Искать поле по значению или по следующему соседу подписи.
- Поле даты в карточке — **не** нативный `datetime-local`, а `UnifiedDateInput` (react-datepicker с `customInput`: разметка `input.matrica-datepicker-input`, значение `dd.MM.yyyy HH:mm`).
- CDP-прогон к списку товаров на стенде не довёл: меню открывается, а пункт «Товары» не находится → живой смоук наряда и простых справочников не сделан (на стенде таких карточек нет), закрыт структурным сторожем.
- `git checkout`/`rm` в PowerShell: путь с кириллицей и `$`-подстановки ломают скрипты — передавать файлы скриптом, не heredoc.
