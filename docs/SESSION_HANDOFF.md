## Что не сработало

- **Писать кириллицу в консоль и читать её оттуда на этой машине нельзя:** `node -e "...console.log(кириллица)"` и `Out-File` дают мусор в выводе (кодовая страница консоли), хотя файл на диске цел. Текст результата — только через `fs.writeFileSync(..., 'utf8')` и чтение файла, а не через stdout.
- **`corepack pnpm -r test` на этой машине даёт случайный красный** (таймауты 5 с в посторонних тестах) — перегруз, а не регресс; гарантированный прогон `--workspace-concurrency=1`.
- **Авто-нарезка симптома для шести недостающих строк индекса дала обрубки** («режим просто не работает у оператора… У нас —…»): для индекса формулировку надо писать руками, механическая обрезка первой фразы читается как мусор.
