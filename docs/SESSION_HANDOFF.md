## Что не сработало

- **Числа из AI-отчёта трижды приняли за замер** (06.09, 08.09, 09.09). Сегодня — «8194 строки из 8258 попыток, ~99% неудач» при 8 фактических строках. Правило прежнее и снова подтвердилось: величину, которую собираются цитировать человеку, проверять вопросом «отвечает ли она ровно на то, чем названа».
- **Лечение счётчика нельзя принимать по первому окну.** Снимки дофиксового формата продолжают врать ещё сутки после выката — и выглядит это как новая беда (M121).
- **Автомерж съедает коммит, досланный после вооружения** (ловилось дважды). Сверять по содержимому `main` (`git show origin/main:<файл> | grep …`), не по статусу PR. Вооружать автомерж последним действием.
- **Длинный текст с кавычками через `git commit -m` / `gh pr create --body`** рвётся в Git Bash. Только через файл (`-F`, `--body-file`).
- **Вывод «значит, снаружи» из тишины в собственном логе.** Отрицательный результат — не улика, пока не проверен заведомо присутствующий сосед (M103). Сегодняшний зеркальный случай: тишина в логе была настоящей уликой — но не там, где искали (писать было некому, а не нечего).
