## Грабли и уроки сессии

- **Правдоподобная причина — не диагноз.** Версия «избирательный антивирусный свип» объясняла
  пропажу задачи идеально и была неверной. Отделилось одним дешёвым опытом: та же команда с
  двумя расписаниями, сравнить коды возврата.
- **Самолечение без канала наружу — это не страховка.** Девять неудач подряд за пять дней не
  увидел никто, потому что они писались в локальный файл.
- **`powershell ... | head -N` печатает пустоту** (обрыв пайпа + буферизация) — дважды принял
  за поломку скрипта. Вывод собирать редиректом в файл.
- **Агентский редактор ломает файлы с BOM.** Правку `.ps1` вносить через PS 5.1 с
  `UTF8Encoding($true)`; и сам патч-скрипт с кириллицей тоже обязан быть с BOM, иначе PS 5.1
  прочитает его как cp1251 (проверено на собственной ошибке — скрипт не распарсился).
- Обратные кавычки в PowerShell экранируют внутри двойных кавычек — текст с ` `` ` в литерале
  ломает парсер. Русские строки безопаснее держать данными (JSON), а скрипт писать ASCII.
