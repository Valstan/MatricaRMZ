## Что не сработало

- **Копия `opencode.db` без `-wal` врёт.** Читал базу движка на проде, чтобы понять, работает ли он, — получил «0 сессий» дважды, хотя WAL писал всё время ответа. Диагностика движка — только по WAL/`stat` или через API, не по копии файла (M165).
- **Судить об успехе по журналу прода нельзя.** `logInfo` в проде не пишется вовсе (только warn/error) — «нет строки answered» ничего не доказывает. Поэтому источник ответа и сделан полем в строке, а не логом (M165 → `answer_source`).
- **Потолок движка, взятый по первому удачному замеру, срезает ответы.** 48–80 с в первый день и 160 с на следующий — при лимите 150 с. Частичного текста session-API не отдаёт: обрыв = потеря работы движка (M166).
