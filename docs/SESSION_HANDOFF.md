## Что не сработало

- **Мой смоук складского документа был зелёным вхолостую.** Слал `docType: 'receipt'` (такого типа нет, правильный `stock_receipt`) без обязательного `docNo` — на настоящем сервере 400. Проходил только потому, что фейк-сервер в харнессе отвечает `ok` на любой URL, а `MatricaApi` этот участок не описывал. Вскрылось лишь когда тип догнали до реального preload (#465). Урок — в письме brain'у; правило: **тест доказывает ровно столько, сколько описывает контракт, на который он опирается**.
- **Код возврата через пайп врёт.** `sdkmanager … | grep … | tail; echo $?` печатает код `tail` — провалившаяся установка SDK выглядела успешной (EXIT=0 при пустом каталоге). Читать `$?` сразу после самой команды.
- **`sdkmanager --licenses` не принимает согласие из `.bat` с редиректом** (`(for /l …) | call … > nul` молча оставляет лицензии непринятыми, а установка потом падает «license is not accepted» с exit 0). Работает `yes | sdkmanager.bat --licenses` из Git Bash.
- **`cmd /c` из Git Bash** съедает `/c` как путь и открывает интерактивный cmd. Нужен `cmd //c` или `powershell -Command "& 'X.bat'"`.
- **Первые версии Ф3-теста писались от представления, а не от контракта** — трижды падали, и каждый раз прав был код: `createWorkOrder` отдаёт только `{id}` (deferred create), `recalcPayload` схлопывает «чужую» форму строки и сбрасывает `partName` без `partId`, `listWorkOrders` возвращает `{ok, rows}`, а не массив. Валидатор нарядов отбил строку услуги без `serviceId` — это превратилось в отдельную проверку (доменные правила живут на android-фасаде).
