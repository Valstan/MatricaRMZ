## Открытое по этой нитке

- **Двигатели, у которых в шапке акта уже лежит обрезанный номер, сами не починятся.** Правка чинит механику на будущее: подстановка возвращается в ПУСТОЕ поле и догоняет карточку, но непустое значение, отличное от карточки, неприкосновенно — иначе она затирала бы то, что оператор вписал руками. Печать при этом не врёт: печатная форма берёт номер из карточки двигателя, а из шапки — только если в карточке пусто. Решение владельца: оставить как есть (правится руками по одному) или добавить разовый проход по базе.

## Что не сработало

- **Колонку реплики нельзя везти drizzle-файлом** (13.09, E3): `ALTER TABLE … ADD COLUMN` в `electron-app/drizzle/*.sql` уронил клиент стенда в цикл self-heal (журнал гоняется на всех базах, `ADD COLUMN` неидемпотентен, без breakpoint падает и на свежей). Только PRAGMA-обёртки `clientSchemaMigrations` + `ensureClientSchemaParity`. GOTCHAS **M127**.
- **`erp_nomenclature` — в замороженном снимке схемы для клиентов <3.5.0** (6 машин за 30 дней): новая колонка двигала бы им хеш и перестраивала базы. Спрятана через `LEGACY_HIDDEN_COLUMNS` + сторож. Прецедент 0094 (`room_id`) хеш уже двигал — учитывать при любой колонке легаси-таблицы.
- **Сущность, созданная мостом на стенде, живёт в реплике до `sync.run()`** — сервер отверг связку BOM на новую марку (FK), карточка показала «сохранено» ложно-зелёным по DOM. В смоуках после засева — `sync.run()` и пауза; синтетический `focus` React не слышит — `el.focus()`.
- **Секрет в CI — не бэкап, и проверить его можно только работой** (13.09). «Ключ потерян» было неверным диагнозом: он жил в секрете и продолжал бы подписывать. Потеряна была возможность его прочитать. Отсюда же гейт `android-signing-check.yml` — до него «валиден ли ключ» выяснялось только релизным тегом.
- **`openssl rand` в Git Bash пишет CRLF, `tr -d '\n'` снимает только LF, а `gh secret set` хвостовой `\r` срезает.** Хранилище создано паролем из 33 символов, в CI уехали 32: локально открывается, в CI «keystore password was incorrect». Значение для секрета не должно иметь пробельных символов по краям. Записано в `machines/PC79.md`.
- **`keytool | grep` в гейте съел сообщение об ошибке** — шаг краснел с пустым логом. Фильтровать вывод только после того, как он сохранён целиком.
- **Мостовой `auth.login` в CDP-смоуке не переводит рендерер с формы входа**: сессия есть, `auth.status()` отвечает `superadmin`, а на экране логин — драйвер рапортует «пункт меню не найден». Записано в `verifier-electron/SKILL.md` §«грабли 2026-09-13».
