- **#1955 (слит)** — **поиск по пользователям в веб-админке**: все места выбора

- **#1960 (слит)** — **вкладка «Доступ» — один источник правды**: роль в зеркале доступов
  больше не берётся из замороженного EAV-атрибута `system_role` (после cutover 0103 там
  у администратора было «Наблюдатель») — она из `permissions-view` (строгая `users`);
  состояние учётной записи стало честным (`loading` / `account` / `none` / `error`):
  при неизвестном состоянии форма «Создать учётную запись» **не** предлагается (раньше
  любой отказ сервера приравнивался к «записи нет» — ровно то, что видел владелец).
  Сторож: `employeeAccessSingleSource.guard.test.ts`.
- **#1962 (в ревью)** — **поле «Цех» и класс «No handler registered»**: на текущем коде
  ошибка «Error invoking remote method 'workshop'» **не воспроизводится** (хендлер есть,
  подключён безусловно, гейт раздела канал не режет) ⇒ пришла из старой сборки клиента,
  лечится обновлением клиента. Чтобы класс не повторился — **сторож инвентаризации
  IPC-каналов** (все `invoke` из preload против всех `handle` из main; 561 против 562,
  единственное расхождение — `files:uploadBlob`, который обслуживает Android-мост, и он
  в белом списке, который не растёт молча). Поле «Цех» показывает состояние словами.

План нитки — [`docs/plans/admin-users-and-access-single-source-2026-11.md`](docs/plans/admin-users-and-access-single-source-2026-11.md).

## Что не сработало

- **Параллельная линия взяла те же промты** (#72/#74) — мои PR с той же правкой стали
  дублем и закрыты. Проверка «а не слито ли уже это в `main`» перед мержем — обязательна.
- **`git commit -m` с многострочным текстом в PowerShell ломает аргументы** (кавычки и
  переводы строк): сообщение писать в файл и коммитить через `git commit -F <file>`.
- **`git branch -f` и `--force-push` гейтом не пускаются** (нужна подтверждающая
  подсказка, а её негде спросить) ⇒ переезд правки на свежий `main` — новая ветка +
  `git cherry-pick`, конфликты разрешаются вручную.
- **PDF-рендер печатной формы**: Chrome `--print-to-pdf` уважает `@page` (A4 landscape),
  но **текст из PDF извлекается с переносами** — судить по нему о вёрстке нельзя; для
  проверки ширин годен скриншот страницы (`--screenshot` при ширине окна 1024 px = 271 мм),
  для проверки разрывов — PDF по страницам (сколько строк на какой странице).
