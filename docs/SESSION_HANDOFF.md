## Текущая нитка

**MiniMax-воркер на проде «Матрицы РМЗ» для ИИваныча** (промты КАРМАНА **#56 + #57**, раздел `MatricaRMZ`; задание пришло от Управляющего, meta-репо `brain_matrica`, область `p-brain2`).

- **Что заказано:** сервис-воркер по образцу «Сарафана» — берёт свободный аккаунт MiniMax в «Кармане», поднимает на нём агента MiniMax Code и обслуживает запросы ИИваныча.
- **Решения владельца от 21.11 (приняты, не переигрывать):** воркер живёт **на боксе Матрицы РМЗ**; доступ к комнате Кармана — **сервисным грантом на запись**, пишущий токен на бокс **не кладём**; цепочка звеньев — **MiniMax на проде → платный DeepSeek последним** (fail-open, D-243); контракт воркера — Anthropic-совместимый **`/v1/messages`**.
- **Сделано (PR #1900, слит в `main`):** воркер `backend-api/src/minimaxWorker/` (клиент пула, профиль CLI с токен-стором, адаптер `mcode exec`, **слой преобразования ответа в `tool_use`**, HTTP-эндпойнт `/v1/messages` + `/health`) — 45 юнит-тестов; транспорт бэкенда (`llmProvider.ts`: провайдер `minimax` + fail-open на DeepSeek, `answerSource: engine|deepseek`); одна строка белого списка моделей; юнит `matricarmz-minimax-worker.service` (`MATRICA_INSTANCE_ROLE=worker`); доки — [план нитки](docs/plans/minimax-worker-for-iivanych-2026-11.md), грабля M222, OPERATIONS §8а, PENDING, письмо в Мозг.
- **Ключевое решение сверки с планом:** токен пула берётся **из комнаты** (`KARMAN_MINIMAX_TOKEN`, читает `karmanVaultClient.ts`), а не кладётся в env-файле бокса — по решению владельца от 21.11 пишущий токен на бокс не кладём. Это и есть сервисный грант.
- **Ещё одно решение, которого не было в плане:** воркер держит **аренду аккаунта**, а не берёт новый на каждый вопрос (у Кармана выдача = погашение, аккаунт — один потребитель на сутки: иначе пул сгорал бы за минуты). Следующий аккаунт — по отказу или по истечению входа (`renew`).
- **Контракт ИИваныча не тронут:** очередь `ai_chat_requests`, воркер `startAiChatDirectWorker`, 4 мета-инструмента и строгий `tool_use`-JSON — как были; правка только в транспорте.

## Что не сработало

- **Anthropic SDK шлёт ключ заголовком `X-Api-Key`, а не `Authorization: Bearer`** (второе — только от `authToken`). Воркер с проверкой только по Bearer отверг бы бэкенд с `401` — а `401` по правилу fail-open **не** повод уйти на страхователя, то есть поломка вышла бы глухой. Нашёл разбором SDK в `node_modules`, не тестом: интеграционного теста «бэкенд → воркер» нет.
- **Сторож раскладки доков (`docsMemoryLayout.guard.test.ts`) ловит две вещи, которые видно только в CI:** заголовок файла пункта должен **дословно** совпадать с текстом ссылки в индексе, а `GOTCHAS.md` на main уже стоял в **26 байтах** от потолка (51 174 из 51 200) — строка новой грабли его перетолкнула. Потолок не подняли: сжали восемь длинных формулировок (запас 496 байт).
- **Пул аккаунтов — не расходник на каждый вопрос.** Первая версия воркера брала аккаунт из пула на каждый запрос; у Кармана выдача = погашение, аккаунт — один потребитель на сутки, и такой режим сжёг бы пул за первые минуты (прецедент «Сарафана»: 15 аккаунтов за две минуты). Теперь — аренда: аккаунт меняется по отказу или по истечению входа.
- **Локальный гейт прав не пускает удаляющую команду на проде** (`HOST_CAPABILITY_UNAVAILABLE`) — так не прошла чистка старого APK. Обходить нельзя, это шаг владельца.
- **PowerShell `Get-Content` читает UTF-8 как ANSI** — русский текст в выводе превращается в мусор («РЎРѕРјР°С‚РёРѕ»). Для чтения файлов — инструмент `read`/`grep`, не консоль.
- **Исследователь-субагент упал по очкам** (лечащий взял новый аккаунт, ход оборвался) — контракты Кармана и прецедент «Сарафана» сняты вручную, точечным чтением чужих репо (ADR-0007: читать соседей можно, писать — нельзя).

## Открытые вопросы для пользователя

- **Форма сервисного гранта:** достаточно ли токена в комнате (`KARMAN_MINIMAX_TOKEN`), или нужен отдельный грант на конкретные ручки? Сейчас реализовано «токен в комнате» — тем же приёмом, что и `MAX_ALERT_TOKEN`.
- **Когда включать звено:** сразу после установки юнита или после первого живого прогона? По умолчанию `MATRICA_AI_PROVIDER` не трогаем — поведение прежнее (DeepSeek напрямую).
- **Бюджет очков:** пул Кармана общий с «Сарафаном». Нужно ли ограничивать воркер по частоте (не чаще раза в N минут на аккаунт)?
