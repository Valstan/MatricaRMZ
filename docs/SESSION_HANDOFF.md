## Активная нитка: пакетный приём — необязательные поля и «Обновить»

Слово владельца 20.10:

- **все поля формы приёма станут необязательными** (сейчас обязательны марка, контрагент, договор, дата прихода);
- добавляются поля **«Внутренний номер»** и **«Дата дефектовки»**;
- у дубля появляется третье решение **«Обновить»**: проверить, каких из предложенных данных в карточке нет, и дозаполнить их (не перезаписывая заполненное). Сценарий владельца: первый раз приняли пачкой только номера заказчика, второй раз тем же списком принесли внутренние номера/договор — карточки надо **дополнить**, а не пропустить.

**Код готов** (план — [`docs/plans/engine-bulk-intake-update-2026-10.md`](plans/engine-bulk-intake-update-2026-10.md)), осталось: смоук на стенде → PR → **3.82.0**. Решения, снятые по ходу:

- **внутренний номер — построчно, а не полем на пачку** (уникальна пара номер+год: один номер на 50 двигателей отбил бы гейт дублей); столбец вставляется в первую строку и расходится вниз; короткий «41» берёт текущий год, «41/26» — свой;
- **«дата дефектовки» пишется этапом «Разборка/Дефектовка»** (вопрос владельцу задан и решён так): поля в карточке нет с 01.10, канон даты — акт/строка этапа, и именно она задаёт стадию завода. Дата одна на пачку, этап идемпотентен, при отказе (дата раньше прихода, нет права писать этапы) итог говорит «этап дефектовки не встал: N» — молча не теряется;
- «Обновить» **только дозаполняет**: заполненное не перезаписывается, расхождение показывается словами «в карточке другое: … — не перезаписываю»; дополненный договор сажает двигатель в план договора.
