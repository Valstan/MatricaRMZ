## Контекст

- **Отдельного права на рекламацию в системе нет** — это решение плана [`reclamation-mvp-2026-07`](plans/_archive/reclamation-mvp-2026-07.md) («read-only через `disabled={!canEditEngines}`»). Следствие выдачи: Альвина получила правку **любых** карточек двигателей. Нужен более узкий доступ — заводить новое право отдельной задачей.
- **Права и роли:** `defaultPermissionsForRole` (роль → набор) + override'ы `user_permissions` поверх + временные `permission_delegations`. Точка сборки — `backend-api/src/auth/permissions.ts`. Роль `viewer` = `OPERATOR_BASE_PERMISSIONS` без единого edit-права (`shared/src/domain/permissions.ts`).
- **Гейт выдачи:** `PUT /users/:id/permissions` не даёт роли `admin` править цели с ролью ≠ `user` — точечные гранты операторам идут от суперадмина.
- Открытых PR нет. Локальных веток кроме `main` нет. Stash пуст.

## Что не сработало

- **CDP-смоук вкладок карточки — четыре промаха подряд**, все «тихие» (промах, а не ошибка): ярлык вкладки несёт маркер-точку (`Рекламация ●`) → точное сравнение не находит; скрытые вкладки остаются смонтированными → `querySelectorAll('button')` и `body.innerText` дают противоположные ответы; якорь панели по кнопке действия не работает в ролевом срезе (кнопок нет вовсе — это и проверяется); карточка из deep-link'а не карточный таб (`.v2-card-tab-close` нет, сохранение через «Закрыть карточку» → «Сохранить»). Всё записано в [`docs/machines/PC40.md`](machines/PC40.md).
- **Смена прав не доходит до UI мгновенно:** `window.matrica.auth.sync()` из CDP обновляет сессию в main-процессе, но не React-стейт — бридж уже говорит новое, кнопка на экране ещё старая. Ролевой срез гонять, дождавшись именно DOM.
- **Ошибочно искал `input[type=date]`** в полях рекламации — в приложении это react-datepicker (`input.matrica-datepicker-input`, `дд.мм.гггг`). Грабля была записана в профиле машины, но не применена — стоила двух ложных «FAIL: дата не подставилась».
- `grep` через Bash по всему дереву упирается в 120-секундный таймаут (node_modules) — искать `Grep`-инструментом.
