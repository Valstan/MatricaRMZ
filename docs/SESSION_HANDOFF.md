Единый источник в рендерере — `hooks/useListBehaviorSettings.ts` (+ CSS-переменные). Пункт суперадмина: «Настройки → Интерфейс → Правила списков».

  - **Сторож кита:** `electron-app/src/renderer/src/ui/listKit.guard.test.ts` (правила из общего источника; старый жёсткий шаблон меню не вернётся; `dragend` гасит состояние).
