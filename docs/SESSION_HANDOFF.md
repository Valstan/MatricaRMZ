## Что не сработало

- Клиент на свежем профиле в первичном синке выглядит «синкающимся» и на клик не жалуется, а сервер при этом отказывает: диагноз ставить по `.verifier-electron/backend.log`, не по UI.
- Gitleaks-гейт не чинится «удаляющим» коммитом: экшен сканирует диапазон коммитов ветки, находка в середине держит красный. Только схлопывание (`reset --soft` + force-push) — GOTCHAS **M154**.
- Условный JS внутри `ensureClientSchemaParity` (`electron-app/.../migrate.ts`, `android-app/src/db/migrate.ts`) нельзя вставлять в середину `sqlite.exec(\`…\`)`-литерала: бэктики рвут строку, esbuild падает. Чистый SQL — внутрь литерала, условный JS — отдельными `sqlite.exec` после него.
- PowerShell съедает `$(...)` и кавычки в командах, уходящих по ssh: сборку удалённых скриптов делать через base64 (`echo <b64> | base64 -d | python3 -`), а не через `"..."` с вложенными кавычками.
