## Контекст

- **Серенькие — одно правило.** Уволен / декрет / на лечении → ребёнок не участвует в отборах и уходит из напоминалок. Флага на ребёнке нет намеренно: разъехался бы с кадровым статусом.
- **Реплика — pull-only**, запись идёт серверной дверью; клиентский push закрыт владением `server` (бэкастоп). Экраны перечитываются по синку (`useLiveDataRefresh`).
- **ПДн детей**: дата рождения, возраст и признаки — чувствительные данные. В карточке и в отчёте по умолчанию; свой раздел доступа — в общий кадровый контур не пускаем.
- **Машина PC79:** dev-стенд — backend на **3011** (3001 занят посторонним процессом), CDP 9222, PostgreSQL `matricarmz_dev` (postgres/postgres, пароль в `%USERPROFILE%\pg-local-credentials.json`). Перед Electron — ABI `better-sqlite3` из `.verifier-electron/abi-backup/electron-*`, после — Node-ABI (иначе падают тесты); своппер — `.verifier-electron/swap-abi-2026.ps1`.

- **Детский агент-разведчик упал** («insufficient balance (1008)» у провайдера — та же причина, по которой 09.11 упал автор модуля ПП). Разведка по коду сделана вручную.

- **Смоук показал пустой список** после того, как строка доехала по синку: экран читал реплику один раз при открытии. Исправлено `useLiveDataRefresh`.
- **Смоук показал запись не сразу:** дверь ждала тика публикатора (раз в минуту) — оператор после выдачи подарка видел пустой журнал. Исправлено публикацией из двери (PR #1738).
- **PowerShell-запись файлов портила кириллицу** (PS 5.1 читает UTF-8 без `-Encoding UTF8` как ANSI, а запись без BOM — уже в ANSI): ESLint поймал это как `no-irregular-whitespace`. Файлы откачены и переправлены через редактор. **Правило на будущее:** файлы с кириллицей править только редактором, не `Get-Content -Raw | WriteAllText`.
