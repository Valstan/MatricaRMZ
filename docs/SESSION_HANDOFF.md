## Открытые вопросы для пользователя

- «Полный акт комплектности сразу» из пачки (списком деталей марки) vs «одна дата, строки досеет
  панель» — сейчас второе; если нужен полный акт прямо из приёмки, это отдельный шаг.
- Ииваныч в «Авто» не отвечает, пока движок качается (первая закачка ~100 МБ) — вопросы в это время
  уходят на сервер. Если для парка это неприемлемо, движок надо ставить заранее (отдельная нитка).
- Проверка расхождения часов пока только предупреждает. Автоматически чинить время без прав
  администратора нельзя — если нужен авто-режим «время по интернету + часовой пояс», это отдельный
  шаг (п. 4 выше).
