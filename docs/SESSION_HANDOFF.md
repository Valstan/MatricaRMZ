## Что не сработало

- **`ssh matricrmz` (канон) на этой машине не резолвится** — в `~/.ssh/config` PC79 алиас прода называется **`matricarmz`** (с лишней «a»). Ошибка «Could not resolve hostname» здесь — **не сеть и не fail2ban**. Проверка без сети: `ssh -G matricarmz | Select-String '^(hostname|port|user) '`.
- **SQL через пайп из PowerShell** (`Get-Content | ssh`) — psql спотыкается о BOM. Рабочая форма: запрос **одной командой** в `ssh '… -c ''…$$литерал$$…'''` (литералы — долларовые, `$` в PowerShell не интерполируется внутри одинарных кавычек).
- **`gh api graphql` режет permission-гейт**, `gh api -X POST …/merge` → 404. Слияние — только `gh pr merge <n> --squash --body-file <UTF-8 файл>` (заголовок брать из самого PR).
