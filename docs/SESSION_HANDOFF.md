**Планшетный UI: масштабирование, скролл, компактные шапки, кнопки скрытия колонок.** PR #484 (авто-скрытие вспомогательных панелей) смержен. Сессия добавила:

5. **Инлайн-кнопки скрытия колонок** — `ColumnToggleButton` (×) на видимых шапках, `HiddenColumnMarker` (+) для скрытых. 8 страниц обновлены.
