## Что не сработало

- **ABI-свап `better-sqlite3` через `Copy-Item -Force` портит pnpm-store для всех воркаутов** (файл — hard link на store). Рабочий порядок: **сначала снять файл, потом копировать** из `.verifier-electron/abi-electron-20261021/` (M209). Проверено на стенде `lane1`: `rm` (в корзину) → копия → `ELECTRON_RUN_AS_NODE=1 electron.exe` с `process.dlopen` подтвердил Electron-ABI; после прогона ABI вернулся в node — иначе падают тесты `electron-app`.
- **CDP-проверка, режущая текст строки целиком, меряет не то:** строка подсказки — это ДВА блока (жирный номер двигателя и пояснение «внутр. N · РМЗ-N»), а разбор по пробелу склеивал их («Э06АТ0889RMZ3») ⇒ проверка валила на корректном продукте. Чинить: брать номер из **первого** блока строки, пояснение читать отдельно.
- **`gh pr merge --squash --delete-branch` сносит рабочий worktree** (`.git`-файл удалён, индекс пуст, `git` начинает видеть главный клон) — грабля [M237](gotchas/M237.md). Мержить **без** `--delete-branch`, ветку сносить руками после.
