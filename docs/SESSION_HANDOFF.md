## Что не сработало

- **Решение кладовщика терялось из-за названия строки в бланке.** В бланке колонка «приказная строка (норма)» названа по другой должности (у штукатура — строка маляра) → движок объявлял позицию «не найдено» и молчал о решении. Вывод: решение кладовщика — это про **предмет**, а не про название строки; название уточняется подбором.
- **`when` в журнале drizzle должен быть больше последней применённой миграции** — иначе мигратор считает файл «старым» и молча пропускает его (миграция не применилась, а команда рапортовала «migrations applied»).
- **Заводские строки приказа — только в конец TSV.** Генератор нумерует строки по порядку в файле: вставка в середину сдвинула бы `sort_order` уже применённых строк 766н (применённые миграции не перезаписываются) — расхождение молчаливое.
- **Торговый идентификатор бывает у нескольких вещей** (перчатки и нарукавники одной сертификации — «ЛАЙТ/BERD»): подбор по нему без проверки предмета уводил перчатки в строку про нарукавники. Правило: сначала предмет строки, идентификатор — только как довод.
