## Что закрыто релизом v3.34.0

Задание владельца 15.09 (вечер) — перестройка ведомостей работ и затык в дефектовке — закрыто по коду целиком.

- **Ведомости работ:** один список в общем укладе программы вместо вкладок по видам работ; у каждой ведомости своя карточка-вкладка (`work_sheet`) со стандартными кнопками и сторожем несохранённого — модальный диалог удалён; реквизиты двигателя (марка, внутр. №, заказчик, договор) подставляются номером двигателя и резолвятся при чтении; печать списка на А4; переходы ведомость ↔ двигатель и история ремонта → ведомость; «Узел» → «Вид работ» во всём интерфейсе (слово занято: узел = сборочная единица) со сторожем против возврата.
- **Дефектовка:** личные номера экземпляров появлялись со второго-третьего нажатия не из-за скорости — `SyncManager.runOnce` при занятости возвращал результат ПРОШЛОГО прогона, и показ опережал данные (GOTCHAS **M134**). Занятость теперь ждёт и запускает свежий прогон, очередь глубиной один.
- **Днём ранее в том же релизе:** хвосты первого выпуска ведомостей (отдельное право `work_sheets.edit`, гейт смены типа колонки по самим записям, откат «Отремонтирован» по штампу, возврат вида работ из архива, скан отчёта сужен — M39) и съём клиентской обвязки из `node_modules` прод-бокса (стор 933 → 359 МБ, GOTCHAS M132/M133).

Подробности — в `COMPLETED.md`, телах PR [#923](https://github.com/Valstan/MatricaRMZ/pull/923)–[#936](https://github.com/Valstan/MatricaRMZ/pull/936) и `git log`.
