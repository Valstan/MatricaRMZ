## Контекст

- **Два слоя номенклатур в СИЗ.** Нормы приказа ссылаются на базовые позиции (`СИЗ-018`), выдача идёт по размерным детям (`СИЗ-018-44`), склад 1С — по торговым («Костюм МОТОР … (96-100/170-176)»). Отчёты обязаны приводить выдачу к базе; мост между слоями — отдельная работа.
- **Выдача списывает склад** (`ppeService.issuePpe` → документ `stock_issue` проводится сразу). Поэтому в заявке «выданное» и «остаток» не пересекаются, а «потребность» уже за вычетом выданного.
- **Период количества — год**: норма приказа годовая, поэтому «выдано за год» сравнивается с годовой нормой.
- **Машина PC79:** dev-стенд — backend на **3011** (3001 занят посторонним процессом), CDP 9222, PostgreSQL `matricarmz_dev` (postgres/postgres, пароль в `%USERPROFILE%\pg-local-credentials.json`).
