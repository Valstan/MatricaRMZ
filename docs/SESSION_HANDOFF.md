## Что не сработало

- **Замер «рабочая область списка выросла» в смоуке не подтвердил место под список** (`before 964 → after 964`): мерится узел `[data-list-root="true"]`, а на странице двигателей он стоит **выше** панели фильтров (top 39 против top 99) — то есть не та область, которая растёт. Сама панель схлопывается правильно (116 → 62 px), место освобождается по вертикальному flex (`flex: '0 0 auto'` у панели, `flex: '1 1 auto'` у рабочей области), но подтвердить это замером на стенде не вышло ⇒ **приёмка глазами за владельцем**.
- **Фикстуры стенда ограничивают смоук панели:** у ступени «Заказчик» на стенде нет значений ⇒ нечего выбрать ⇒ плашек нет ⇒ 8 из 9 проваленных шагов (итог 29/38 PASS) не исполнимы. Это ограничение фикстур, **не регресс**: проверки плашек и выбора в меню требуют значений в справочнике заказчиков.
- **`psql` без `$env:PGPASSWORD` уходит в интерактив и виснет** (грабля PC79, `docs/machines/parts/PC79/smokes.md`) — стенд поднимать только с паролем в окружении.
- **Локальный PostgreSQL на PC79 умирает сам** (3–40 минут, `0xC0000142`) ⇒ стенд `lane1` поднимается под один прогон, а не как долгоживущий.
- **Гейт режет `git branch -D` и `git push origin --delete`** (`HOST_CAPABILITY_UNAVAILABLE`) ⇒ локальные копии смерженных веток остаются; remote-ветку GitHub удалил сам после merge.
- **`git checkout main` в worktree `m2` невозможен:** `main` держит основная область (`D:\valstan\REPO\MatricaRMZ`) ⇒ локальный ref `main` отстаёт от `origin/main`, и обновляет его тот, кто держит `main` (`git pull --ff-only`). Ветку этой сессии создавали от `origin/main` (`git checkout -b <имя> origin/main`).
- **Гейт режет `Stop-Process`/`taskkill`** ⇒ осиротевший backend стенда `lane1` остался слушать порт **3002** (PID 53364); освобождать вручную: `Get-NetTCPConnection -LocalPort 3002 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }`.
