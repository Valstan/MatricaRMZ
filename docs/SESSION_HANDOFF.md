**Подписанная экосистема — ADR-0003** ([`docs/adr/0003-signed-code-ecosystem-one-kaspersky-rule.md`](adr/0003-signed-code-ecosystem-one-kaspersky-rule.md)): подписывать всё, что Матрица запускает, своим CA — чтобы в Касперском работало **одно правило** вместо кучи исключений, и так же всё, что появится в экосистеме (модули, харнесс, EXO-кластер с локальными нейронками).

**Ключевое измеренное (детали — в ADR, здесь только итог):**

- **15 PE из 15 подписаны** в полной сборке с инсталлятором (`signtool verify /pa /v` → `Issued to: MatricaRMZ Test Root CA`). В релизе 359 файлов; остальные 344 — не-PE, подписи физически не подлежат (Authenticode — механизм для PE) и не нужны: их покрывают исключения на данные.
- **Нет ключа → сборка не падает** (`EXITCODE=0`, релиз выходит неподписанным) — намеренно: парк не должен остаться без релизов. С ключом шаг `-Mode Verify` строгий: неподписанный артефакт останавливает релиз. Битый PFX → exit 1 с читаемым текстом.
- **24 строки исключений и доверенных приложений на машину → ~8** (корень в доверенных + одна галочка в GUI + исключения на данные) — и ни одной новой строки на каждый будущий модуль экосистемы.
- **Процессы, которые Матрица запускает, подписью не закрываются** — у процесса нет своего образа. Их закрывает второй механизм Касперского: доверенное приложение = клиент + «не контролировать активность дочерних приложений».
- **electron-builder не подписывает `extraResources`** → сторож подписывается отдельным шагом до сборки; опции `win.signDlls` в 26.8.1 не существует, DLL и `.node` идут через `win.signExts`.
- Настоящий прогон `release-electron-windows.yml` на GitHub-раннере (run `41908688540`) — **конвейер зелёный целиком**, включая новые шаги.

## Что не сработало

- **Установка корня в `CurrentUser\Root` выглядит как зависание** (замерено 45–207 с) — это не зависание, а проверка доверия Windows при добавлении в хранилище. На парке это надо закладывать в развёртывание, иначе оператор решит, что всё встало (ADR-0003 п.3).
- **Developer Mode и `SymlinkEvaluation` не дали симлинки без повышения прав** — сборка electron-builder обрывалась на распаковке `winCodeSign`; привилегия выдаётся только при `RunAs` ([M190](gotchas/M190.md)). На CI проблемы нет.

- **Какое хранилище сертификатов предлагает вкладка в GUI Касперского** — блокирует решение по ADR-0003 (п. 7).
