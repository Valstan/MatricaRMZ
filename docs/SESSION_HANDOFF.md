## Что не сработало

- **Писать кириллицу в консоль и читать её оттуда на этой машине нельзя:** `node -e "...console.log(кириллица)"` и `Out-File` дают мусор в выводе (кодовая страница консоли), хотя файл на диске цел. Текст результата — только через `fs.writeFileSync(..., 'utf8')` и чтение файла, а не через stdout.
- **`corepack pnpm -r test` на этой машине даёт случайный красный** (таймауты в посторонних тестах) — перегруз, а не регресс; гарантированный прогон `--workspace-concurrency=1`.
- **Резать «по слову закрыто» нельзя:** пять кандидатов из девяти на поверку несли открытый хвост (хвосты J3, закрытые наряды до релиза, ветки-остатки с решением владельца внутри). Ротация режет по факту «остатка нет», а не по заголовку.
- **Авто-нарезка симптома для строк индекса даёт обрубки** («режим просто не работает у оператора… У нас —…»): формулировку для индекса надо писать руками. Поэтому в фазе 2 строка индекса — заголовок пункта целиком, без обрезки.
