## Что не сработало

- **Первый прогон `runSync` падал `Error: offline` при замоканном `fetch`** — предикат «есть ли `navigator` → значит браузер» врёт: в Node 22 `navigator` существует, а `onLine` у него нет. Полчаса ушло в отладку мока вместо предиката. Грабля — [`GOTCHAS.md`](GOTCHAS.md) **M56**.
- **Ожидание «повторный синк тянет 0 строк» оказалось неверным, а не код.** Клиент штатно перечитывает хвост с перекрытием курсора (защита от гонок) — правильный инвариант не «pulled=0», а «дублей не появилось и курсор стабилен». Тест переписан на инвариант; исходная формулировка краснела на здоровом поведении.
- **`drizzle-orm/sqlite-proxy` на сыром `sql\`...\`` отдаёт позиционные массивы, а не объекты** (`[['x']]` вместо `[{code:'x'}]`), и `get()` на промахе даёт `[]`, а не `undefined`. Объектный маппинг появляется только у select-билдера по схеме — то есть на реальном пути сервисов; в тестах сырой SQL проверять позиционно.
- **Не пытаться типизировать общий vite-плагин через `Plugin` из `vite`:** пакет сидит на vite 5, vitest 4 тянет vite 7 — типы несовместимы под `exactOptionalPropertyTypes`. Структурный литеральный тип подходит обоим.
