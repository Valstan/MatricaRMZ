## Что не сработало

- **Диагностика docx по целостности контейнера** — тупик: `unzip -t`, `file`, парсинг всех XML-частей и совпадение sha256 давали «всё хорошо» на файле, который Word отвергал. Сдвинулось только после открытия файла настоящим Word'ом через COM (на PC40 он есть) и бисекции по одному признаку.
- **Поиск порчи в транспорте** (Яндекс.Диск → клиент) — потратил на это время зря: скачанный с прода файл байт-в-байт совпал с тем, что произвёл генератор. Порча была в самом генераторе.
- **Правка регулярок с управляющими символами инструментами** — рецидивировала трижды (литералы то появлялись, то терялись), один заход питоном обнулил файл. Лечение — собирать класс символов из ASCII программно (**M82**).
- **`git status` + `pnpm install` как способ понять, нужен ли деплой планшетного APK** — не сработало бы: APK на прод кладётся руками, в git его нет; поймано только явной проверкой Диспетчера (`up-to-date` вместо `update`).
