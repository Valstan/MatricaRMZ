## Что не сработало / грабли сессии

- **Стенд-бэкенд держит старую сборку** — после правок backend/shared серверная фича молча не работает (ловилось трижды). `stop.ps1` убивает только electron; бэкенд гасить по PID порта 3001.
- **CDP: двойной клик = двойное переключение.** `el.click()` + синтетическая серия событий открывали и тут же закрывали панель/оверлей (МЕНЮ, «История изменений»). Для тумблеров — ровно один клик.
- **МЕНЮ в шапке — не вкладка, а переключатель оверлея** (`data-active` у него не бывает); кнопки разделов есть в DOM и без него.
- **Bridge-логин не поднимает React-стейт** — после него нужен `Page.reload`.
- **ABI-качель better-sqlite3** между vitest (Node) и стендом (Electron 43).
- Все эти грабли записаны в `docs/machines/rmz4val.md`.
