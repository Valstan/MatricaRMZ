## Что не сработало

- «Прод-путь лежит» → не лежал: в команде был перепутан алиас ssh (`matricrmz` вместо `matricarmz` — на букву), а «TCP-22 открыт» относится к чужому sshd (прод слушает нестандартный порт). Проверять алиас через `ssh -G <алиас>`.
- «Кнопка не сохраняет» по проверке на экране → экрану врёт: значение меняется, а в базе пусто. Сверять с сервером (`engines.get`, `checklists.engineGet`), а не с DOM.
- Поле карточки искалось по подписи через `parentElement.querySelector('input')` → попадало в ПЕРВОЕ поле грида, а не в своё (так «Примечание» переписало «Номер двигателя»). Искать поле по значению или по следующему соседу подписи.
- CDP-прогон к списку товаров на стенде не довёл: меню открывается, а пункт «Товары» не находится → живой смоук наряда и простых справочников не сделан (на стенде таких карточек нет), закрыт структурным сторожем.
- `gh api` из PowerShell: `&` и `|` в URL ломают разбор аргументов — передавать запрос через `gh api` с одинарными кавычками и разбирать вывод в `ConvertFrom-Json`; при `Set-Location` внутрь скрипта политика безопасности блокирует запись в каталоги вне workspace.
- Прокси GitHub на `127.0.0.1:10809` был мёртв (порт не слушается) — `git push` падал с `Failed to connect to github.com:443 over proxy`. Прямое соединение работает: перед push снять прокси (`$env:HTTP_PROXY=''; $env:HTTPS_PROXY=''; git -c http.proxy= -c https.proxy= push`). Тот же обход нужен для `gh`/`gh api`.
- После раскладки артефактов `latest.json` показал `lastError: stale_manifest` (манифест посчитан по недокачанному файлу) — вылечивается повторным рестартом primary, когда файл уже на месте: свежий скан пересеивает манифест, `lastError` становится `null`.
- Инлайновые скрипты по `ssh` из PowerShell ломаются кавычками (`'...'`, `$(...)`, кавычки внутри) — длинные проверки на проде писать файлом и заливать через `scp`, а не в одну строку команды.
