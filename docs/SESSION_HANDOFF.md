- **Стенд-бэкенд держит старую сборку**: после правок backend/shared серверная фича молча не работает, проба краснеет «как будто клиент не пишет». Ловилось дважды. `stop.ps1` убивает только electron. Записано в `docs/machines/rmz4val.md`.
