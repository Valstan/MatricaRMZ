## Закрытая нитка: первый сейв новой карточки не теряется (выпуск 3.82.0)

Слово владельца 20.10: заполняешь новую карточку двигателя, сохраняешь — через полминуты она пуста; заполняешь второй раз — держится. То же с «Принять двигатели списком».

**Корень (GOTCHAS M163):** клиент отправляет сущность и карточку одним батчем; ветка `entities` применяется раньше ветки карточек, и её `INSERT` зажигает `trg_mirror_engine_card_entity` → `rebuild_erp_engine_card` заводит **пустую** строку карточки (EAV ещё пуст) со своим `updated_at` = `clock_timestamp()`. Строка клиента проигрывает ей по LWW и отбрасывается молча; издатель публикует пустую строку, pull затирает локальные значения.

**Фикс (в `main`, выкатан):** миграция `0112_engine_cards_first_save_guard.sql` (зеркало не заводит строку, когда зеркалить нечего) + `applyPushBatch` (строка без номера журнала не считается автором по LWW; отказ в ветке карточек больше не молчит — метрика + `logSkip`). Приёмка — `engines:first-save-check` (живой PG; в CI — джоба `migrations-check`), смоук `cdp-engine-bulk-intake.mjs` шаг `[9]`.
