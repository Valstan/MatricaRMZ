## Что не сработало

- **Три реестра, а не два.** Две карты pull (снимок и инкрементальный) и список зеркал — это три места; каждый PR серии был зелёным, потому что проверялось только «зеркало → карты pull», а не наоборот. Теперь сторож держит обе стороны.
- **Сторож не значит «проверено на живом».** Дубли на проде копились два часа, пока миграция `0120` ждала мержа: миграция переводит строки в `pending`, а если код с обработчиком зеркала ещё не выкачен — издатель успевает наполнить журнал дублями. Правильный порядок выката: **код → миграция → отдельный шаг публикации** (`sync:restamp`).
- **Применённую миграцию не правят** — `0117`/`0118` уже катили, изменения ушли в `0119`/`0120`.
- **psql на Windows не печатает кириллицу** — читать прод-БД через node `pg`; на самом боксе `psql` в консоли через ssh читается нормально.
