## Текущая нитка — эгресс движка и квота free-тира

Задача владельца: Ииваныч на проде работает через серверный opencode (контур A), трафик движка идёт через ВПН, при отказах — переключение серверов ВПН.

**Что выяснено фактами (24.10):**

1. **ВПН для движка не работал ни дня** (M168). В `/usr/local/lib/neural/egress-redirect.sh` uid был захардкожен `1000` (владелец), а `opencode` живёт под `1001`; в юните `UID_ENGINE=1001` уже стоял, но сервис с ним не перезапускали — конфиг прав, рантайм стар. Исправлено (uid берётся у пользователя сервиса, сервис перезапущен). Проверка — два exit-IP: движок `155.117.232.x` (туннель), шелл `195.161.41.30` (напрямую).
2. **Квота free-тира выедена, и ротация её не возвращает** (M169). 21 сервер подписки NextGenVPN — мгновенный 429 на каждом; все free-модели — 429. Холодная ротация (стоп движка → смена выхода → старт) на трёх свежих выходах — те же 429. Напрямую бокс 429 не получает, но и не отвечает (висит 90–240 с).
3. **Пробы агента сожгли дневной запас сами**: единственный настоящий вопрос Ииваныча 24.10 обслужен в 20:34 (`answer_source=engine`), остальное — проверки. Вывод: движок пробовать только **реальным вопросом оператора** (текст из `ai_chat_requests`), синтетические «2+2» запрещены.
4. **DeepSeek на проде `-0.00`** → запасного звена нет.

**Что стоит на боксе (вне репозитория — см. PENDING):**

- `/usr/local/lib/neural/tunnel-watchdog.sh` + `/usr/local/lib/neural/engine-probe.py`;
- `tunnel-watchdog.timer`: каждые 2 минуты `--check` — живость туннеля по exit-IP (`api.ipify.org`, провайдера **не** трогает) плюс последний **реальный** запрос Ииваныча в `ai_chat_requests`; если его обслужил не движок → холодная ротация тем же текстом вопроса (до 3 серверов) и алерт в Telegram;
- `neural-subscription-refresh.timer` — раз в неделю обновляет список серверов;
- журнал — `/var/log/neural/tunnel-watchdog.log` (M170: `logger` на боксе не доходит никуда).

## Следующий шаг

1. **Решение владельца по деньгам** — без него Ииваныч молчит: пополнить DeepSeek (дешёвый и быстрый путь) **или** OpenCode Go (снимает free-лимит, ВПН остаётся ради скрытия IP).
