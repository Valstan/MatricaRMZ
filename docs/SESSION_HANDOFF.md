## Что не сработало

- **`git checkout -b <new> origin/main` при незакоммиченных правках в дереве → отказ «local changes would be overwritten»** (24.11): чинится `git checkout -b <new> origin/main` + `git cherry-pick <sha>`.
- **PowerShell на PC79:** `Get-Content -Raw` читает UTF-8 без BOM как ANSI (кракозябры) ⇒ файлы править только `write`/`edit`; `Set-Content -Encoding utf8` пишет BOM. В консоли читать русские файлы только через `read`, не через `Get-Content`.
- **Цикл ссылок в хуках React** (`persist` → `requeueSave` → `scheduleRetry` → `flushPendingSaves` → `persist`): dependency-массивы вычисляются на рендере ⇒ TDZ. Разорвано ссылкой `flushRef` (сброс очереди берётся из ref, а не из замыкания).
- **`gh pr merge --squash` до зелёных required-checks отказывает** ⇒ включать `gh pr merge --auto`.
- **Смоук на PC79 невозможен:** локальный PostgreSQL на этой машине не поднимается ⇒ CDP e2e не гонялся (приёмка — за владельцем).
