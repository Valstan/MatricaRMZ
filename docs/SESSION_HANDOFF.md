## Что не сработало

- **Дважды «починили» вкладки, а не открывались** (.1647 — производный `tabList`/`selectTab`, .1711 — корень). Урок: симптом «клик по кнопке ничего не делает» в таб-модели — сначала искать молчаливые early-return в цепочке `handleMenuTab → setTab → requestTabSwitch → setTabState`, а не только в UI-обработчиках.
- **`edit`-инструмент по короткой oldString заменил НЕ тот блок**: oldString `let activeTabKey = ...` совпал с блоком `openedListTabs` (текст был вставлен поверх), задублировал activeTabKey и потерял `openedListTabs`+`tabList`. Вывод: уникализировать oldString (добавлять соседние строки), после каждой большой правки — `typecheck`.
- **PowerShell + ssh с вложенными python-одиночками**: `ssh matricarmz "python3 -c '...json.load(open(\"...\"))...'"` разбивается об экранирование PowerShell (бэкслеши/кавычки манглятся). Рабочий паттерн — без вложенных кавычек: `python3 -c` с двойными кавычками снаружи и одинарными внутри не проходит; проще писать маленький скрипт-файл или использовать `jq`/`grep`. (`stat -c%s` + сравнение через переменные тоже манглятся.)
- **SSH-команда с `&&` цепочкой из трёх шагов (download exe + download blockmap + ledger-publish + restart) ушла в timeout** — 60с не хватило на 136МБ-скачивание с GitHub на VPS; файл остался недокачан (98369536 из 136297706), что дало `stale_manifest` + частичный манифест. Урок: скачивание exe отдельной командой с длинным timeout, только потом blockmap/ledger/restart.
