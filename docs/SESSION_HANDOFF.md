## Что не сработало

- **Python `open(p, "w")` на Windows пишет CRLF** — деплой-скрипт для `bash -s` упал на `set -euo pipefail`. Писать с `newline="
"` либо прогонять `sed -i "s/$//"` перед отправкой на прод. И `psql` на проде — без `$DATABASE_URL` (его нет в env), только через `set -a; . /etc/matricarmz/matricarmz.env`.
- **Стенд: три невидимых блокера подряд** — окно «Что нового», модал черновиков, сессия `verify` без раздела «Снабжение». Каждый выглядел как «экран не открылся». Записано в `verifier-electron/SKILL.md` §«грабли 2026-09-12».
- **Python-патч по многострочному якорю с `
` внутри JS-строки** дважды тихо не совпал — для таких правок инструмент Edit, не heredoc.
- **`git stash push -- <пути>` с untracked-файлом падает целиком** (pathspec не в индексе) — либо `-u`, либо просто коммитить по путям.
- **SQL-запрос по памяти о колонках** (`app_version`, `machine_name`) — колонки называются `last_version`, `last_hostname`; сначала `\d`, потом запрос.
- Прежние (11–12.09): вопрос владельцу — с цифрами в руках; схема ≠ база (`service_price_orders`).
