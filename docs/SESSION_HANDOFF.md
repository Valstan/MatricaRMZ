## Что не сработало

- **Меню по координатам** — `document.elementFromPoint(75, 17)` для кнопки «МЕНЮ»: когда открыта другая вкладка, координата уезжает на вкладку и оверлей меню не открывается вовсе (смоук падал на «пункт не найден»). Лечение: искать кнопку **по тексту** «МЕНЮ».
- **Проверка «строка записана в план» по реплике** — новый план едет в реплику зеркалом (раз в минуту), и проверка его не видела. Лечение: читать план **с сервера** и ждать его появления в реплике.
- **Карточка движка на экране списка старее привязки к договору** (зеркало едет до минуты) — модалка отказывала движку напрасно. Лечение: карточки читаются в самой модалке (`engines.list()`), а номер договора, если в карточке его нет, берётся из строгой реплики.
- **Стендовая БД отставала от кода** (не накачены `0133` / `0134`) — издатель зеркала падал каждую минуту, и план **вообще не доезжал** до клиента. Лечение: `db:migrate` на стенде (прод под гейтом).
- **Сверить применённые миграции по хэшу файла** — мимо: drizzle 0.45.2 выбирает миграцию по `created_at`, а хэш из файла только пишет в журнал и **не сверяется** (грабля [M218](gotchas/M218.md)).
- **Передать скрипт с кириллицей на прод-бокс через `Get-Content -Raw`** — PowerShell 5.1 переписывает файл в ANSI и ломает русский текст ([M110](gotchas/M110.md)). Лечение: передавать байтами (base64) → на боксе `base64 -d`.
- **Дождаться CI через `gh pr checks --watch`** — обрыв на «unexpected EOF» от GraphQL, чек при этом был зелёный. Лечение: опросить `gh pr view <n> --json statusCheckRollup` по JSON.
- **Гейт записи не различает стенд и прод** — `node .verifier-electron/cleanup-smoke-fixtures.mjs` блокируется: хост не может спросить подтверждение, а скрипт пишет `UPDATE`. Лечение: снимать через интерфейс/мост клиента; на стендовой БД остался один живой договор-фикстура «СМОУК…» (на парк не влияет, стенд локальный).
- **Права в рендерере доезжают позже входа по мосту** — после `auth.login` права уже есть у `auth.status()`, а карта прав рендерера (`caps`) обновляется позже: элемент, закрытый **по праву**, остаётся неактивным, и подмена значения в нём молча ничего не делает. Лечение: **ждать разблокировки элемента** и показывать права в отчёте прогона.
- **Раздел моста, которого нет в preload, падает МОЛЧА** — `window.matrica.mail` не был объявлен никогда, и `MailComposeDialog` глотал ошибку: окно письма открывалось, вложение вечно «готовим файл…». Компилятор молчал (`matricaApi` — обычный объект, тип `MatricaApi` с ним не сверяется). Лечение: **сторож контракта** `preloadContract.guard.test.ts` (разделы shared ↔ preload) + понятная ошибка в окне письма вместо вечного ожидания.
- **Экран и модель печати брали номер двигателя из разных источников** — на экране живой из карточки, в модели печати снимок строки; файл мог унести старый номер. Лечение: одно правило на три места (живая карточка, снимок строки — запасной вариант). Проверять надо не «красиво ли», а совпадают ли **экран, лист и файл**.
