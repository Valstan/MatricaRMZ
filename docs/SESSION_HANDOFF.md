## Что не сработало

- **Фикс аудита двигателя ref'ом — откачен, стало бы хуже.** Ref убирает устаревшее замыкание, но `auditEditDone` выходит раньше на `if (!sessionHadChanges.current) return`, а этот флаг синхронно гасят ВСЕ пути закрытия карточки. Единственный путь, где он доживает, — удаление двигателя, поэтому «починка» давала ровно одну новую запись: аудит правки **по удалённой сущности**. Поймал адверсариальный верификатор, проследив воспроизведение сквозь новый код (не «проверь код», а «покажи, что репро теперь идёт по правильной ветке»).
- **Смоук дважды зеленел впустую.** (1) Эталон брался из поля ДО нормализации → маркер прошлого прогона становился «эталоном», сравнение вырождалось; лечение — сбрасывать до замера + утверждать, что эталон непустой и не равен маркеру. Именно эта строка вскрыла настоящий баг сброса. (2) Проверка била по полю «Марка двигателя», у которого на TEST-001 канона нет (`props.engineBrand` пуст) — правильное и неправильное поведение давали один ответ; переведена на «№ двигателя».
- **Три ложные гипотезы про несработавший сброс** (HMR не доехал, клик мимо кнопки, диалог не подтвердился) стоили больше, чем сам фикс. Помогла только инструментовка кода и взгляд на фактические значения.
- **Тело PR с обратными кавычками через `gh pr create --body "..."`** — bash съедает их как подстановку команд, PR уезжает покорёженным. Класть тело в файл и `--body-file`.
