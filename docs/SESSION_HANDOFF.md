**Приёмка владельцем (руками, после сборки):**

1. **Ручка в карточке:** открыть карточку наряда → в строках вида работ вместо кнопок ↑/↓ **ручка «⠿»**; перетащить строку мышью — видно перетаскиваемую строку и **линию места вставки**; клик по ручке → красная рамка → ↑/↓ двигают; повторный клик снимает.
2. **Меню:** в списке, где удаление запрещено, пункта «Удалить» нет; в списке двигателей есть «Бирки на выбранные» и «Добавить в производственную программу».
3. **Контур:** Ctrl + рамка выделяет несколько строк; клик мимо снимает выделение.
4. **Настройка:** суперадмин → «Настройки → Интерфейс → Правила списков» — переключатель меняет поведение во всех списках (в т.ч. на другой машине парка).
5. **Планшет:** на планшете перетаскивание мышью не работает (HTML5 DnD не ловит касание) — ручка остаётся способом включить режим перемещения; на тач-устройстве без мыши перестановка недоступна. **Это известное ограничение — если владелец ждёт перестановку пальцем, нужно либо полифилл drag-and-drop, либо оставить ↑/↓ на тач-платформе.**
