## Что не сработало

- **`start-backend.ps1` поднимает `dev:no-watch`** → новый маршрут не подхватывается без
  перезапуска, и стенд отвечает старой сборкой: `GET /ppe/cards/overview` уходил в `/cards/:id`
  и падал запросом `where id = 'overview'`. Признак «ошибка из чужого обработчика» на свежем
  маршруте — сначала проверить время старта backend. Запись — `docs/machines/PC79.md`.
- **Смоук-драйвер, который тогглит панель фильтров «вслепую»** → состояние панели живёт между
  прогонами (окно не перезапускается), и `click(toggle)` её закрывает вместо открытия: метки
  ступеней «пропадают», хотя они на месте. Проверять состояние до клика.
- **Клик по группе ступени без проверки, раскрыта ли она** → значение `уволен N` не находится,
  проверка молча падает. Драйвер теперь раскрывает группу по факту (есть ли кнопка значения).
- **Тест, держащий даты литералами** (`engineBulkIntakeService`) → авто-метка этапа ставится
  моментом записи, и назавтра субординация дат отказывает. Даты — от «сегодня», а не от даты
  написания теста.
- **Сторож `ListChrome.guard` числил `PpeCardsPage` в подтаблицах** → после перевода страницы в
  виртуальный список сторож требовал `RowNumberCell`, которого там быть не должно. Место страницы
  — в `PAGES`/`COUNTED_PAGES`; там же поймался `CARD_PARENT_TAB` без записи `ppe_card`.
