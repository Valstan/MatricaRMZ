## Следующий шаг

**Проверка на устройстве (шаги владельца, руками на планшете):**

1. **Щипок вниз** уменьшает интерфейс ниже канона; возврат к 100 % — двойной тап/щипок.
2. **Кнопки карточки** не уходят за правый край (1024×768), длинные подписи сокращены.
3. **Списки**: нет горизонтальной прокрутки, лишние колонки свёрнуты (а не обрезаны), липкая
   шапка на месте.
4. **ПП на планшете** открывается из меню и из левой полосы; план читается без сети, запись
   требует сети («нужна сеть» — штатно).
5. **Если щипок вниз не уменьшает** — решение за владельцем: вариант B (свой слой зума в
   renderer: `usePinchZoom`, 50–150 %, кнопки «− / канон / +», двойной тап — сброс) при выключенном
   зуме WebView (`setSupportZoom(false)`).

## Что не сработало

- **CDP-смоук на этой машине не поднялся:** клиент стенда не открывает окно (CDP `/json/list`
  пуст — признак ABI better-sqlite3), а остановить осиротевшие процессы и создать драйвер
  permission-гейт этой сессии не дал. **Локальный смоук не гнался — проверка на устройстве.**
- **`start-electron.ps1` из скилла `verifier-electron` не парсится в PowerShell 5.1** (кириллица
  в комментариях без BOM читается как ANSI) — обход: запускать `pnpm -F @matricarmz/electron-app dev`
  напрямую с `MATRICA_CDP_PORT` и `MATRICA_API_URL=http://127.0.0.1:3001` в env (без `.env.dev`
  клиент ушёл бы на ПРОД по умолчанию — `electron-app/src/main/index.ts:476`).
