## Текущая нитка

**Нет активной нитки.** Короткая сессия: владелец прислал стек падения сразу после выката v2026.728.1630 — нажатие «Импорт из 1С» роняло рендерер `React #310` (окно не открывалось вовсе, вся отгруженная в 1630 функциональность до кладовщика не доходила). Причина — `useMemo` объявлен после раннего `if (!props.open) return null` в `Stock1cImportDialog.tsx`. Хук поднят выше return ([#392](https://github.com/Valstan/MatricaRMZ/pull/392)), выкачено v2026.728.1659.

**Находка сессии важнее самого бага:** его обязан был поймать `react-hooks/rules-of-hooks` на `pnpm lint`, но **`eslint-plugin-react-hooks` в проекте не подключён вовсе** — линтер годами не знал ни одного React-правила и честно рапортовал «зелено». Гейт был зелёным не потому, что код чист, а потому что проверки в нём нет. Для контура автономии («подтверждение = зелёные гейты») это источник ложной санкции. Заведено 🔴-техдолгом в [`PENDING_FOLLOWUPS.md`](PENDING_FOLLOWUPS.md) §Мелочи, письмо в мозг — `mailbox/to-brain/2026-07-28-lint-gate-was-green-because-the-rule-was-never-installed.md`.
