Источник хитов — свой узкий main-поиск по локальной реплике `operations` на канале `workSheets:rows:search` (имя канала и есть гейт раздела «Производство»), а не чтение списка целиком. Строка хита — дословно заголовок вкладки из списка («Обкатка · 12345»), дата справа мелким. Серверный `/search` не тронут; запрос по номеру двигателя его этапов НЕ даёт — реквизитов двигателя в поисковом стоге нет намеренно, это защита от шума.
