## Текущая нитка

**Нет активной нитки.** Сессия закрыла жалобу владельца на импорт из 1С: заведение новых позиций падало `HTTP 400: Для создания укажите источник (directoryKind)` на первой же из 546 строк (импорт не проводился вовсе), и склады приходилось сопоставлять по одному за проход. Детали — [`COMPLETED.md`](COMPLETED.md) §Склад, эффект для завода — [`zavod/PROGRAM_EFFECTS.md`](zavod/PROGRAM_EFFECTS.md).

Коротко: контракт создания номенклатуры (`directoryKind`/`directoryRefId` + обязательные `groupId`/`unitId`/`templateId`) кодирован не в API, а в UI-хелпере `createNomenclatureRowForSource` — диалог импорта был **вторым** вызывающим и о контракте не знал. Теперь позиции 1С заводятся видами без карточки-источника (`component`/`material`/`consumable` по группе из `classify1cGroup`), справочники резолвятся **до** цикла (отказ — до начала проводки, а не на 546-й строке). Плюс заказ владельца: таблица сопоставления всех складов файла разом + «➕ Завести новый склад…» прямо в диалоге.
