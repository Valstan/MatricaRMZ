## Что не сработало

- Правка больших блоков в `App.tsx` через `edit`-инструмент по точному совпадению: блоки на 200+ строк не совпадали из-за пробелов/переводов строк — пришлось вырезать диапазоны строк через PowerShell (`$lines[0..N] + …`). Вывод: большие хирургические правки в этом файле делать по номерам строк скриптом, а не одним edit-блоком.
- `git commit -m '...'` с апострофом (weren't) внутри двойных кавычек в PowerShell → shell разбил аргумент и интерпретировал слова как pathspec. Вывод: commit-сообщения в PowerShell — только одинарными кавычками без апострофов или через heredoc/файл.
- `ssh matricarmz "psql -c \"...\""` — двойные кавычки в команде ломаются о PowerShell; рабочий паттерн — внешние двойные + внутренние одинарные (`psql -t -c 'SELECT …;'`).
