## Что не сработало

- **Кириллица через stdout консоли — мусор** (кодовая страница): `node -e "...console.log(кириллица)"`, `Get-Content`, `Out-File` на экране дают кракозябры, хотя файл цел. Текст результата — в файл через `fs.writeFileSync(..., 'utf8')` и читать файлом.
- **`corepack pnpm -r test` на малоядерной машине даёт случайный красный** — перегруз, а не регресс; гарантированный прогон `--workspace-concurrency=1`.
- **Разовый скрипт-разрезчик живёт в `%TEMP%`, а не в репо:** параллельная сессия с `git add -A` подхватила бы его как «новый инструмент». Проверка нарезки — тоже скриптом, ответ в файл, а не в консоль.
