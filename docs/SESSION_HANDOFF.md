## Что не сработало в этой нитке

- **Вопрос владельцу через UI не доехал** (инструмент вопросов у агента не рендерится) —
  задавал развилки, они зависли. Вывод: вопросы задавать текстом в теле PR / в ответе,
  а не инструментом.
- Смоук-скрипты на Windows: правка многострочных блоков через `Edit` не берёт (CRLF в
  файлах `.mjs`), а вставка строки с обратными кавычками внутрь инъектируемого JS ломает
  парсинг. Рабочий путь: правка через node-скрипт по `lines.splice` и `//`-комментарии
  без обратных кавычек в инъектируемой строке.
