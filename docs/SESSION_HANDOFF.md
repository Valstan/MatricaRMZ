- **`python -c "open(p,'w')…"` для правки файла** — при исключении внутри `.write()` (у меня — суррогатные пары в эмодзи) файл уже усечён до нуля. `shared/src/domain/releaseWelcome.ts` пришлось восстанавливать `git checkout --`. Для правок файлов брать Edit, а не «открыть на запись и собрать содержимое».
- **Перезапуск стенда сразу после правки renderer** — смоук ловил `timeout Runtime.evaluate`, пока Vite пересобирал. Перед прогоном убеждаться, что `/json/list` отдаёт цель, и только потом запускать.
