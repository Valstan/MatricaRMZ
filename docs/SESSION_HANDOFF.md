- **Алиасы пресетов отчётов** (`REPORT_PRESET_ALIASES` в `shared/src/domain/reports.ts`): старые id (`engines_list`, `engines_contracts_overview`) валидны навсегда, резолвятся `resolveReportPresetId()` на входе каждого обработчика — миграции пользовательских данных не было и не нужно.

## Что не сработало / грабли сессии

- **Печать из offscreen-окна Electron невозможна** — `Invalid printer settings`, хотя `printToPDF` из того же окна работает. Для `print()` окно поднимать как `{show:false}` **без** `offscreen`. Письмо брейну: `mailbox/to-brain/2026-08-20-offscreen-window-prints-nothing.md`.
- **Непечатаемые типы в HTML-печати** (`<img src="file://...docx">`) уходят пустыми листами без единой ошибки — фильтровать по MIME и перечислять строкой.
- **Стенд-клиент держит СТАРУЮ сборку main-процесса**: правки в `src/main` HMR не подхватывает — гасить `electron.exe` и поднимать заново (иначе смоук репортит починенный дефект как живой; поймано на печати).
- **Свёрнутые секции МЕНЮ прячут кнопки-действия из DOM** — `span.v2-menu-btn-label` нет, пока секция не развёрнута; и **незакрытый МЕНЮ-оверлей съедает trusted-ввод** (`Input.dispatchMouseEvent`), из-за чего драг-резайзеры «не тянутся» без ошибки. Записано в `docs/machines/PC40.md`.
- **Виртуализированный список двигателей** — строку нельзя найти перебором DOM, надо сузить поиском; список отчётов и карточка живут в разных панелях — селекторы скоупить на `[data-pane-active]`.
- `pnpm -r typecheck` даёт ложный TS2305 на `@matricarmz/shared` — гонять по пакетам; `typecheck` не покрывает тест-файлы electron-app (`typecheck:test`).
