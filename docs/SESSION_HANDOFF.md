## Что не сработало

- **`resolve.dedupe` + react вне Vite-root:** сборка renderer из чужого пакета падала `Rollup failed to resolve "react/jsx-runtime"` — dedupe резолвит из root'а конфига. Лечение: объявить `react`/`react-dom` зависимостями самого `android-app` (уже сделано).
- **Session-limit уронил половину workflow** (3 агента из 6) посреди разведки — `resumeFromRunId` после сброса лимита докатил из кэша без потерь. Паттерн повторяем.
- Стаб-мост: пропсы `on*` обязаны оставаться `undefined` (не Proxy-функциями) — иначе existence-guarded подписки renderer получают не-функцию; уже учтено в `android-app/src/bridge/shim.ts`.
