## Что не сработало

- **Трансформер карточек на регулярках** портит JSX: проп-строки теряли кавычки, `deleteLabel` превращался в `eleteLabel={Удалить…}` (битый код) ⇒ перевод сделан **AST-скриптом на TypeScript** (`ts.createSourceFile`), тела обработчиков переносятся как есть.
- **Ожидание смоука «Сброс» у карточки двигателя** было неверным: у двигателя нет обработчика `reset` ⇒ кнопки нет (по правилу каталога). Ожидаемый набор = **каталог ∩ домен ∩ обработчики карточки**, а не «всё, что есть в домене».
- **Sync-гейт на detached HEAD** — ложный красный (см. выше): worktree должен быть привязан к ветке с upstream.
- **Permission gate хоста** режет цепочки команд: мутирующие `gh` (`merge`, `edit`, `create`) — **отдельной командой**, без `;`; `rm -- <файл>` — **отдельной верхнеуровневой командой** с абсолютным путём (после `cd` блокируется политикой).
- **`git commit -m` с кириллицей из PowerShell** → манжит текст ⇒ писать сообщение в UTF-8 файл и `git commit -F`.
- **`node scripts/docs/rotate-completed-index.mjs --help`** — флага `--help` нет: скрипт **выполняет ротацию** (по умолчанию `--max 320`); индекс упирался в потолок (153 609 / 153 600) ⇒ сжатие `--max 240` дало 145 156 и место под строку релиза.
- **Ответы смоука читать через `node -e`, не `Get-Content`**: PowerShell 5.1 портит UTF-8 без BOM.
- **Сторож `globalModules.guard.test.ts` (escapeHtml) красный под нагрузкой:** сканирование репозитория занимает 2.9 с одиночно, а лимит теста — 5 с ⇒ в полном прогоне (341 файл в параллельных воркерах) таймаут. Одиночный прогон — 10/10 PASS, и **тот же красный воспроизводится на чистом дереве** ⇒ не регресс. Проверять так: stash правки → прогон → `stash pop`.
- **«Пусто.» от `prompts-section.mjs list` — это не сломанный канал:** у раздела может не быть живых промтов (все архивные) ⇒ смотреть `archived=1` и сырой JSON ответа.
