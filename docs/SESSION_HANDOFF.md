- **Слово «чужая» про подпись пугало операторов.** В панели подпись называлась «чужая (CN=Entrust…)», и это читалось как «программа чем-то заражена». В интерфейсе о доверии оценок быть не должно: теперь это факт — «нашим ключом MatricaRMZ — Касперский доверяет по подписи» / «другим ключом — в сборке для разработки это нормально».
