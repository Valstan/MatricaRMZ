## Контекст

- **Серенькие — одно правило.** Уволен / декрет / на лечении → ребёнок не участвует в отборах и уходит из напоминалок. Флага на ребёнке нет намеренно: разъехался бы с кадровым статусом. Мировая практика совпадает (Frappe HR шлёт напоминания только Active).
- **Реплика — pull-only**, запись идёт серверной дверью; клиентский push закрыт владением `server` (бэкастоп). Экраны обязаны перечитываться по синку — `useLiveDataRefresh` (смоук это поймал).
- **ПДн детей**: дата рождения, возраст и признаки — чувствительные данные. В карточке и в отчёте по умолчанию; в отчёты не тащатся без запроса, возраст публично не разглашается (SHRM).
- **Машина PC79:** dev-стенд — backend на **3011** (3001 занят посторонним процессом), CDP 9222, PostgreSQL `matricarmz_dev` (postgres/postgres, пароль в `%USERPROFILE%\pg-local-credentials.json`). Перед Electron — ABI `better-sqlite3` из `.verifier-electron/abi-backup/electron-*`, после — Node-ABI (иначе падают тесты); своппер — `.verifier-electron/swap-abi-2026.ps1`.
