## Что не сработало

- **Правка EAV напрямую в SQL не годится:** «миграция» владельца исполнена переносом через серверную дверь — SQL обновил бы только сервер, а парк увидел бы старое значение («3» вместо «ДС 3») ещё годами.
- **Два скрипта резали одно поле по-разному** (`backfill-section-tokens` и `canonicalize-section-keys`): первый понимал голое число как номер ДС, второй — как основной договор. Правило сведено в `shared`, сторож держит.
- **Patch-id не годится для сквош-мержей:** коммит, влитый сквошем, не совпадает по patch-id с исходным — сверка чужих веток делается по наличию файлов в `main`, а не по patch-id.
- **Счёт на проде разошёлся с данными 12.11** (ожидали 55 + 8, пришло 54 + 6): данные живые, часть строк за это время поправили вручную или удалили. Поэтому сверять надо по dry-run, а не по памяти.
