## Что не сработало

- **Клиентский гард «pull не трогает `pending`»** → при LWW-отказе сервера локальная строка навсегда остаётся `pending`: расхождение вместо потери, и оператор видит значение, которого нет у парка. Нужен серверный сигнал `skipped` (`PENDING_FOLLOWUPS`).
- **Колонка `mirror_derived`** (флаг «строка порождена зеркалом») → признак уже вычислим: у зеркальной строки `last_server_seq IS NULL`. Миграция ради колонки не нужна.
- **Штамп `updated_at` из `max(EAV, entities)`** → лечит только первый сейв, а тихий отказ LWW оставляет как класс (и прячет его от счётчиков).
- **Многострочный SQL через here-string в `psql -f -`** на этой машине доезжает битым — писать файлом и `scp` (запись в `docs/machines/PC79.md`).
- **`electron-builder install-app-deps` без сноса `.forge-meta`** → отчитывается `preparing/finished`, бинарь не пересобирает, и клиент **не открывает окно вовсе** (CDP `/json/list` пуст, в консоли тишина после `DevTools listening`); настоящая причина — `NODE_MODULE_VERSION` — только в `%APPDATA%\@matricarmz\electron-app-cdp-9222\matricarmz.log`. Рецепт — `GOTCHAS` **M2**.
- **Слияние завод-контура с dev-контуром в одну кучу** → отвергнуто: чтение не появляется от переноса, а холодный старт дорожает на объём журнала эффектов (389 КБ). Лечится триггером (линза), а не местом.
- **`git worktree remove` второго дерева на Windows** → каталог удерживает процесс закрытой сессии; пришлось убить два `node`/`tsx` процесса из этого дерева и снять metadata через `git worktree prune`. Пустая папка осталась до перезапуска приложения — силой не удалять.
