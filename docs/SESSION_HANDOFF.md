## Что не сработало

- **Правка `.npmrc` заставила pnpm пересобрать `node_modules`, и тесты Electron упали с «Electron failed to install correctly»** — гонка с переустановкой, не дефект кода: после того как установка дописала `dist`, те же файлы прошли зелёными. Ставить на PC79 pnpm-инсталлы и тесты Electron нельзя параллельно.
- **Ветка от устаревшего локального `main` дала конфликтующий PR, и GitHub молча не запустил ни одной проверки** (`gh pr checks` — «no checks reported», `workflow_dispatch` на той же ветке работал). Лечится `git rebase --onto origin/main …` + `push --force-with-lease`; записано в профиль машины.
- **Артефакты релиза едва не уронили манифест:** команда `mv … ; mv … ; ls …` с непарной кавычкой уехала на бокс исковерканной — часть файлов не переехала, а `latest.json` остался указывать на перемещённый `3.103.0.exe` (клиент получил бы 404). Вышло: вернуть старый файл из `.trash-`, разложить артефакты заново **короткими командами в одинарных кавычках PowerShell**, и только потом смотреть, что манифест сошёлся. Правило для прод-путей: одна удалённая команда — одна строка, без цепочек с `;` и без смешанных кавычек.
