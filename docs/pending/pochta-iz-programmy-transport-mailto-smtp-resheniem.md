# 🟡 Почта из программы: транспорт `mailto:`, SMTP — решением владельца 🗓 since:2026-10-21

**Раздел:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) → «⏳ Ждёт внешнего окна / события»

Модуль отправки отгружен (#1414): «Почта» рядом с печатью/Word/Excel во всех списках и в
печатных формах карточек. Устроено без своего почтового сервера — у завода его нет:

- письмо открывается в почтовом клиенте машины (`mailto:`), тема и текст предзаполнены;
- полный текст **всегда** копируется в буфер (в `mailto:` он влезает не целиком — 1800 символов);
- файл вложения лежит в `%TEMP%\matrica-mail\` и кладётся рядом кнопкой «Показать файл в папке» —
  прикрепляется в клиенте одним движением (`mailto:` вложений не умеет).

Если на практике прикрепление окажется лишним шагом — решение владельца: свой SMTP
(пароль на каждой машине или общий сервер завода). Тогда модуль меняет только транспорт,
диалог и точки подключения остаются.
