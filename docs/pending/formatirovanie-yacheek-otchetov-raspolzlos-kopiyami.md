# Форматирование ячеек отчётов расползлось копиями 🗓 since:2026-08-22

**Раздел:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) → «🟡 Техдолг»

Закрыто по существу 2026-08-22 (заголовок группы «Моих отчётах» и живой отчёт «Рабочего стола»), остаётся правило на будущее: **копий форматирования в проекте было три, и каждая новая рождалась с одной и той же бедой** — не зная типа колонки, `String(value)` печатает дату миллисекундами.
