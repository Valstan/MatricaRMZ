Нитка закрыта ([#424](https://github.com/Valstan/MatricaRMZ/pull/424)–[#427](https://github.com/Valstan/MatricaRMZ/pull/427)), открыто по краям:

1. 🔴 **Два ретро-скрипта контрактов ждут обновления парка — строгий порядок.** Оба идемпотентны, пишут через `setEntityAttribute` (доезжают клиентам sync'ом), dry-run по умолчанию.
   - **Предусловия (все):** (а) парк обновился до **≥ v2026.808.1830** — версия без фикса #502, открыв карточку, пересинкает слоты СТАРОЙ логикой и перепортит результат; (б) PC20 переустановлен вручную (см. §Застрявшее автообновление); (в) web-admin уже read-only по контрактам ([#503](https://github.com/Valstan/MatricaRMZ/pull/503), на проде — легаси-редактор писал конфликтующие скаляры).
   - **Порядок:** `contracts:canonicalize-section-keys` (dry-run → `:apply`) → затем `contracts:resync-slots` (dry-run → показать владельцу отчёт расхождений → `:apply`) → контрольный dry-run через 2-3 дня (пустой diff = парк чист).
   - **canonicalize-section-keys** ([#439](https://github.com/Valstan/MatricaRMZ/pull/439), план [`plans/contract-section-stable-key-2026-08.md`](plans/contract-section-stable-key-2026-08.md)): ключ основной секции → стабильный `primary`. Замер до правки: 183 привязки, 226 слотов, 52 платежа на 31 790 777 ₽, осиротевших — ноль.
   - **resync-slots** ([#506](https://github.com/Valstan/MatricaRMZ/pull/506)): досоздаёт слоты до СУММЫ строк марки, сеет позиционные цены в пустые, рассаживает двигатели по слотам своих марок; печатает отчёт расхождений (марка вне плана / двигателей больше плана / без секции) — эти данные **не трогает**, решение по ним за владельцем.
2. 🟡 **`appliedHiddenFields` наряда эфемерны** (`useState`, `WorkOrderDetailsPage`): скрытые шаблоном «Цена»/«Сумма» возвращаются после переоткрытия карточки, в payload не сохраняются. Для «формы наряда без зарплатных данных» этого мало.
3. 🟡 **Слоты сверх плана нигде не подсвечены отдельно** (R5-PR2 плана `grand-refactor-2026-08`, **S**). Заголовок группы марки показывает «занято из всего», и слот сверх плана просто увеличивает знаменатель. Ретро-скрипт `contracts:resync-slots` уже умеет считать расхождения (марка вне плана / двигателей больше плана / без секции) — осталось показать их в карточке контракта постоянной пометкой, а не только в консольном отчёте.
4. 🟢 **Автоподстановка подписантов простой формы наряда** (нормировщик / кадры / ОТК / мастер цеха) по должности — сейчас печатаются только роли и пустые линии под живую подпись. Готовые группы поиска есть в `resolveWorkOrderSignatureDecryptions` и `RepairChecklistPanel`.
