# 🟡 Утиль по детали: выключить страховку по подстроке «картер» 🗓 since:2026-11-02

**Ссылка:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) — индекс открытых задач. План — [scrap-criterion-parts-2026-11](../plans/_archive/scrap-criterion-parts-2026-11.md).

- **Симптом:** картер уводит двигатель в утиль по вхождению слова «картер» в имени строки акта — это старое правило D-#9, оставленное страховкой (`LEGACY_CRANKCASE_FALLBACK` в `shared/src/domain/scrapCriterion.ts`). С 3.100.0 картерные детали попадают в набор критериев автоматически (наполнение при первом чтении набора, `seedScrapCriterionParts`), то есть работают по общему правилу — по id детали.
- **Что нужно:** когда владелец убедится на парке, что набор критериев покрывает все картерные строки актов (в том числе строки без id и с другим названием), страховку выключают одной константой: `LEGACY_CRANKCASE_FALLBACK = false`. После этого «картер» в утиль уводит только помеченная деталь — как и любая другая.
- **Чего не делать:** не выключать страховку до прогона по боевым актам — часть картерных строк в старых актах заведена без id детали и с названием, которого нет в справочнике; такие строки поймает только подстрока.
