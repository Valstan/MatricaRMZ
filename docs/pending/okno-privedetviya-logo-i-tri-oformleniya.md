# ⏳ Окно приветствия: логотип от владельца и приёмка трёх оформлений глазами 🗓 since:2026-11-26

**Раздел:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) → «⏳ Ждёт внешнего окна / события»

Промт КАРМАНА **#162** («Окно приветствия: короткие новинки и три анимации») **сделан кодом**: три оформления (сияние / вьюнки с деталями / снег с сугробом и логотипом), компактные новинки, крупный кегль, текст больше не едет сам. Осталось за владельцем — три вещи.

## 1. Логотип (ждём файл от владельца)

Владелец просит дать нужный логотип сам. Файла нет ⇒ окно рисует **явную заглушку** («ЛОГОТИП» в пунктирной рамке): она не выдаётся за логотип и окно не ломает.

**Как подхватить без правки кода:** положить файл `welcome-logo.png` (или `.svg`, прозрачный фон) в `%APPDATA%\MatricaRMZ\` на машину парка. Главный процесс (`electron-app/src/main/services/releaseWelcomeLogo.ts`) ищет файл и отдаёт его окну картинкой (`data:`-URL) — при следующем обновлении клиент подхватит его сам. Для сборки — `resources/welcome-logo.png` рядом с программой.

**Что нужно от владельца:** вектор (SVG) или прозрачный PNG в большом разрешении — иначе логотип мылится при наезде камерой в снежном оформлении.

## 2. Приёмка глазами: три оформления

«Красиво» — вкус, тест не решает. Нужен просмотр на живом клиенте всех трёх вариантов: у одной машины своё оформление, у другой — своё (выбор считает главный процесс по `clientId` + номеру релиза, поэтому у разных клиентов разное; в пределах одного обновления — одно и то же).

## 3. Переписывать ли прошлые записи под компакт (решение владельца)

Новое правило (короткая фраза, жирный зачин, ≤ 160 знаков) действует **с 3.148.0** (`RELEASE_WELCOME_COMPACT_FROM`); прошлые записи `RELEASE_WELCOME_HISTORY` **не переписаны** — закрытые записи не трогаем. Из-за этого в окно попадают длинные строки релизов за два дня: окно показывает всё сразу и само ничего не двигает, но если строк больше, чем влезло, остаётся **прокрутка** (запасной путь).

**Решение владельца:** (а) оставить как есть — прокрутка запасным путём; (б) переписать новинки последних релизов под компакт вручную.
