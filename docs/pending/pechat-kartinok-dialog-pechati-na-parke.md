# 🟡 Печать картинок: проверить диалог печати Chromium на живой машине парка 🗓 since:2026-11-26

**Раздел:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) → «🟡 Техдолг и отложенное»

## Что это

Живая диагностика печати (промт КАРМАНА #159, PC79, 26.11.2026) показала: **на этой машине
диалог печати Chromium не работает ни с одним принтером** — `webContents.print()` возвращает
«Invalid printer settings» (принтеров в системе пять, все в норме, спуллер работает, Chromium
их видит). Печать картинок поэтому уходит в **системный мастер печати фотографий**, и оператор
видит в сообщении, почему так вышло.

**Вопрос к владельцу: работает ли диалог печати Chromium на живой машине парка** (там, где
печать из карточки работала). От этого зависит, что увидит оператор в поле «Поиск по файлам»:

- **диалог работает** → кнопка «Отправить на печать» открывает обычный диалог печати (принтер,
  масштаб, ориентация), всё как задумано;
- **не работает и там** → «Отправить на печать» всегда уводит в мастер печати фотографий.
  Тогда стоит подумать, не убрать ли вторую кнопку («Через мастер печати фотографий») — иначе
  у оператора две кнопки, которые делают одно и то же.

## Что уже сделано (26.11.2026, PR по промту #159)

- Общий модуль печати картинок `electron-app/src/main/services/photoPrint.ts` (`printPhotos`):
  проверка принтера (нет принтера → «Принтер не найден: в системе нет ни одного принтера»),
  диалог печати, при «Invalid printer settings» — увод в системный мастер **с внятной причиной**
  в сообщении оператору.
- Выдача «Поиска по файлам» печатает тем же кодом, что и печать вложений из карточки.
- Мастер печати фотографий починен: окно больше не умирает вместе с процессом, который его
  открыл; помощник мастера больше не падает с «Value does not fall within the expected range».
  Подробности — [`M235`](../gotchas/M235.md).
- Пункт «Через мастер печати» в панели вложений карточки открыт (26.11.2026, PR #2090): новая дверь
  `files:printWizard` копирует серверные вложения в папку оператора и отдаёт копии тому же общему
  шагу `printPhotos` (`mode: 'os'`); пункт прячется сам, если мастера на машине нет
  (способность спрашивается у main, правило промта #158).

## Как проверить (1 минута на машине)

1. «Поиск по файлам» → отметить снимки → **«Отправить на печать»**.
2. **Открылся диалог печати** (список принтеров, копии, ориентация) → печать работает как надо.
3. **Открылось окно «Печать изображений»** (системный мастер) → на этой машине диалог Chromium
   не работает; сообщение над кнопкой объясняет причину.
4. Если принтера нет вообще → оператор видит «Принтер не найден: в системе нет ни одного принтера».

## Что ещё открыто по этой нитке

- **«Открыть много файлов в одном окне мастера»** — отдельная задача: на PC79 глагол «Печать» у
  множественного выделения мастер не открывает (оболочка печатает по одному файлу).
- **Полевая приёмка глазами владельца** — мастер из вложений карточки открылся и напечатал
  набор снимков одним окном.
