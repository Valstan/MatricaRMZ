37. **Поиск по файлам: поиск по папкам по названию, крупные превью картинок, печать отобранного** (промты **#88 и #89**, 24.11.2026) — **сделано кодом** (PR **#1988**, ветка `feat/file-search-folder-scan-2026-11`): в модуле «Поиск по файлам» появился режим **«по названию в папках»** — оператор добавляет папки с фотографиями двигателей, вводит номер двигателя и получает папки, в названии которых он есть («Э06АТ0889»), вместе с крупными превью их содержимого; отобранные галочками картинки уходят на печать через системный диалог (оператор правит размер и отправляет сам). Поиск по содержимому файлов не тронут. Границы: renderer не читает диск (картинка получает `id` от main, путь не уходит), папки для поиска берутся из машинно-локального хранилища (не из аргументов renderer), модуль только читает, потолки на обход и находки. **Осталось за владельцем:** развилка «Microsoft Picture Manager» снята — делаются **оба** пути печати (системный диалог Chromium — все картинки сразу; **системный мастер печати фотографий** `photowiz.dll` — одно окно на картинку, размер и раскладку правит оператор; из Electron глагол не вызвать ⇒ `Start-Process -FilePath '<файл>' -Verb print` из PowerShell) — **PR #1989** (`0d1bad57`), влит; кнопка мастера прячется сама, если мастера на машине нет (`fileSearch:printCapabilities`). **Осталось за владельцем:** глубина обхода (по умолчанию 3 уровня) и **проверка мастера печати на машине парка** (`reg query "HKCR\SystemFileAssociations\image\shell\print"`); **живая приёмка** — смоук не гонялся (локальный PostgreSQL на PC79 не поднимается) ⇒ за владельцем. План — [`file-search-folders-2026-11.md`](../plans/file-search-folders-2026-11.md).
