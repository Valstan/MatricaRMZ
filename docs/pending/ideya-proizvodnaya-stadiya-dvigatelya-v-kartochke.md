# Идея: производная «стадия» двигателя в карточке (разборка/дефектовка/сборка) 🗓 since:2026-07-29 🟢

**Раздел:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) → «🟢 Крупные фичи / решения владельца»

Вопрос владельца 29.07: «Начат ремонт» ставится и при разборке, и при отправке на сборку — не двусмысленно ли. Разбор: это **этап** («двигатель в работе на заводе», 40% прогресса), не операция; раскалывать флаг на два нельзя — на нём прогресс контрактов, отчёты, прогноз, взаимоисключение статусов (`shared/domain/contract.ts` `applyStatusFlagChange`). Если захочется детализации — показать в карточке двигателя **производную** строку «стадия: разборка / дефектовка / сборка», выведенную из существующих операций (акты дефектовки, assembly-наряды, `repairIssued`), ничего не меняя в учёте. Решение за владельцем; делать только если попросит.
