# 🟡 Индекс грабель у потолка: новая грабля не влезает без сокращения формулировок 🗓 since:2026-11-20

**Раздел:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) → «🟡 Техдолг и отложенное»
**Нить:** закрытие сессии 20.11.2026 — всплыло при попытке завести граблю про сторож форм памяти.

## Суть

`docs/GOTCHAS.md` — индекс грабель (220 записей на 20.11.2026) — упёрся в потолок **50 КБ**,
который держит сторож `docsMemoryLayout.guard.test.ts` (`INDEX_LIMIT_BYTES = 50 * 1024`).
Запас после сжатия шапки — **107 байт**: новая грабля (строка индекса ~180 байт с кириллицей)
не влезает.

Ротации нет и быть не может: сторож требует, чтобы **каждый** файл в `docs/gotchas/` имел
строку в индексе («каждый файл записи попал в индекс»). Поэтому единственный способ — сокращать
формулировки существующих строк, как и сказано в шапке самого индекса: «упёрлись — значит пора
сокращать формулировки, а не поднимать потолок».

## Что делать

- **Разово:** сжать 5–8 самых длинных строк индекса (медиана 210 байт, максимум ~430) —
  оставить симптом-якорь и признак, детали лечения отправить в сам файл грабли.
- **Системно (на решение владельца):** завести ротацию индекса по возрасту — как у
  `COMPLETED.md` (`docs/_archive/COMPLETED-3x-*.md`), с поправкой сторожа: архивные записи
  не обязаны иметь файл в `docs/gotchas/` (или файлы переезжают в архив целиком).

Пока этого не сделано, **новая грабля не заводится**: правило уходит в канон (`AGENTS.md` →
§Autonomy, список гейтов), а не в индекс грабель.

## Лечение в этой сессии

Правило «правки `docs/` — **до** прогона гейтов» (сторож форм памяти читает документы из
рабочего дерева, а не из коммита, и ловит форму строк `COMPLETED.md` — потолок 900 байт на
строку) записано в `AGENTS.md` §Autonomy. Грабля как таковая не заведена: индекс не вмещает.

**23.11.2026 (закрытие сессии по печатным формам) — разовое сжатие сделано:** десять самых
длинных строк индекса сжаты до симптома-якоря (M104, M105, M110, M112, M114, M145, M148,
M181, M212, M213) — индекс **50 942 → 49 666 байт**, запас снова ~1.5 КБ. Две новые грабли
(M223 — маркер конфликта в коде, M224 — ключ React с редактируемым полем) в индекс влезли.
Системная ротация индекса по возрасту — **по-прежнему решение владельца**.

**26.11.2026 (промт КАРМАНА #144, полоса 1) — грабля заведена, правило подтверждено живьём.**
Индекс снова упёрся: **51 198 из 51 200 байт** (запас 2 байта) — новая грабля в индекс не
влезала, а гейт требует строку индекса за каждым `gotchas/M<N>.md`. Заведена грабля
**M239** («индекс грабель у потолка»: файл `docs/gotchas/M239.md` + строка индекса), под её
размер сжаты три самые длинные строки (M116, M167, M187) — симптом-якорь остался в индексе,
детали лечения лежат в файлах грабель. Состояние после правки: `docs/GOTCHAS.md` —
**51 077 из 51 200** (запас 123 байта), `docs/COMPLETED.md` — 134 366 из 153 600 (ротация
прошла, запас большой). **Системная ротация индекса по возрасту — по-прежнему решение
владельца**; правило на каждый день: **упёрлись — сокращаем формулировки, а не поднимаем
потолок.**
