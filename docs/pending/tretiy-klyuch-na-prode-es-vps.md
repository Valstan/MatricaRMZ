# 🟡 На проде третий ключ — с бокса es-vps: держать или снимать 🗓 since:2026-11-27

**Откуда пункт.** Владелец 27.11.2026 решил: ротировать ключ своей машины и снять
«осиротевший ключ упразднённой машины PC40». Проверка показала: **второй половины
предпосылки уже нет** — осиротевший ключ PC40 на проде **не висит** (файл правили в
октябре, и тогда же добавился ключ с другого бокса). Сам ключ PC79 ротирован в этом
же ходе. Осталась одна настоящая развилка: **что делать с третьим ключом**.

## Фактический состав (сверено 27.11.2026 по отпечаткам, не по комментариям)

| Ключ | Владелец | Состояние |
|---|---|---|
| RMZ4VAL | другая машина (не наша) | просрочен по 90-дневному циклу — ротирует его своя машина, мы не трогаем |
| PC79 (выпущен 2026-08-28) | наша машина | **ротирован 27.11.2026**: новый выпущен, старый снят, бэкап `authorized_keys` рядом с файлом |
| третий ключ | **бокс es-vps** | живой: приватной половины на PC79 нет, ключ приходит с соседнего бокса |

Раньше в этом месте стоял осиротевший ключ PC40 — **он уже снят** (сентябрь–октябрь).
Пункт о нём («на проде висит ключ упразднённой машины PC40») закрыт как **устаревший**:
фактического факта, который он описывал, больше нет.

## Развилка

Третий ключ — **тот же приватный ключ, что ходит на бокс es-vps**: одна пара ключей
даёт доступ на два сервера. Это не дыра (подобрать ed25519 нельзя, вход по паролю
запрещён), но это **постоянный грант на прод с чужой машины**.

Варианты владельца:

- **держать** — доступ es-vps на прод сохраняется (страховка: если наша машина
  выпадет, есть второй вход). Цена — прод доступен с чужого бокса;
- **снять** — на прод остаются только два ключа (RMZ4VAL и наш PC79). Тогда вход на
  прод — только с этой машины: страховки нет.

## Что уже сделано (в этом же ходе, 27.11.2026)

- Новый ключ PC79 выпущен (ed25519, без парольной фразы) и добавлен в агент;
- новый ключ положен на прод **рядом** со старым → доступ не рвался ни на секунду;
- вход новым ключом проверен, старый снят из `authorized_keys` по **телу ключа**
  (не по комментарию), бэкап файла сделан рядом;
- старый ключ отклонён сервером — проверено живьём;
- `~/.ssh/config` переключён на новый ключ.

**Отпечатки, имена файлов ключей и комментарии в репозиторий не пишем** — сверять
на месте: `ssh-keygen -lf ~/.ssh/authorized_keys`.
