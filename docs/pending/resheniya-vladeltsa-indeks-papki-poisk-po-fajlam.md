# 🟡 Поиск по папкам: карта индекса дерева — шесть развилок владельца (промт #180) 🗓 since:2026-11-27

🗓 since:2026-11-27 · нитка «Поиск по папкам: карта индекса дерева и фоновая индексация»
(промт КАРМАНА **#180**; план — [`../plans/folder-search-index-2026-11.md`](../plans/folder-search-index-2026-11.md);
замер с числами — [`../evidence/folder-search-180/README.md`](../evidence/folder-search-180/README.md))

**Что сделано кодом:** причина медленного обхода названа и измерена (метаданные по
каждому файлу съедали 90 % времени обхода; обход шёл строго по одной папке; индекса не
было вовсе — версия «переполнен индекс» отвергнута). Обход идёт с ограниченным
параллелизмом, лишние запросы метаданных убраны, дерево папки индексируется **в фоне
отдельным процессом**, следующий поиск по той же папке отвечает по карте. На экране
видно прогресс индексации; если индексация не завершилась за разумный срок — в журнале
запись «индексирование папки не завершилось», в интерфейсе предупреждение, процесс
остановлен.

## Развилки, которые отдал промт — закрыты по умолчанию, ждут владельца

| # | Развилка | По умолчанию (что сделано) | Чем может быть иначе |
|---|---|---|---|
| 1 | **Куда складывать карту индекса** | машинно-локальное хранилище клиента (`<userData>/folder-index/`): модуль только читает, на сетевой папке прав на запись может не быть | отдельный файл рядом с папкой (карта переживёт переустановку и попадёт на другую машину — но нужны права на запись) |
| 2 | **Правило устаревания карты** | карта протухает, если папка менялась позже индекса → идём по диску; сверху «карте не старше суток» | иное правило (например, «свежая карта важнее свежести файла») |
| 3 | **Строить ли карту автоматически** | да, при добавлении папки, в фоне; плюс кнопка «Построить индекс» | только по явному запросу оператора (построение стоит как один полный обход) |
| 4 | **Куда «сообщить разработчику», что индексация не завершилась** | журнал клиента (`matricarmz.log`) + предупреждение в интерфейсе на экране поиска по папкам | файл на диске для отправки, уведомление в другом месте программы |
| 5 | **Потолок и приоритет фонового процесса** | потолок 15 мин на папку (потом процесс останавливается), пауза 30 мс между чтениями папок | режим «тише» при полной загрузке машины; другие потолки |
| 6 | **Потолки обхода при быстром обходе** | как были: глубина 3, 5000 папок, 20 000 файлов; при срабатывании — замечание оператору в примечаниях и в полосе | другие значения |

## Что осталось открытым (ждёт владельца)

1. **Полевая приёмка глазами оператора.** Замер сделан на локальном SSD; на боевой
   сетевой папке оператора его нужно прогнать тем же инструментом
   (`node scripts/folder-scan-benchmark.mjs "<папка>"`), чтобы увидеть разрыв в его
   сети. И проверить глазами: полоса индексации на экране «Папки с фотографиями»,
   предупреждение при зависании, второй поиск по той же папке (отвечает по карте).
2. **Ответы по шести развилкам выше** — каждая меняет одно место.
