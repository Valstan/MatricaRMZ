# 🟡 Массовое изменение в приёме: произвольные свойства карточки 🗓 since:2026-11-02

**Ссылка:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) — индекс открытых задач.

- **Симптом:** массовое изменение в приёме двигателей списком (3.100.0) раскладывает по списку только поля пачки: марку, контрагента, договор, входной контроль ОТК, дату дефектовки, внутренний номер. Произвольные свойства карточки двигателя (свои поля из «Карточки детали») в раскладку не попадают: приём их не пишет.
- **Что нужно:** расширить набор раскладываемых свойств за счёт произвольных атрибутов карточки — тогда в пачке можно массово проставить, например, признак или номер партии. Требует расширения приёма (`engineBulkIntakeService`): писать произвольные атрибуты карточки в общую дверь EAV, с проверкой прав и синхронизации.
- **Почему не сделано сразу:** произвольные атрибуты карточки — это общий канал EAV, а приём сейчас пишет только типовые поля карточки (`engine_brand`, `customer_id`, `contract_id`, даты, номера). Расширение требует отдельного обсуждения прав и состава полей, а не «ещё одну галочку».
