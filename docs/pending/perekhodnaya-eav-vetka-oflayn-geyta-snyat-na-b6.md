# 🟡 Переходная EAV-ветка офлайн-гейта — снять на B6 🗓 since:2026-08-30

**Раздел:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) → «🟡 Техдолг и отложенное»

**R4b задеплоен релизом 3.58.0 (2026-10-02), условие снятия прежнее — B6:** ветка живёт пока в парке есть сборки без реплики.

Офлайн-гейт разделов (`employeeService.replicaMembershipRows`) читает реплику `users`/`user_section_access`, **а пока она на машине пуста — по-прежнему EAV**. Ветка нужна ровно на время, пока в парке есть сборки без реплики: без неё на такой машине membership стал бы null, гейт вернул бы true на каждый канал и молча превратился бы в декорацию.

**Снять вместе с EAV-путями на этапе B6** (вывод EAV из синка). Раньше нельзя — в парке останутся старые сборки. Позже — значит навсегда: у переходных веток нет естественного момента смерти, если его не назначить.

Признак, что снимать пора: в парке нет клиентов ниже релиза, отгрузившего реплику (проверяется по `client_settings.last_version`).
