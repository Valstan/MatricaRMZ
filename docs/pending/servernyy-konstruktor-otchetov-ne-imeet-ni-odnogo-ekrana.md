# Серверный конструктор отчётов не имеет ни одного экрана 🗓 since:2026-08-20

**Раздел:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) → «🟡 Техдолг»

`backend-api/src/routes/reports.ts` (`/reports/builder/meta|preview|export`) — полноценный каталог таблиц с русскими заголовками, но `reportsBuilder` не вызывается **ни из одного `.tsx`** (проверено грепом по `electron-app/src` и `web-admin/src`). При этом внутри те же болезни, что чинит этап A плана: колонки с русскими заголовками поверх UUID, коды enum без подписей, а `renderHtml` и выгрузка в xlsx игнорируют тип колонки — даты уходят в печать числом вроде `1755590400000`.

Чинить сейчас незачем — пользователей нет. Решить: доделать UI или выпилить маршруты.
