# Аварийный режим времени «по интернету + часовой пояс» 🗓 since:2026-10-21

**Раздел:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) → «🟡 Техдолг»

Сейчас расхождение часов только **предупреждается** плашкой (порог 2 минуты, сверка по
заголовку `Date` нашего сервера). Автоматически чинить время без прав администратора нельзя.
Режим «считать время как мировое + часовой пояс Windows» — отдельный шаг: касаться он должен
только новых записей, жить до перезапуска программы и висеть с явной красной плашкой
«работаем по расчётному времени». Глобально подменять `Date.now()` нельзя — разъедутся
сортировки и ключи. План: `docs/plans/drafts-clock-restart-2026-10.md` §2.
