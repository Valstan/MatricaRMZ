# 🟡 Размерный ряд СИЗ для РМЗ: базовый может не подойти 🗓 since:2026-11-03

**Ссылка:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) — индекс открытых задач. План — [ppe-order-norms-and-personal-card-2026-11](../plans/ppe-order-norms-and-personal-card-2026-11.md).

- **Что сейчас:** номенклатура приказа заведена по базовому размерному ряду — одежда 44–56, обувь 38–46, перчатки S–XXL, СИЗ ОД 54–62. Норма указывает на **базовую** позицию, а размер сотрудника подставляется при выдаче (дерево «база → размеры»).
- **Риск:** у РМЗ свой ряд (своя специфика кабельных перчаток, свой размер обуви по СБЦ, свой рост). Если ряд не совпадает, кладовщик не найдёт нужный размер для конкретной позиции.
- **Что нужно:** подтвердить у кладовщика фактические размеры по каждой группе СИЗ на РМЗ и сверить с заведёнными 333 позициями номенклатуры. Расхождения правятся в справочнике номенклатуры (не в приказе и не миграцией) — приказ задаёт норму, а не размерный ряд завода.
- **Чего не делать:** не плодить размеры в нормах приказа — 191 строка норм превратилась бы в тысячи строк (см. решение 1 в плане нитки).
