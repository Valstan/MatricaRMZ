# Платежи по двигателям — обкатка бухгалтером 🗓 since:2026-07-29 🟢

**Раздел:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) → «🟢 Крупные фичи / решения владельца»

Фича целиком на проде с v2026.729.1041 (PR [#401](https://github.com/Valstan/MatricaRMZ/pull/401)–[#408](https://github.com/Valstan/MatricaRMZ/pull/408), план [`plans/engine-payments-2026-07.md`](plans/engine-payments-2026-07.md); сквозной CDP-смоук PASS). Открыто по отзыву:
1. **Приёмка бухгалтером на реальном контракте:** вкладка «Платежи» двигателя, слоты + «Распределить аванс», подсветка срока ремонта, «Горящие» в списке, отчёты. Особо проверить пары «деньги пришли раньше двигателей» и наоборот. **С v3.45.0 отсчёт идёт от даты поступления двигателя на завод, а не от аванса, и у двигателей без этой даты подсветки нет вовсе** — при приёмке смотреть заодно, сколько таких (фасет «Срок ремонта», значение «без даты поступления»).
2. **Текст служебной записки** — заготовка («Прошу дать указание о запуске в ремонт…»); финальную формулировку дать владельцу, шапку/реквизиты дописать по образцу заводского документа.
   _(Правка платежей прямо в контракте закрыта 31.07 — единым списком, [#426](https://github.com/Valstan/MatricaRMZ/pull/426).)_
3. **Приёмка бухгалтером надстройки 31.07:** галочки по маркам + «Разнести аванс» на отмеченные, колонки платежей справа от двигателя, блок «Двигатели без секции». Особо проверить контракт с ДС: слот подбирается по марке в порядке «основной договор → ДС», и это поведение вживую не смотрели.
