# ⏳ Панель фильтров: спойлера нет, плашки выбранных плавающие — приёмка на парке (PR #1688) 🗓 since:2026-11-12

**Раздел:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) → «⏳ Ждёт внешнего окна / события»

**Заказ владельца 12.11.2026:** фильтры стали компактные и удобные — спойлер «Ещё N» можно
убрать и показывать все кнопки сразу; ширина выбранных плашек не должна раздвигать кнопки-родители;
плашки выбранных должны висеть независимыми «плавающими» плашками, стремиться в одну строку и быть
ближе к центру кнопки своего родителя (наползать на соседа — можно).

**Что сделано (код, PR #1688):** общий компонент `electron-app/src/renderer/src/ui/components/FacetFilter.tsx`
— правка одна, меняет вид панели на **восьми** экранах (списки двигателей, контрактов, сотрудников,
СИЗ, этапов ремонта + отчёты «Двигатели», «Сейчас на заводе», «Этапы ремонта»):

- **спойлера «Ещё N ▾» больше нет** — видны все ступени сразу; рейтинг остался, но задаёт **порядок**
  (частые слева), а не состав;
- **плашки выбранных вынесены из потока колонки** в отдельный плавающий слой
  (`absolute` + `translateX(-50%)` + `nowrap`): висят под своей кнопкой, прижаты к её центру,
  всегда в одну строку, могут наползать на соседа;
- ширину колонки задаёт **только кнопка** (у колонки больше нет `maxWidth`), поэтому длинное название
  выбранного значения больше не раздвигает соседние кнопки; место под строку плашек резервируется
  **высотой**, иначе следующий ряд кнопок наполз бы на плашки.

**Гейты:** typecheck, typecheck:test, lint, `pnpm -r --workspace-concurrency=1 test` — зелёные;
CDP-смоук `cdp-facet-panel.mjs` — **23/23 PASS** на живом стенде (колонка по ширине = кнопке
84 = 84, плашка шире кнопки — 186, прижата к её центру, наползает на соседа, спойлера в ряду нет).

**Что осталось — приёмка на парке:** владелец открывает на своей машине любой список с фильтрами
(например «Двигатели») и любой из трёх отчётов, выбирает в ступени длинное значение и смотрит:

1. ряд ступеней — без спойлера, все кнопки на виду;
2. ряд **не расползается в ширину**: расстояние между кнопками-родителями не меняется от длины
   выбранного значения;
3. плашка висит **под своей** кнопкой, прижата к её центру, в одну строку со своими соседками по
   ступени, и может зайти на соседнюю кнопку — это норма.

**Закрывается по факту приёмки владельца на парке**, не по факту «код смержен».
