# ⏳ Проставить сроки носки по 113 годовым позициям приказа о СИЗ: без срока они не попадают в «пора выдавать» 🗓 since:2026-11-05

**Ссылка:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) — индекс открытых задач. План: [ppe-acceptance-journal-2026-11](../plans/ppe-acceptance-journal-2026-11.md).

- **Что сейчас:** по решению владельца от 05.11 срок носки для годовой нормы («1 шт.», «12 пар») проставляет кладовщик по позиции — в приказе такого срока нет, а выводить его из количества нельзя («срок носки» и «количество на год» — разные величины). Миграция `0121` обнулила выведенные сроки у **113 из 191** строк приказа и перевела их в вид `annual`.
- **Риск (операционный):** пока срок не проставлен, эти позиции **не попадают в «пора выдавать»** — их меняют по износу или по решению кладовщика. Автоматических напоминаний по ним больше нет.
- **Что нужно:** кладовщику зайти в карточку СИЗ → раздел «Сроки носки по позициям» и проставить срок (в месяцах) по каждой позиции с видом «годовая норма». Срок действует на всех сотрудников профессии — предупреждение об этом есть на экране. Срок, заданный приказом («на 2 года», «до износа», «по документам изготовителя»), не трогаем — он виден отдельно и помечен как приказной.
- **Чего не делать:** не возвращать вывод срока из количества (решение владельца; возврат — отдельная осознанная правка). Не выгружать журнал в 1С до ответа бухгалтера по структуре файла: [выгрузка СИЗ в 1С](vygruzka-siz-v-1s-struktura-zhdet-buhgaltera.md).
