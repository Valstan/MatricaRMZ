## Решения владельца (27.11.2026) — приняты

| Развилка | Решение владельца | Что сделано |
|---|---|---|
| Сколько подсказок показывать | **12 по умолчанию + кнопка «показать ещё» до 20** | сервис отдаёт `total` (сколько нашлось всего), кнопка в подвале выпадашки делает новый запрос с лимитом 20; дальше — честная заметка «показаны первые 20 из N» |
| Что показывать в подсказке | **номер двигателя + внутренний номер + номер РМЗ** (как сейчас) | без изменений |
| Потолок `MAX_IMAGES_PER_MATCH` (200 картинок) | **оставить 200 + замечание оператору** | без изменений |
| Когда показывать выпадашку | **как сейчас, во всех режимах** | без изменений |

**Что владелец сознательно оставил как есть.** В режиме «В файлах» выпадашка с
номерами всплывает при вводе 4+ цифр, и Enter выбирает подсказку вместо запуска
поиска по содержимому. Это замечено и оставлено по решению владельца — **не
«чинить» побочно**: кнопка «Искать» и Esc работают как раньше. Если оператор
пожалуется — это новое решение, а не тихий регресс.

## Что осталось открытым (ждёт владельца)

1. **Полевая приёмка глазами оператора.** Живой CDP-смоук на стенде пройден (24/24,
   повтор на свежем `main` — 28/28; «показать ещё» — 33/33, доказательства —
   [`../evidence/file-search-155/show-more-2026-11-27/`](../evidence/file-search-155/show-more-2026-11-27/README.md)),
   но решение «так ли это выглядит глазами оператора» — за владельцем. Что смотреть: фото
   двигателя по номеру (подсказки полного номера + режим «Фото двигателя» с папкой
   целиком), полоса прогресса поиска с отменой, журнал действий (называет объект,
   удалённое возвращается за три дня), мастер печати фотографий, планшетная
   программа. Приёмка парка планшетов — отдельная тема (связь android-парка).
