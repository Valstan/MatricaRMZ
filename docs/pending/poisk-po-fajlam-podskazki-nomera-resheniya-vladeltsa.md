(`shared/src/domain/fileSearchEngineSuggest.ts` — «похоже на номер», вид совпадения, порядок выдачи),

поиске по папкам, три режима кнопками рядом со строкой поиска («В файлах», «В папках по названию»,
«Фото двигателя»), сторож страницы. **Живая приёмка (26.11.2026):** CDP-смоук на стенде `lane1` —

**Развилки промта, закрытые по умолчанию** (по правилу §«Промты проекта — раздел КАРМАНА»: «закрыть
по умолчанию, явно записать в PENDING, вынести владельцу»):

| Развилка | Решение по умолчанию | Почему так |
|---|---|---|
| Сколько подсказок показывать | **12** (потолок 20) | как в глобальном поиске; список читают глазами |
| Что показывать в подсказке | **номер двигателя** (его и подставляем) + внутренний номер и номер РМЗ, если они есть; марка — нет | в подсказке для поиска по папке марка лишняя |
| По какому полю искать подсказки | по **номеру двигателя** («Э06АТ0889»); по внутреннему клейму («41/26») подсказок нет | папка на диске названа по номеру двигателя |
| Потолок `MAX_IMAGES_PER_MATCH` (200 картинок в одной находке) | при срабатывании — замечание оператору «показаны первые 200 картинок из N», как было | отдельного решения владельца промт не требовал |
| Печать из результатов и контекстное меню | **не дублировали** | это отдельные заявки владельца |

**Что осталось открытым (ждёт владельца):**

1. **Сколько подсказок показывать.** Сейчас 12 (потолок 20). Если операторы часто ищут «последние 4
   цифры» и номера с одним хвостом у многих двигателей — список упирается в лимит; решение владельца:
   другое число или показ «ещё N».
2. **Что показывать в подсказке.** Сейчас: номер двигателя + внутренний номер + номер РМЗ. У карточки
   есть ещё поля (марка, дата прихода, заказчик) — показывать ли их.
3. **Потолок `MAX_IMAGES_PER_MATCH`.** В одной папке может оказаться не 3 снимка, а сотня (оператор
   сложил в одну папку разное). Сейчас 200 картинок на находку, дальше — замечание оператору.
   Нужно решение владельца: показывать первые 200, разбивать на страницы или иначе.
4. **Правило «похоже на номер» — только цифры.** Оператор, который ищет цифры в тексте файлов
   («0889» как часть номера детали), получит выпадашку с номерами двигателей. Если такие запросы
   частые — правило придётся уточнить (например, подсказки только в папочных режимах).
5. **Полевая приёмка глазами владельца.** Живой CDP-смоук на стенде пройден (24/24), но решение
   «так ли это выглядит глазами оператора» — за владельцем.
