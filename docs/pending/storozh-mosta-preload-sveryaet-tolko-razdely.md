# 🟡 Сторож моста preload сверяет разделы, но не аргументы — поле теряется молча 🗓 since:2026-11-27

🗓 since:2026-11-27 · найдено при доводке нитки «Список двигателей: этап ремонта и шаблоны
фильтров» (промт КАРМАНА **#181**, PR **#2146**)

**Что было.** Шаблон фильтров списка двигателей сохранял значения ступеней и перечень
включённых ступеней (`enabled`), но в профиль оператора уезжал **без перечня включённых**:
в `electron-app/src/preload/index.ts` тип аргумента `filterTemplateSave` не знал про поле
`enabled`, и мост резал его молча — шаблон выглядел сохранённым, а на другой компьютер
приезжал неполным.

**Почему сторож не поймал.** `electron-app/src/main/services/preloadContract.guard.test.ts`
сравнивает **разделы** контракта (`export type MatricaApi = { … }`) с разделами объекта
`matricaApi` в preload — то есть имена верхнего уровня. Аргументы методов он не сверяет:
у preload они намеренно свободнее (`presetId: string` вместо `ReportPresetId`), и строгое
сравнение типов дало бы ложные срабатывания. Между тем **поле внутри аргумента** может
разъехаться так же незаметно, как пропавший раздел, — а последствия те же: данные теряются
на границе без единой ошибки.

**Чем лечить (варианты на выбор владельца).**

1. Расширить сторож до **формы аргументов**: для методов, чей аргумент — объект-литерал,
   сверять набор ключей (не типы). Дёшево, ложных срабатываний почти нет.
2. Типизировать `matricaApi` в preload как `MatricaApi` — тогда компилятор сам скажет о
   расхождении полей. Дороже: типы в preload местами осознанно свободнее.
3. Оставить как есть и **держать правило**: новое поле в аргументе метода ⇒ правится и в
   preload, и в контракте, иначе фича «работает наполовину и молчит».

**Класс в памяти Мозга:** brain **G696** — «Раздел моста, которого нет в preload, ломает
фичу молча»; там же лечение — сторож контракта. Этот пункт уточняет G696: сторож нужен и
**на уровне аргумента**, а не только на уровне раздела.

**Куда смотреть:** `electron-app/src/main/services/preloadContract.guard.test.ts`,
`electron-app/src/preload/index.ts`, `shared/src/ipc/types.ts`.
