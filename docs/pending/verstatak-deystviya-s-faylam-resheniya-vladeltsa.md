# 🟡 Верстак: действия с принятыми файлами — решения владельца (промт #144) 🗓 since:2026-11-26

🗓 since:2026-11-26 · нитка «промт КАРМАНА #144 — Верстак: действия с принятыми файлами»
(код слит PR **#2066**, живая приёмка и починки — PR **#XXXX**, полоса 1)

**Что сделано кодом:** панель действий над выделенными на Верстаке файлами (портал
`PopupLayer`): **Прикрепить… · Копировать… · Перенести… · Коллеге… · Почта… · Убрать**;
прикрепление нескольких файлов к карточке через одноразовую записку (карточка забирает файл
сама, доступ проверяет сервер); «перенести» = копия **плюс убор своего ярлыка** (оригинал в
программе не удаляется никогда); отправка коллеге пачкой; почта — честный отказ (программа не
умеет вложений, оператору сказано словами); присланный файл помечен «от кого и когда пришёл».

**Живая приёмка 26.11.2026 на Windows-клиенте (стенд `lane1`)** — CDP-смоук PASS; сценарий
плана §6 п.4 пройден целиком: выделить несколько файлов на Верстаке → панель действий →
«Прикрепить…» → выбрать двигатель → вкладка «Фото и документы» → «Приложить (2)» → файлы
во вложениях карточки **и в серверной БД**. Приёмка вскрыла два дефекта, оба починены:
панель действий уезжала **за нижний край окна** (оператор выделял файлы и не видел панели) и
диалог выбора карточки-цели искал только серверным поиском, где двигателя нет никогда.

**Развилки промта, закрытые по умолчанию** (по правилу §«Промты проекта — раздел КАРМАНА»:
«закрыть по умолчанию, записать в PENDING, вынести владельцу»):

| Развилка | Решение по умолчанию | Почему так |
|---|---|---|
| Что делает «перенести» | **Копия в выбранную папку + убор своего ярлыка**; оригинал в программе остаётся | правило проекта: Верстак убирает только свой ярлык и никогда не удаляет файл (дедуп по sha256, счётчика ссылок нет) |
| Предупреждение о дубликатах | **После копирования** оператору говорится, что уже лежавший файл не перезаписан, а сохранён рядом с номером | `uniqueTargetPath` не перезаписывает — спросить ДО копирования можно, но лишний вопрос ради редкого случая |
| Карточка-цель по умолчанию | **Не запоминаем**: оператор выбирает поиском | пока не решено, последняя карточка может быть не той, что нужна |
| Куда складывать присланное с телефона | **Ярлык на Верстаке с пометкой** «от кого и когда пришёл» | не плодит ещё одну настройку и не создаёт файлов мимо учёта (папка-приёмник потребовала бы копирования на диск мимо файлового слоя) |
| Почта с вложениями | **Честный отказ в интерфейсе**: файлы собираются в папку и открывается почтовый клиент, оператору сказано, что письмо уйдёт без вложений | своего почтового сервера нет (решение владельца 20.10.2026), `mailto:` вложений не умеет |

**Что осталось открытым (ждёт владельца):**

1. **«Перенести» с удалением оригинала.** Сейчас «перенести» = копия + убор ярлыка, оригинал
   в программе цел. Если нужен настоящий перенос (файл уходит из программы, ярлык пропадает) —
   это отдельное решение: правило проекта прямо запрещает Верстаку удалять файл, а дедуп по
   sha256 без счётчика ссылок делает такое удаление опасным (один и тот же файл может висеть
   на нескольких объектах).
2. **Предупреждение о дубликатах до копирования.** Сейчас оператору говорится после копирования,
   что уже лежавший файл не перезаписан, а сохранён рядом с номером. Можно спросить ДО
   копирования («в папке уже есть такой файл — создать копию рядом?»), если владелец хочет.
3. **Карточка-цель по умолчанию.** Сейчас карточку выбирает оператор поиском. Часто это одна и
   та же карточка (двигатель из наряда) — можно запоминать последнюю и предлагать её первой.
4. **Полевая приёмка глазами владельца.** CDP-смоук на стенде `lane1` прошёл, но живой приёмки на
   рабочем компьютере оператора не было.
