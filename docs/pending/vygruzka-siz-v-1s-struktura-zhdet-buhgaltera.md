# ⏳ Выгрузка СИЗ в 1С: структура файла ждёт бухгалтера 🗓 since:2026-11-03

**Ссылка:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) — индекс открытых задач. План — [ppe-order-norms-and-personal-card-2026-11](../plans/ppe-order-norms-and-personal-card-2026-11.md).

- **Что сделано:** выгрузка карточки СИЗ в файл для 1С работает — XLSX и CSV, две фиксированные структуры (нормы карточки и выдачи), даты в формате `ДД.ММ.ГГГГ`, без UUID, CSV без BOM. Файл забирает бухгалтер и загружает в свою 1С.
- **Что блокирует:** какая именно 1С стоит у владельца и какие поля приёмки она ждёт. Формат выгрузки от этого зависит: свой счёт, справочник «СИЗ», номенклатурные коды, признак «выдано/возврат», период. Реализация выгрузки от ответа не зависит — блокируется только формат.
- **Что нужно:** ответ бухгалтера — версия/конфигурация 1С, какая форма приёмки (документ «Выдача СИЗ», регистр, загрузка в справочник), какие реквизиты обязательны. Дальше правка структуры выгрузки — точечная работа в `electron-app/src/main/services/ppeOneCExportService.ts`.
- **Пока ждём:** в репозитории уже есть общий выгрузщик 1С-XML (`buildReport1cXml`, канал `reports:preset1cXml`) — если бухгалтер просит XML, формат переводится на него, а не пишется с нуля.
