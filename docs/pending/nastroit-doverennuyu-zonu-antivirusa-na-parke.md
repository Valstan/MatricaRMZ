# 🟡 Настроить доверенную зону антивируса на парке 🗓 since:2026-08-04

**Раздел:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) → «⏳ Ждёт внешнего окна / события»

Техника ADR-0002 сама по себе поведенческий анализ не гасит. На каждой машине разово: папка `%LOCALAPPDATA%\Programs` в исключения **и** `MatricaRMZ.exe` + `matricarmz-watchdog.exe` как **доверенные приложения** («не проверять активность / не проверять сетевой трафик»). Файлового исключения мало — HIPS/System Watcher гасится именно доверенным приложением. Домена/GPO на заводе нет (решение владельца 2026-08-04), поэтому раскладка вручную; подпись кода отложена до появления домена или возможности купить сертификат публичного CA.

**Инструмент есть с 2026-08-26** — [`scripts/client-ops/`](../../scripts/client-ops/README.md) (перенесён из `biblio` по мандату владельца, brain D-050): печатает готовые строки под фактические пути машины, умеет экспорт/импорт эталонной конфигурации на парк.

**С v3.14.0 ручного ввода строк больше нет, и доставка на парк решена.** Помощник складывает оба списка в файлы **того формата, который Касперский принимает кнопкой «Импорт»** на своих экранах (формат снят побайтово с живого экспорта: UTF-16LE + BOM, CRLF; папка обязана кончаться `\`). Ключи `-MergeExclusions` / `-MergeTrusted` переносят прежний экспорт дословно, поэтому вопрос «заменит ли импорт список целиком» снят. Установщик кладёт помощник на Рабочий стол **архивом под паролем `111`** (ZipCrypto — распаковывает встроенный проводник) плюс памятку: пароль не секрет, он лишь делает архив непрозрачным для сканера, иначе неподписанный `.ps1` съедается до того, как для него заведено исключение (**M94**).

Пункт остаётся жёлтым по двум причинам, обе — про людей, а не про код: **исключения по-прежнему вносит человек** в окне Касперского (`avp.com` команды «добавить исключение» не имеет, Самозащита правку извне блокирует), и **на парк это фактически не разложено** — сценарий владельца «приостановить защиту → распаковать → запустить → импортировать → включить защиту» ещё не прогонялся ни на одной машине парка. Закрывать пункт **по факту раскатки**, а не по факту наличия инструмента.

## Обновление 2026-11-04: подпись снимает большую часть списка (ADR-0003)

Отсрочка «подпись кода отложена до появления домена или возможности купить сертификат публичного CA» **снята**: подписывать код можно своим самоподписанным CA — публичный CA не нужен, нужен только корень в доверенных на машине и одна галочка в Касперском.

Замер на PC79 (клиент установлен, Kaspersky Free 21.27 на месте) показал текущее состояние: **15 исключений + 9 доверенных приложений = 24 строки на машину**. Из них подпись закрывает всё, что касается исполняемых файлов: доверенные приложения (9) и исключения на бинарники больше не нужны — подписанное доверенной подписью приложение Касперский сам помещает в группу «Доверенные» через вкладку «Доверенное системное хранилище сертификатов».

Что остаётся: **исключения на данные** (SQLite-база, логи, `db-key.json`, каталог обновлений, `%TEMP%`) — их подпись не покрывает, это не исполняемые файлы.

Инструмент: [`scripts/signing/`](../../scripts/signing/README.md) — создание CA, подпись, установка корня без прав администратора, проверка. Подпись в CI уже прокинута (`CSC_LINK`/`CSC_KEY_PASSWORD` в релизном workflow) — не хватает только самого сертификата.

**Что нужно на каждой машине парка вместо 24 строк:** поставить корень `rootca.cer` (одна команда, без прав админа, без диалога) + включить одну вкладку в Касперском.

**Что закрывает вопрос о «куче исключений» полностью** — отдельное решение, в этот ADR не входит: переход на **KES + Kaspersky Security Center** (бизнес-линейка), где доверенная зона и Application Control с правилом по сертификату разъезжаются политикой на группу машин сами, без ручных действий на каждой машине. Нужны лицензия и домен.

Открытый вопрос для проверки на живой машине (ADR-0003, вопрос 7): видит ли служба Касперского корень из `CurrentUser\Root`, или вкладка предлагает только `Локальный компьютер` (тогда корень ставится с правами администратора — другой класс операции, чем текущая per-user раскладка).
