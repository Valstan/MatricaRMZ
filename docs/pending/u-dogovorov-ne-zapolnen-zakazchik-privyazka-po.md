# У договоров не заполнен заказчик — привязка по короткому номеру неоднозначна 🗓 since:2026-08-13

**Раздел:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) → «🟡 Техдолг»

У 62 договоров из 69 пусто `customer_id`. Из-за этого короткий трёхзначный номер не сужается до одного договора: у «№ 903» три кандидата, у «№ 239» — девять. При импорте учётной таблицы двигателей это оставило **655 строк без привязки к договору** плюс 69 конфликтов (в программе привязан другой договор), которые по решению владельца не трогали.

Заполнить заказчика у договоров → привязка станет однозначной почти везде, и импорт можно будет догнать повторным прогоном `engines:import` (он идемпотентен и пишет только изменившееся).
