## Что осталось за владельцем

1. **Утвердить состав советников** — сейчас статус `approved` со ссылкой на мандат КАРМАН #126/#127 («состав определяет агент по анализу репозитория»). Отдельная строка с номером решения в `../brain_matrica/docs/DECISIONS.md` — **зона Мозга**, вносит управляющий.
2. **Решить, обязателен ли совет перед планом** — сейчас протокол требует его для класса «новая сущность / новая граница / миграция / права», а не для каждой правки.
3. **Решить, где ведутся протоколы советов** — сейчас в проекте (`docs/council/`), альтернатива — в Мозге.

## Границы Совета (зафиксированы в протоколе и статье 13)

- не выдаёт права на изменения (решение — за владельцем, исполнение — по гейтам `AGENTS.md` §Autonomy);
- не делает прод-операции (миграции на проде, деплой, правки живых данных);
- не дублирует канон Мозга: советники Мозга (`../brain_matrica/docs/advisors/`) — указатель, не копия;
- не правит чужие репозитории (`../brain_matrica/`, `../Matrica4/`) — только чтение.
