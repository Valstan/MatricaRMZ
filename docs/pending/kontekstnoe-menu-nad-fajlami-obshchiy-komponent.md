# 🟡 Контекстное меню над файлами в карточке: общий компонент готов 🗓 since:2026-11-26

**Раздел:** [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md) → «🟡 Техдолг и отложенное»

## Что это

Заявка владельца от 25.11.2026: **«Контекстное меню над файлами: почта, печать, ИИ, коллега»** —
контекстное меню над файлами в карточке/вложениях. Отдельная нить, идут параллельно.

Промт КАРМАНА #158 («Действия над отмеченными снимками: меню, PDF и внешнее окно для фотографий»)
закрывает ту же задачу **в выдаче «Поиска по файлам»**, где файлы ЛОКАЛЬНЫЕ (лежат в папках
оператора), и по ходу выяснилось: **набор действий должен быть один**, иначе через месяц
в двух меню будут разные пункты.

## Что уже сделано (промт КАРМАНА #158, PR — см. COMPLETED.md)

* **Набор действий — один на все точки включения:** `electron-app/src/renderer/src/ui/components/FileActionsMenu.tsx`
  (`FILE_ACTIONS` + компонент `<FileActionsMenu>`). Он же рисуется **порталом** `PopupLayer`
  (гейт `components/popupLayer.guard.test.ts` теперь требует его и оттуда).
* **Состав:** печать, мастер печати фотографий, PDF одним файлом, почта, коллеге, в чат,
  открыть папку, на верстак, скопировать путь. **Пункта «удалить файл» нет** — программа
  не удаляет файлы оператора.
* **Недоступное в меню не показывается:** у каждого пункта проверка `available` — правило
  промта #158 («пункт, который на этой машине не сработает, в меню не показывается»).
* **Сторож набора:** `components/FileActionsMenu.test.ts` (состав, отсутствие «удалить»,
  подсказка у каждого пункта, уникальность id).

## Что осталось (собственно включение в карточке)

Вторая точка включения — **панель вложений карточки** (`components/AttachmentsPanel.tsx`).
Файл общий: он открыт в девяти карточках, и в этой нити его правит другая сессия —
**границы пересеклись, второй ждёт merge первого**. Поэтому здесь только каркас:

1. Взять `<FileActionsMenu>` из `components/FileActionsMenu.tsx` (он уже готов и покрыт
   сторожем и гейтом портала).
2. Открывать его **правой кнопкой по строке вложения** и **кнопкой над отметками**
   (у панели уже есть ряд групповых кнопок — новая кнопка встаёт в него рядом со счётчиком).
3. Реализовать обработчики действий **над серверными вложениями** (`fileId`): они уже
   готовы — `files:print`, `files:assemblePdf`, `files:revealForShare`, `files:openObjectDir`,
   `desktopTransfer.sendToColleague`, `desktopFileLink` для Верстака.
4. **ИИ** (в наборе #158 его нет — он работает только с путём, выданным диалогом выбора;
   для серверных вложений его надо согласовать отдельно).

Готовая дверь, которой пользуется карточка: `files:revealForShare` — образец «скопировать
файлы в папку и открыть её» (уже используется почтой на Верстаке).

## Как закрывать

1. Взять общий компонент (шаг 1 выше) — **не рисовать второе меню**.
2. Реализовать пункты над `fileId` (шаг 3) — теми же дверями, что уже есть.
3. Прогнать гейт портала (`components/popupLayer.guard.test.ts`) и сторож набора.
4. Живой смоук (CDP): ПКМ по вложению → меню → действие → результат плашкой.
