# 🟡 Пересжать уже загруженные снимки 🗓 since:2026-09-14

Сжатие при загрузке ([#902](https://github.com/Valstan/MatricaRMZ/pull/902)) работает только для новых файлов. В хранилище лежит **1389 jpg на 6.4 ГБ** (в среднем 4.6 МБ), снятых до него. Прогон по ним дал бы ≈5.2 ГБ на Я.Диске и, что важнее, сделал бы будущие кэш-копии на боксе впятеро легче — сейчас любое повторное обращение к старому снимку снова кладёт на диск 5–6 МБ.

Работа не тривиальна: у строки меняется `size` и `sha256` (а он — ключ дедупа с уникальным индексом), файл надо перезалить на Я.Диск и сверить. Нужен скрипт с dry-run, поштучной проверкой и возможностью остановиться. Решение владельца — делать ли.
