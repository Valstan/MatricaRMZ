# Случай: дубли общих модулей — идеи за рамками — 2026-11-28

**Что советовал (шут).** Посмотреть за шоры проекта: что, если задача сформулирована не про функции?

**Что вышло.** Три идеи:

1. **«Один человек отвечает за место двигателя»** — одна точка входа вместо запрета «выбирать лестницу
   мимо контракта». Отклонено **по объёму** (миграция API домена: 253 вхождения), идея оставлена в
   бэклоге.
2. **«Капля на двигателе»** — программа сама признаёт, что разошлась («в списке дефектовка, в
   карточке заведён»). Абсурдно как реализация, но это ровно то, что болит оператора.
3. **«Один эталонный вопрос владельцу»** — вместо «объединить лестницы» спросить «на каком экране
   двигатель должен называться иначе?» — решение в терминах экранов, а не модулей. **Принято в
   вердикт** (развилка владельцу).

**Вывод.** Нелепая идея полезна, если за ней стоит настоящий вопрос. И: шут **не решает** — две
идеи из трёх переведены в применимые предложения советом, одна осталась в бэклоге.
