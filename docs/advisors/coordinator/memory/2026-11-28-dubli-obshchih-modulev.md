# Случай: дубли общих модулей (лестницы этапов и `escapeHtml`) — 2026-11-28

**Что советовал (координатор).** Разобрать пункт PENDING «объединить лестницы „где двигатель сейчас“ и
общий `escapeHtml`», определить маршрут и состав, не пересоздавая схему приёма под задание.

**Что вышло.** Маршрут «крупное» → совет из 5 ролей (разведчик · эффективщик · скептик · шут ·
тестер) → вердикт: **доработать существующее** (пороги + контракт лестниц), **завести новый**
(`escapeHtml` в `shared/src/`), **не делать** («копии в main», печать картинок). Развилка — владельцу.

**Что оказалось неожиданным.** Пункт PENDING **наполовину неверен**: «2 копии лестниц в main» — это
**импорты** доменных функций, а «печать картинок» уже собрана в общий шаг `printPhotos`. Совет,
который принял бы пункт на веру, обсуждал бы несуществующий дубль.

**Вывод.** Перед тем как звать совет по пункту PENDING — **проверить его фактами по коду** (одна
разведка стоит дешевле пустого совета). И: **состав — по зонам задачи**: антрополога не было
(задача без интерфейса), тестер был (поведение видно оператору).
