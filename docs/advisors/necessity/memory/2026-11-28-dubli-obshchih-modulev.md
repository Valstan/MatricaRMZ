# Случай: дубли общих модулей — нужность объединения — 2026-11-28

**Что советовал (скептик).** Проверить, нужно ли проекту объединение в том виде, в каком оно
записано, и не расползается ли работа.

**Что вышло.** **Сузить.** Семь «лестниц» считают **разные** вещи (текущий проход · абсолютное
место · лучший акт · место по ПП · готовность к отсчёту) — их слияние сотрёт различия, а цена —
регресс на 2500+ двигателях. Нужны **общие пороги + контракт в словах** (день, риск низкий).
`escapeHtml` объединять **нужно** (11 копий — цена каждой правки печати). Заводить «единый модуль
этапов» **не нужно** — ранжирование уже общее.

**Вывод.** Формулировка задачи может быть неверной: «объединить семь функций» — не вопрос, который
можно закрыть слиянием; правильный вопрос — «какая функция что отвечает, и где написано правило
дважды». И: **цена решения сравнивается с пользой** (день против дней-недель).
