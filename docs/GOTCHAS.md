# Gotchas — проектные грабли по симптомам

> Symptom-keyed debug-рефлексы MatricaRMZ. **Грепай по симптому перед долгой отладкой** — дешевле, чем переоткрывать. `/start` это **не** читает. Кросс-проектные грабли — в `../brain_matrica/cross-project-ideas/GOTCHAS.md`.
>
> **Раскладка (D-097, [ADR-0013](../../../brain_matrica/adr/0013-memory-layout-index-plus-chunk-files.md)):** здесь — только индекс «симптом-якорь → запись»; текст каждой грабли лежит отдельным файлом `gotchas/M<N>.md` (область, Симптом / Корень / Диагностика / Лечение). Читай **строку индекса**, а файл — только по найденному `M<N>`: так в контекст едет 2–6 КБ вместо всего реестра.
>
> **Новая грабля:** файл `gotchas/M<N>.md` + строка в индексе — `/close_session`. Потолок индекса держит сторож `docsMemoryLayout.guard.test.ts` (≤ 50 КБ): упёрлись — значит пора сокращать формулировки, а не поднимать потолок.
>
> **Пул (brain #087):** класс, который уже записан у Мозга, помечен в файле записи последним пунктом `**Пул:** [G<N>]` — строка-указатель вместо копии переносимого урока. Нет пункта — значит класс живёт только у нас: отправлять письмом, номер не выдумывать.
>
> _Seed 2026-06-16 (реорг памяти, [план](plans/_archive/memory-reorg-2026-06.md)); разрезан по D-097 2026-10-26 ([план](plans/memory-index-plus-chunks-2026-09.md))._
