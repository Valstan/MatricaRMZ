|---|---|---|

Оставалось подозрение на `memorySession` в `authService` (модульная переменная, общая для обоих тестов файла) вместе с незаawait'енным `flushPendingEngineReservationReleases` (`syncManager.ts:107`) — с учётом третьего случая это уже маловероятно.
