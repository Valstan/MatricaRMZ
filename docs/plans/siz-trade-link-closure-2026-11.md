# План: закрытие нити промтов КАРМАНА #20/#25 — своя номенклатура и сертификат у позиции набора

**Задание владельца (промт #20, раздел КАРМАНА):** «у каждой позиции набора норм своя номенклатура и свой сертификат; названия не пересекаются, сертификаты могут». План библиотеки — **#25**.

**Состояние на 21.11.2026:** кодовая часть сделана 16–17.11 (миграция 0132, гейт сертификатов, печать бланка, справочник торговых позиций). Не сделаны были **данные**: 14 спорных пар у четырёх новых должностей из ЕТН.

**Заводская линза:** учёт СИЗ (контур кладовщика) · затор: не касается (главный затор — начало сборки) · поток: не ломает — обезличивание деталей, ремфонд, `stamped_number` и маршрутный лист не затронуты; меняется только учёт СИЗ.

## Шаги

1. **Движок связывания** ([`ppeTradeLinking.ts`](../../backend-api/src/services/ppeTradeLinking.ts)) — решения кладовщика не теряются: «не привязывать» действует до подбора; ненайденное название строки уточняется по торговому идентификатору; подбор различает предмет строки (перчатки ≠ нарукавники). ✅
2. **Данные приказа** — 8 заводских норм (TSV → генератор → миграция 0138): кепка (автослесарь, пескоструйщик), плащ ФОРЕСТ (автослесарь, тракторист, водитель погрузчика), нарукавники ЛАЙТ/BERD (автослесарь, тракторист), костюм МОТОР (водитель погрузчика). ✅
3. **Решения владельца по помеченным местам (21.11)** — миграция 0139: свои нормы электромонтеру на ботинки («Обувь … (ударов)», 1 пара) и хлопковые перчатки («Перчатки … — хлопковые с латексным двойным обливом», 6 пар); номенклатура переиспользована (СИЗ-016 и СИЗ-069) — вещь одна. Автослесарю нужны и каска, и кепка → обе позиции остаются. ✅
4. **Бланк решений** — [`siz-trade-link-choice-2026-11-21.csv`](../reports/siz-trade-link-choice-2026-11-21.csv) + разбор для владельца ([`.md`](../reports/siz-trade-link-choice-2026-11-21.md)). ✅
5. **Прогон** — стенд: 145 позиций → **142 связаны, 3 сняты по решениям, 0 спорных, 0 ненайденных** (запись в журнал синка прошла). ✅
6. **Прод** (гейт #025 — **разрешён владельцем 21.11.2026**): миграции 0138 и 0139 → `employees:link-trade-positions --apply --choices=<бланк 21.11>` → `ppe:publish-seed --apply` → проверка в журнале синка. ⏳
7. **Архив промтов #20/#25** в КАРМАНЕ — после пункта 6 (архив = «сделано»). ⏳

## Осторожности

- **Заводские строки — только в конец TSV.** Генератор нумерует строки приказа по порядку в файле: вставка в середину сдвинет `sort_order` уже применённых строк 766н (миграции не перезаписываются) — расхождение будет молчаливым.
- **`when` в журнале drizzle** должен быть больше последней применённой миграции — иначе мигратор её пропустит (проверено на стенде).
- **Метка источника у набора — одна на набор**: решение 17.11 и решение 21.11 в одном наборе (пескоструйщик) не смешиваются.
- **Кросс-профессиональная привязка — не «мнение программы»:** решения взяты из уже принятых решений владельца по тому же товару; новых имён не придумано.
