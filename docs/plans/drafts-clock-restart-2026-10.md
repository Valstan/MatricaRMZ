# Гигиена клиента: черновики-«гвоздь», проверка часов, кнопка «Перезапустить программу»

> **Тип:** plan · **Статус:** active · **Создан:** 2026-10-21 · **Релиз:** 3.87.0

## 1. Черновики: вкладка, которая не закрывается

**Боль (владелец 21.10):** у оператора копятся черновики, на сервер они не уходят. При запуске
программы всплывает модальное окно «разберите черновики», но оператор открывает один черновик —
окно закрывается, и найти список заново он не может.

**Решение:**
- вкладка **«Черновики»** появляется **сама**, как только `drafts.list()` непуст;
- стоит рядом с вкладкой Ииваныча (после избранных, перед её постоянным местом — см. рельсу);
- **крестик неактивен**, пока в списке есть хотя бы один черновик: вкладку нельзя закрыть,
  можно только уйти на другую;
- на вкладке — **красный бейдж с числом** черновиков (как колокольчик чата, но красный);
- модалка при входе остаётся, но её кнопка ведёт **в эту вкладку**, а не открывает черновик
  «наугад»;
- счётчик обновляется по событиям сохранения/удаления черновика и при синке.

**Код:** `App.tsx` (pin-логика вкладки и `canClose`), `DraftsPage.tsx` (счётчик наружу),
`V3TabShell.tsx` (бейдж), IPC `drafts:*` (событие изменения). Guard-тест: «при count > 0
крестик неактивен», «бейдж показывает число», «после удаления последнего черновика вкладка
закрывается».

## 2. Рассинхрон времени

**Симптом (владелец):** на части машин время расходится с мировым; оператор заносит данные,
они не уходят на сервер и висят черновиками (пример — пользователь Мубаракшина).

**Важно:** синхронизация ходит по номеру журнала (`seq`), а не по часам, поэтому расхождение
времени само по себе синк не рвёт. Сначала — **диагностика** (какие строки висят и с какой
ошибкой: blocked/error — механизм `blockedRows.ts` уже есть), и только потом лечение часов.
Но проверку часов делаем независимо: она дешёвая и полезная сама по себе.

**Решение:**
- источник истины — **заголовок `Date` ответа нашего же сервера** (сторонние сервисы не нужны,
  трафик не тратим); поправка на половину RTT;
- проверка при старте и далее **раз в 2 часа**; порог предупреждения — **> 2 минут**;
- предупреждение — **плашка в шапке** (не модалка), не блокирует работу;
- в плашке: «Время на компьютере расходится с сервером на N мин»,
  кнопка **«Синхронизировать»** (пробуем `w32tm /resync`; без прав администратора откажет —
  тогда честно показываем «нужны права администратора»),
  кнопка **«Открыть настройки времени»** (`ms-settings:dateandtime` — работает без прав),
  короткая инструкция «что нажать» и объяснение последствий: документы не уходят, версия
  базы отстаёт, чужие изменения не видны.

**Аварийный режим «время по интернету + часовой пояс»** (последний эшелон: считать время как
`мировое + часовой пояс Windows`) — **отдельным шагом после диагностики**, потому что:
- глобально подменить `Date.now()` нельзя без риска разъехавшихся сортировок и ключей;
- режим должен касаться только новых записей, жить до перезапуска программы и висеть с явной
  красной плашкой «работаем по расчётному времени».

**Код:** новый сервис `main/services/clockSkewService.ts` (проверка/порог/состояние),
`ipc/register/system.ts` (статус, «синхронизировать», «открыть настройки»), плашка в
`V3TabShell.tsx`. Тесты: домен порога и расчёта поправки, guard «порог не меньше 2 минут»,
guard «плашка не модальная».

## 3. Кнопка «Перезапустить программу»

**Зачем (владелец):** программа живёт в трее и не выгружается; после правок/сбоев оператору
нужен способ перезапустить её самому, не перезагружая компьютер.

**Решение:**
- кнопка в шапке — **«Перезапустить программу»** (не «перезагрузить», чтобы не путали
  с компьютером);
- обработчик: корректное гашение (движок Ииваныча, синк, закрытие БД) → `app.relaunch()` →
  `app.exit(0)`;
- если гашение не уложилось в отведённое время — не вешаем окно: показываем «закрываю…» и
  выходим принудительно, перезапуск всё равно происходит;
- watchdog для этого **не нужен** (он остаётся на случай «зависло намертво»: плановый проход
  раз в 15 минут и `--repair` по ярлыку).

**Код:** `main/index.ts` (обработчик рестарта), `ipc/register/system.ts`, кнопка в
`V3TabShell.tsx`. Guard-тест: «рестарт вызывает relaunch после гашения сервисов», «кнопка
недоступна в режиме просмотра бэкапа».

## Гейты и выпуск

Обычные гейты + CDP-смоук: вкладка черновиков с бейджем и неактивным крестиком, плашка часов
(подмена времени в тесте), кнопка рестарта (в смоуке — проверка наличия и обработчика, без
реального перезапуска стенда). Релиз 3.87.0.

## Сделано (код) — 21.10.2026

- **Вкладка «Черновики» — гвоздь** (`App.tsx`, `V3TabShell.tsx`, `shared/src/domain/tabsModel.ts`):
  появляется **сама**, как только `drafts.list()` непуст, и стоит **рядом с Ииванычем**
  (в домене появилось действие `OPEN_LIST` с `afterTabId` — вставка после указанной вкладки).
  На вкладке — **красный бейдж со счётчиком** (`v3-tab-drafts-badge`, `data-drafts-count`).
  Пока черновики есть, вкладку закрыть нельзя: крестик показан, но **неактивен** и объясняет
  почему (`v3-tab-close-locked`); когда черновиков не осталось — вкладка закрывается штатно.
  Счётчик обновляется по **событию из main** (`drafts:changed` при сохранении/удалении), а не по
  таймеру и не по синку.
  Модалка восстановления при входе осталась, но её кнопка теперь — **«Разобрать черновики»**,
  которая ведёт в эту вкладку, а не открывает черновик наугад.
- **Проверка часов** (`main/services/clockSkewService.ts`, `shared/src/domain/clockSkew.ts`):
  источник истины — заголовок `Date` **нашего же сервера** (сторонние сервисы не нужны, трафик не
  тратим), поправка считается **на середине RTT**; порог предупреждения — **2 минуты**, проверка —
  **раз в 2 часа** (плюс при старте). Предупреждение — **плашка в шапке, не модалка**
  (`v3-clock-skew`): «Время на компьютере расходится с сервером на N мин» + кнопки
  **«Синхронизировать»** (`w32tm /resync`; без прав администратора откажет — говорим честно:
  «нужны права администратора») и **«Открыть настройки времени»** (`ms-settings:dateandtime`,
  работает без прав), плюс объяснение последствий.
- **Кнопка «Перезапустить программу»** в шапке (`ipc/register/system.ts`): штатное гашение
  (движок Ииваныча, последний синк с потолком 8 с, трей) → `app.relaunch()` → выход;
  если гашение зависло — принудительный выход через 12 с (рестарт всё равно состоится).
  В режиме просмотра бэкапа кнопка недоступна.

режим должен касаться только новых записей и висеть с красной плашкой.
