# Сейчас на заводе: точные срезы, один отчёт, Карта этапов (2026-10)

Заявка владельца 14.10.2026: фильтры этапов врут — выбран «Укладка вала», а в срез
попадают чужие этапы; два отчёта про одно и то же; две кнопки справочников про одно и то же.

## Диагноз (проверено по коду)

1. **Неточный срез «Все этапы» в отчёте.** `EngineFactoryStagesReportPage.tsx:136-166`
   раскрывает двигатель в строки-проходы, но `hasStage.valueOf`
   (`engineListFacets.ts:379-391`) отдаёт **все** `stageCodes` двигателя каждой строке.
   Выбор «Укладка вала» показывает все проходы двигателей, у которых укладка была, —
   а не только укладку. В списке «Двигатели» (`EnginesPage`) строки — двигатели, там
   any-of корректен; чинить надо только раскрытые строки отчёта.
2. **«Где сейчас?» + период — смешанные смыслы.** `factoryStage` считается от двигателя
   целиком (`engineFactoryStage`), а `stageDate` в раскрытом отчёте — от прохода
   (`lastStageAt: entry.at`). Комбинация отвечает на два разных вопроса одним списком.
3. **Два отчёта — один вопрос.** `engines_at_plant` (строка = двигатель + дни/состояние +
   разрезы приход/дни/утиль) и `engine_factory_stages` (строка = проход + дубли
   допустимы) — оба «кто на заводе». Разница только в разрезах и колонках.
4. **«Виды работ» удалить нельзя** (проверено): `workSheetService.ts:244` — узел с
   `completesRepair` при добавлении строки отмечает этап в воронке; `sheetStage`
   (`engineFactoryStage.ts:116-135`) — фолбэк «где сейчас» для двигателей без строк
   единого списка; права `work_sheets.edit` / `work_sheet_types.edit`, IPC
   `workSheets:types:*`, кэш типов. Удаление = миграция строк + прав + IPC.
   Поэтому — **одна кнопка «Карта этапов» с двумя вкладками**, сущности живут.

## Что делаем

### PR-1. Точные срезы + «Где сейчас?» (shared + обе страницы)
- `hasStage.valueOf`: раскрытая строка-проход несёт **только свой этап**
  (`stageCodes: [entry.code]`, `stageDates: {code: at}` на таких строках в
  `EngineFactoryStagesReportPage`; движок `listFacets.ts` не трогаем — any-of остаётся
  для строк-двигателей в `EnginesPage`). Один этап → только его срез; два → оба;
  дубли двигателя в разных группах — допускаются (уже так: `flattenGrouped`).
- Переименование: ступень `factoryStage` — «Где сейчас?» (`engineListFacets.ts:412`);
  колонки «Этап на заводе» → «Где сейчас?» в обоих заводских отчётах, `EnginesReportPage`
  и списке «Двигатели»; правки комментариев/тестов/смоуков со старой подписью.
- «Где сейчас?» активен → ступень «Дата этапа» недоступна: выбор чистится, поле
  прячется (отчёт + список «Двигатели»); подсказка «период не нужен — смотрим, где
  двигатель сейчас». Причина — см. п.2 диагноза.
- Порядок значений ступеней этапов — по приоритету шаблона (`sortOrder` линейки,
  боковая ветка в конец — как `orderedStageTemplates`): `engineStageFacetOptions` и
  `options` ступени `factoryStage` больше не разворачивают линейку «поздние первые».
  Порядок групп в отчёте («поздние выше») не меняется — это порядок показа, не фильтра.
- Колонка «Дата этапа» в `EnginesPage` (`stageDates[selectedStageCode]`) — как была
  (решение 12.10.2026), только подпись ступени в подсказке новая.

### PR-2. Один отчёт «Сейчас на заводе» + кнопка в левом меню
- Новый пресет `engines_now_at_plant` «Сейчас на заводе»: страница = раскрытые
  строки-проходы (PR-1) + колонки «Дней на заводе» / «Состояние» / «Утиль» из
  `engines_at_plant` + все его разрезы (этап / заказчик / заказчик → этап / приход /
  дни / утиль / без). `isEngineAtPlant` — как был.
- Старые `engine_factory_stages` / `engines_at_plant`: из каталога убрать, оставить
  **алиасами** на новую страницу (ярлыки/история/избранное открывают по id —
  правило рецепта reports-as-lists); `dispatch.ts` и `humanLabelsExceptions.ts` —
  тем же путём; guard-тесты обновить.
- Кнопка левого меню «Сейчас на заводе»: новый `MenuTabId` (`uiSections.ts`) +
  иконка (`Tabs.tsx`) + рендер страницы напрямую (мимо каталога), избранное-звезда
  как у прочих nav-кнопок. Состояние/колонки — новые storage-ключи
  (`report:enginesNowAtPlant:*`), старые не тянем.

### PR-3. «Карта этапов» вместо двух кнопок
- Одна кнопка «Карта этапов» в тулбаре `WorkSheetsPage` (гейт — ИЛИ двух прав);
  диалог с вкладками «Этапы ремонта» (`RepairStageTemplateDialog` как есть) и
  «Этапы работ» (`WorkSheetTypeEditorDialog` как есть, монтируется только активная
  вкладка). Нет ни одного права — кнопки нет, как сейчас.
- Старые `data-`-аттрибуты кнопок снять, смоуки/guard-тесты перевести на новый.
