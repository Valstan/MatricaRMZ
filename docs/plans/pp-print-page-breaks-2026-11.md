## Что было в коде (проверено 23.11.2026)

- **Все договоры лежали в одном `<tbody>`** ⇒ блок нельзя было перенести: разрыв страницы
  попадал внутрь списка двигателей, и **шапка группы оставалась на прошлом листе** без
  своих строк.
- **Правил разрыва в форме не было ни одного** — ни для блока, ни для шапки группы, ни для
  подписей (подписи — отдельная таблица, она тоже могла разорваться пополам).
- Шапка колонок не была помечена как повторяющаяся (`thead` без `display:table-header-group`),
  то есть на втором листе колонки оставались без названий.

## Что стало

| Что | Правило | Зачем |
|---|---|---|
| Каждый блок контракта — **свой `<tbody>`** | `<tbody style="break-inside:avoid;page-break-inside:avoid">` | блок переносится целиком, а не рвётся пополам |
| Строка шапки группы | `break-after:avoid;page-break-after:avoid` | шапка не отрывается от своих строк |
| Строка плана | `break-inside:avoid` | одна строка не делится между листами |
| Таблица подписей | `break-inside:avoid;page-break-inside:avoid` | подписи не рвутся пополам |
| Шапка колонок | `thead { display: table-header-group }` | на каждом листе видно названия колонок |

Правила — **инлайном**, как всё оформление формы: при выгрузке в Word классы не читаются,
а разрывы страниц должны работать и там.

## Границы

- Только печатная форма ПП: `electron-app/src/renderer/src/ui/utils/productionProgramPrintHtml.ts`
  и её тест. HTML общий для превью и печати ⇒ правка одна.
- Данные, права, порядок строк, состав плана и выгрузка в файл/Word/Excel **не тронуты** —
  меняется только вёрстка листа.

## Заводская линза (три строки)

- **Участок:** производственная программа — план на бумаге (лист, который вешают на стенд цеха).
- **Кормит ли затор:** нет. Главный затор — начало сборки (ручной подбор деталей из
  обезличенного фонда, `FACTORY_MODEL.md` §3); разрывы листа плана — не узкое место.
- **Не ломает ли инвариант потока:** нет. Состав, порядок и права строк плана не менялись;
  изменилось только то, где проходит разрыв страницы.
