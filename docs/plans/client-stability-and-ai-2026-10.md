# Стабильность клиента, списки, автозапуск, ИИ-узел (2026-10-13)

Пакет из 10 ниток со слов владельца (сессия 13.10.2026, машина `Computer`).
Порядок зафиксирован решением владельца: **A→B→C→D**, внутри фаз сверху вниз.
Модель ИИваныча по умолчанию — бесплатная облачная из раздачи opencode.
Звезда — единая (левое меню + закреп + Верстак), прикреплялки убрать.

## Фаза A — стабильность

- **A1. Вис ресайза колонок.** Список двигателей, тянули ширину — UI виснет
  насмерть (только диспетчер задач). Подозрение: залипший pointer-capture
  или пересчёт раскладки, клинящий главный поток. Лечение: pointer events
  с гарантированным release + сторож, ресайз в принципе не вешает программу.
- **A2. Вис диалога добавления этапа ремонта** (история ремонта в карточке
  двигателя). Уходит фокус, глючит дропдаун этапов. Чинить связку
  фокус-менеджмент + дропдаун, покрыть гардом.
- **A3. Новый двигатель не сохраняется с первого раза.** Пустая карточка
  после «Сохранить», со второго раза ок. Найти отказ сервера/синка по логам,
  сделать сохранение с первого раза + видимую причину отказа.

## Фаза B — списки, фильтры, звёздочки

- **B4. Префиксы повторов в фильтрах.** «Возврат №1/2/3» не плодят отборы:
  фильтр этапа = все прохождения включая повторы. Отдельный фильтр
  «повторные заходы» — только счётчик по всем этапам, двигатели из реальных
  этапов не забирает.
- **B5. Фильтр «Все этапы» в «Двигателях на заводе».** Каждый этап — строкой,
  двигатель дублируется; при группировке по этапу виден в каждой группе.
  Фильтр «текущий этап» — только последний, без дублей.
- **B6. Группировка списков** из отчёта — в список двигателей и список этапов
  ремонта (повторы двигателей в группах допустимы).
- **B7. Авто-приоритет этапов в одни сутки.** Сборка/обкатка одной датой
  раскладываются сами. ✅ Порядок от владельца 13.10.2026: дата прихода —
  входной контроль ОТК → разборка/дефектовка — ремонт деталей — укладка вала →
  сборка → обкатка — выходной контроль ОТК — отгрузка заказчику — приемка
  заказчиком (= sortOrder реестра `repairStages.ts`).
- **B8. Звезда вместо прикреплялок.** Иконки «прикрепить» убрать везде;
  звезда = левое меню + закреплённое наверху + Верстак, включая отчёты
  и шаблоны отчётов. На вкладках звезда ДО кнопки закрытия.

## Фаза C — платформа

- **C9. Автозапуск.** Матрица стартует с компьютером, клиент сам
  восстанавливает удалённую запись, запуск — свёрнуто в трей. Ярлык
  «Восстановление Матрицы» убрать: у новых — из установщика, у существующих —
  чисткой при обновлении.
