## PR-2. Фильтр «Все этапы» в списке двигателей (детальный план, 12.10.2026)

Допущение объёма (подтверждено владельцем 12.10): список двигателей — главный объём;
плюс убрать ступень «Есть этап» (`engineHasStage`) из списка И отчёта «Этапы ремонта»
(там остаётся «Вид работ»; отбор по истории этапов — только в «Двигателях»).
Список «Этапы ремонта» (`WorkSheetsPage`, ступени `type`/`engineHasStage`) иначе не трогаем.

Исходная механика (уже есть, переиспользуем):
- Ступень `hasStage` отбирает двигатели, проходившие этап когда-либо
  (`engineListFacets.ts:370`, значения `stage:<code>` из `engineStageFacetOptions`).
- Колонка `engineStage` («Этап», `EnginesPage.tsx:676`) уже показывает ТЕКУЩИЙ этап
  (+ «· возврат») — это и есть «где они сейчас», не трогаем.
- История для `stageCodes/lastStage*` уже читается целиком в
  `engineService.ts:607-675` (`getEngineRepairHistoryMap`) — дату выбранного этапа
  добудем там же, без миграций (локальная реплика) и без синка.

Шаги:
1. **Переименование ступени**: `hasStage` label «Есть этап» → «Все этапы»
   (`shared/src/domain/engineListFacets.ts:371`). Значения — те же (виды работ/узлы).
2. **Данные**: в проходе истории (`engineService.ts:623-632`, рядом со `stageCodes`)
   собирать `stageDates: Record<код, at>` — последний проход каждого кода
   (та же семантика «поздний признак», что у `best`). Пробросить в `EngineListItem`
   (`shared/src/ipc/types.ts:89-156`, опциональное поле; `engineService.ts:655-671`).
3. **Колонка «Дата этапа»** в `EnginesPage.tsx` (рядом с датами стадий, скрыта по
   умолчанию как `repairStartedDate`): при ровно одном выбранном значении «Все этапы»
   показывает `stageDates[код]` (когда прошли ЭТОТ этап), иначе — `lastStageAt`.
   Sortable, `printValue`, tabletLabel.
4. **Печать**: `title` у `ListPrintDialog` (`EnginesPage.tsx:1133`) динамический —
   при ровно одном выбранном этапе `Двигатели, прошедшие этап: <имя>`, иначе прежний
   «Список двигателей». Имя — из того же справочника, что значения ступени.
5. **Фильтр `stageDate` («Дата этапа», дата ПОСЛЕДНЕГО этапа) — не меняем** (отвечает
   «сборка за сентябрь»); связку «дата именно выбранного этапа» даёт колонка из п.3.
   Если владелец захочет и отбор по дате выбранного — отдельным шагом (меняет
   семантику ступени).
6. **Убрать `engineHasStage` из `workSheetFacets`** (`shared/src/domain/workSheets.ts:388-404`,
   влияет на список и отчёт «Этапы ремонта» разом — оба строят ступени этой функцией).
   Проверить: сохранённые состояния фильтров со ступенью (санитайзер обязан молча
   отбросить неизвестный id), тесты/сторожа, упоминающие `engineHasStage`.
7. Тесты: shared — подпись ступени + `engineStageFacetOptions` (дополнить);
   `engineService` — `stageDates` на синтетической истории (юнит); guard — колонка
   в списке + динамический title печати. CDP-смоук: выбрать этап → список + дата +
   печать-заголовок (проверить руками заголовок в диалоге печати).

Приёмка: выбрать «Все этапы = Укладка» → только двигатели с укладкой в истории;
колонка «Дата этапа» — дата укладки; «Этап» — текущий; печать — заголовок с укладкой.
