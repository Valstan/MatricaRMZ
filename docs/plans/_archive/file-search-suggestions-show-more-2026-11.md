## Заводская линза (три строки)

- **Участок:** приёмка и дефектовка — оператор находит фотографии двигателя в своей папке по номеру.
- **Кормит ли затор:** не кормит. Главный затор модели — «начало сборки: ручной подбор совместимых деталей из обезличенного фонда»; модуль ищет фото по номеру двигателя, а не детали в фонде.
- **Инвариант потока:** не ломает. Модуль только читает папки и локальную реплику карточек; записи в карточку двигателя не касается. Обезличивание деталей, партия/экземпляр (`stamped_number`), маршрутный лист и сдельщина не затрагиваются.

## Глобальная линза (три строки)

- Выпадашка подсказок — `electron-app/src/renderer/src/ui/components/SuggestInput.tsx` + `hooks/useSuggestionDropdown.ts`; дубль: нет (готовый блок проекта уже взят в нитке #155, самодельной выпадашки не появилось).
- Действие: **доработать** `SuggestInput` двумя аддитивными пропсами (`previewLimit` — потолок строк списка, `footer` — подвал «показать ещё»/заметка), поведение по умолчанию прежнее (15 строк, без подвала).
- Реестр глобальных модулей (`docs/GLOBAL_MODULES.md`) не меняется: нового модуля нет, существующий только расширен пропсами.

## Что сделано

- **Домен** (`shared/src/domain/fileSearchEngineSuggest.ts`): `rankAllFileSearchEngineSuggestions` — выдача без потолка (из неё и лимит, и честное «сколько всего нашлось»); `fileSearchEngineSuggestFooter` — что показать под списком: кнопка «показать ещё N» / заметка «показаны первые 20 из 27» / ничего.
- **Сервис** (`main/services/engineNumberSuggestionService.ts`): отдаёт `{ suggestions, total }` — `total` считается по полной выдаче, до обрезки лимитом.
- **Контракт и IPC** (`shared/src/ipc/types.ts`, `main/ipc/register/fileSearch.ts`): в ответе `fileSearch:engineNumberSuggestions` появилось `total`.
- **Компонент** (`components/SuggestInput.tsx`): `previewLimit` (потолок строк списка, по умолчанию 15) и `footer` (подвал: кнопка или заметка) — оба необязательные.
- **Страница** (`pages/FileSearchPage.tsx`): состояние подсказок хранит запрос вместе с выдачей; по умолчанию запрашивается 12, кнопка «показать ещё» делает новый запрос с лимитом 20; потолок показывается честной заметкой; ответ принимается, только если в строке то же самое.

**Живая приёмка (27.11.2026, стенд `lane1`).** CDP-смоук на живом Windows-клиенте:
**33/33 PASS**. Доказательства — [`../../evidence/file-search-155/show-more-2026-11-27/`](../../evidence/file-search-155/show-more-2026-11-27/README.md).
Драйвер (в репозитории) — `.claude/skills/verifier-electron/scripts/cdp-file-search-engine-suggest.mjs`,
расширен под новую правку: фикстур-двигателей теперь 29 (25 из них — сверх потолка
списка, иначе кнопку «показать ещё» не увидеть).

**Что вскрыл прогон — и почему это была правка продукта, а не измерения.** Первый прогон
новой проверки дал два FAIL: после клика по «показать ещё» список был пуст. Причина —
выпадашка гаснет по автоскрытию через 3 с (общее решение владельца для всех подсказок
программы), а клик по подвалу это автоскрытие не продлевал: оператор нажал «показать
ещё» — и список исчез, не показав ничего. У мыши это обычно не воспроизводится (движение
мыши над выпадашкой продлевает таймер), но полагаться на это нельзя. Правка: `SuggestInput`
продлевает автоскрытие при клике по подвалу (`bumpAutoHide` перед `props.footer.onClick`).
После правки — 33/33 PASS.
