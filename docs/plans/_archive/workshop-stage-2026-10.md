# Цех — атрибут этапа, не двигателя (2026-10-13)

Решение владельца 13.10.2026: двигатель принадлежит заводу, а не цеху. Цех живёт
в этапе ремонта (`operations.meta.workshopId` + снимок `workshopName`), справочник —
`directory_workshops`. Из карточки двигателя («Основное», `workshop_id`) поле убрано.

## Что чинено

### PR-1 (ветка `feat/workshop-stage-2026-10`) — показ цеха из этапов
1. Карточка двигателя: `workshop_id` убран из «Основного» (поле, сейв, `workshop_transfer`,
   черновик). EAV-значение в базе остаётся замороженной историей. `workshopOptions`
   и загрузка справочника остаются — они нужны `EngineHistoryFeedPanel` для цехов
   строк истории.
2. `RepairHistoryEntry.workshopName?` — снимок имени едет из `meta` в запись ленты
   (раньше терялся); `getEngineRepairHistoryMap` кладёт его в карту рядом с `workshopId`.
3. `EngineListItem.workshopName` — снимок истории как fallback, когда справочник
   недоступен (офлайн, нет прав, цех деактивирован) или id legacy-текст.
4. Новый хук `useWorkshopNames()` — `id → имя` из `workshops.list(activeOnly:false)`.
   `EnginesPage` и отчёт «Двигатели на заводе» резолвят имена им, а не каждый своим кодом.
5. Список двигателей: колонка «Цех» (видна по умолчанию, сортировка, печать).
6. Отчёт «Двигатели на заводе»: колонка «Цех» заполняется (была пустой — отчёт не
   резолвил имена); ступень «Цех» показывает имена вместо «без названия».

### PR-2 — правка цеха в этапах (ветка `feat/workshop-stage-edit-2026-10`)
1. `updateManualEntry` + IPC (`ops:updateManual`) + shared/preload-типы: ручная запись
   правится с цехом (`workshopId` + снимок; `''` — снять; смена id без имени стирает
   чужой снимок). Форма правки в ленте получила селект цеха.
2. `saveManual`: снимок имени из справочника сразу (раньше — id без имени).
3. Правка этапа в ленте: форма несёт id+имя (seed из строки), применение — свежее имя
   из справочника поверх снимка. Откат (`restore-stage`, `restore-manual`,
   `readd-manual`) цех возвращает.
4. Писатели `saveRepairStageRow` / `saveWorkSheetRow`: снимок имени переживает правку,
   когда цех не менялся (цех вне справочника — `activeOnly:true` у селектов).
5. `WorkSheetDetailsPage`: цех вне справочника виден опцией (`row.workshopName`),
   сохранение держит его снимок при неизменном id. Селект доступен на существующей
   строке под `canEdit` (проверено + сторож).

### PR-3 — бэкфилл пустых цехов (по слову владельца, прод-мутация)
Скрипт `workshops:backfill-stage-workshops --dry-run/--apply`: строки `operations`
(`sheet`/`stage`) без `meta.workshopId`: сборка (`sborka`) → цех код `1`, обкатка
(`obkatka`) → цех код `2` (id резолвятся из `directory_workshops` по `code`);
legacy-текст (`«Цех №1»` вместо uuid) нормализуется в uuid + снимок имени.
Прогон на dev, затем на проде по явному слову в том же ходе.

## Намеренно не делаем
- `engine.workshop_id` (EAV) не удаляем из базы — замороженная история; список и
  отчёт его больше не читают как источник (история важнее, как и было).
- Авторизацию serve / реестр в git — см. план `opencode-nodes-2026-10.md`.
