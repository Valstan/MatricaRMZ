## Шаг 1. Выделение в списке двигателей не слетает (PR-1)

Корни (все в `electron-app/src/renderer/src/ui/hooks/useListSelection.ts`,
потребитель — `pages/EnginesPage.tsx:519-525`):

- **Гонка mousedown (`:118-140`)**: глобальный слушатель на `document` в capture-фазе
  чистит `Set` при клике «мимо выделенного», а `onChange` чекбокса приходит ПОЗЖЕ.
  Итог: вторая галочка = `N+1 → 1`. Лечение: клик внутри списка
  (`closest('[data-list-root]')`, чекбоксы, `Shift`) очистку не триггерит.
- **`onRowPrimaryAction (:77-80)`** чистит всё при клике по невыделенной строке
  (открытие карточки). Лечение: открытие карточки выделение не трогает.
- **Поиск/фильтр**: `selectedEngines = displayRows ∩ selectedIds` (`EnginesPage:522`) —
  выпавшее из фильтра пропадает из счётчика и печати. Лечение: хранить ids отдельно,
  счётчик и печать — по всем ids (данные для невидимых добрать из `engines.list()`),
  в печать идут все ids, а не только видимые.
- **Размонтирование** (уход в карточку) убивает `useState`. Лечение: персист ids
  в `sessionStorage` (скуп `useListUiState`, ключ `list:engines:selection`), при
  монтировании сверка с загруженными строками (чужие ids отбрасываются).
- `keydown`-очистка (`:118-140`): сузить до `Escape`, чтобы Ctrl+P и пробел не гасили.

Сторож: юниты на `useListSelection` (гонка mousedown, персист, сверка) + CDP:
выделить 2, сменить поиск, вернуться — обе галочки на месте, счётчик кнопки верный.

## Шаг 2. Одна форма печати: выбор → раскладка → печать (PR-2, ядро нитки)

Выбранный вариант (из предложенных владельцем): **один диалог, две секции**.
Кнопки «Бирка» (карточка, `EngineDetailsPage:2454`), «Бирки на двигатели»
(список, `EnginesPage:928`) ведут в него; стартавый набор зависит от контекста
(карточка → этот двигатель; список → выделенные; пусто → пусто + подсказка).

- Секция выбора: список-набор (чекбоксы — снять = убрать из печати и превью),
  поиск по номеру (`engines.list()` + фильтр-подстрока, как в `BulkStageAddDialog`),
  кнопка «Добавить ещё» = закрыть диалог (набор живёт в `sessionStorage`
  `print:engineTags:queue`, карточку можно открывать другую, набор на месте).
- Секция раскладки: ориентация (альбомная по умолчанию, см. шаг 3), 6/4/2,
  живое превью (`iframe srcDoc`, как сейчас), «Печать».
- `EngineTagPrintDialog.tsx:80-115` расширяется набором; `tagRows: EngineListItem[]`
  (`EnginesPage:348`) едет из очереди, а не только из видимых.
- «Печать этикеток» (`LabelPrintDialog`, QR) — НЕ сливаем: другая сущность
  (тара, не двигатель). Отдельным режимом не делаем.

Сторож: очередь переживает закрытие/карточку (юнит sessionStorage), CDP:
карточка А в очередь → карточка Б в очередь → в форме 2, снять галочку → превью 1.

## Шаг 6. Ресайз колонок мышью (PR-6, самый инженерный)

Ресайза нет (проверено: только сплиттеры панелей). Проектируем:

- Новый хук `useResizableColumns(layoutId)` рядом с `useColumnLayout`:
  ручка 8px у правого края `th` (`cursor: col-resize`), drag через
  pointer-capture (как сплиттеры в `App.tsx:6507`), `min 48px`, запись в
  расширенный `columnLayoutStore` (`widths: Record<id, px>`, тот же LWW-роуминг),
  кнопка сброса (двойной клик по ручке = авто).
- Приоритет: ручная ширина бьёт `useAdaptiveListTables` (тот пишет
  `--ui-list-col-N-max-ch` поверх — для зафиксированных колонок пропуск) и
  `col.width` инлайн-дефолты. Drag не тогглит сортировку (`th onClick`
  `EnginesPage:780` — глушить по флагу движения).
- Раскатка: все списки на паттерне `listHeaderKindProps` (Engines, Contracts,
  Counterparties, Nomenclature×2, StockDocuments, SupplyRequests, WorkOrders,
  WorkSheets, Employees, отчёты×3) — механически, один PR, CDP-смоук на
  Двигателях и Контрактах (потянуть, перезайти — ширина держится).
