# Отчёты как списки — рамка и рецепт переноса

**Статус:** активный, рамка выложена 15.09.2026 (PR отчёта «Двигатели на заводе: этапы ремонта»). Остальные отчёты переносятся по одному, по слову владельца.

## Context

Владелец (15.09.2026, вечер): «отчёты должны, по сути, стать такими же списками, как список двигателей, как список контрактов: вверху панель фильтров, где мы прощёлкиваем, что нам надо, а внизу список, который тут же формируется — колонки убирать ненужные, добавлять нужные, фильтры включать и сразу видеть, что получается». Сегодняшний `ReportPresetPage` — форма фильтров → «Сформировать» → таблица предпросмотра без ступеней, без настройки колонок и без сортировки. Списки же (`EnginesPage`, `ContractsPage`, `WorkSheetsPage`) уже умеют всё перечисленное на общей обвязке.

Решение — не переписывать пресетную страницу, а дать ей вторую ветку: пресет с `presentation: 'list'` рисуется своим компонентом-списком, а пресетная механика (регистрация в каталоге, избранное, история, ярлык на Верстак, восстановление вкладки, deep-link) остаётся общей и достаётся бесплатно.

## Рамка (что уже есть)

- `ReportPresetDefinition.presentation?: 'table' | 'list'` — `shared/src/domain/reports.ts`. У спискового пресета `filters: []`, `columns: []`; `dispatch.ts` отвечает отказом словами (сервис его не строит).
- Реестр `LIST_REPORT_PAGES` — `electron-app/src/renderer/src/ui/pages/reports/listReportPages.ts`: `ReportPresetId → компонент(ListReportPageProps)`. `ReportPresetPage` в самом начале делегирует ему экран целиком.
- `ListReportPageProps` — `engines`, `canExport`, `onOpenEngine`, `onBack`. App отдаёт их в оба места, где рисуется `ReportPresetPage`. Новому списку из другого домена (контракты, наряды) поле добавляется сюда же.
- Группировка — `shared/src/domain/listGrouping.ts` `flattenGrouped(rows, levels)` → плоский ряд `{group | row}`; `VirtualTable.rowNumberOf` даёт заголовку группы пустой «№», строкам — сквозной номер; строка группы — один `<td colSpan>`.
- Печать — `ListPrintDialog.rowGroupLabel` печатает заголовок группы перед первой её строкой.
- Сторож: `pages/reports/EngineFactoryStagesReportPage.guard.test.ts` — каждый `presentation: 'list'` зарегистрирован страницей и наоборот; страница в `PAGES` сторожа `ListChrome.guard.test.ts`.

Первый жилец рамки — `EngineFactoryStagesReportPage.tsx` (образец для копирования).

## Рецепт переноса пресета в список

1. Страница `pages/reports/<Name>ReportPage.tsx` по образцу: `useListUiState('report:<slug>:ui')`, `useColumnLayout('report:<slug>:columns')`, `FacetFilter` с описателями ступеней из домена (`ENGINE_FACETS`, `CONTRACT_FACETS`, или свой набор), `ListCount`, `VirtualTable` + `flattenGrouped`, `ListPrintDialog` с `rowGroupLabel`, `PageToolbar` с `ColumnSettingsButton label="Колонки списка"` (иначе не пройдёт `ListChrome.guard`).
2. Зарегистрировать в `LIST_REPORT_PAGES`; в реестре пресетов поставить `presentation: 'list'`, `filters: []`, `columns: []` (сторож проверит пару).
3. `dispatch.ts`: явный `case` с отказом словами; `humanLabelsExceptions.ts` — в список непокрытых с обоснованием «строится на экране».
4. Если нужны данные, которых нет в каталоге приложения, — расширить `ListReportPageProps` и отдать из App, а не грузить внутри страницы; списки строятся из уже загруженного.
5. Старые ярлыки и история продолжают открывать пресет по id — ничего не переименовывать.

## Кандидаты (по одному, после слова владельца)

- `engines` («Двигатели», универсальный) — почти весь его отбор уже есть ступенями `EnginesPage`; в списковом виде отличается только набором колонок и группировкой по договору/марке.
- `work_sheets` («Ведомости работ») — `WorkSheetsPage` уже список; отчёту остались итоги по видам работ и печать по договору.
- `engine_stages` («Стадии двигателей по контрактам») — поглощается «Этапами на заводе» с группировкой заказчик → этап; снять после приёмки нового.

## Чего не делаем сейчас

- Не переводим весь каталог разом (решение владельца 15.09: «новый отчёт + общий каркас, остальные потом по одному»).
- Не трогаем экспорт CSV / PDF списковых отчётов — печать списка есть, остальное по запросу.
- ~~Даты стадий «отремонтирован», «утиль», «ремонт начат» в `EngineListItem` не носим~~ — снято 16.09 (программа осень-2026, B2): строка несёт `statusDates`, «Дата этапа» в отчёте заполнена, в списке двигателей три скрытые по умолчанию колонки.
