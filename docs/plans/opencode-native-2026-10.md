# OpenCode-узел — нативно в клиенте (2026-10-13)

Решение владельца 13.10.2026: узел ставится вместе с Матрицей **тихо, без админа,
без новых портов и без новых процедур Касперского** — ресурсами самой Матрицы.

## Почему не патч harness, а редизайн

1. **Установщик per-user без UAC** (`installer.nsh`: «ставимся per-user и UAC не
   поднимаем») физически не может: писать в `%PROGRAMDATA%`, создавать задачи
   планировщика и правила брандмауэра. `InstallOpencode` из PR под `#1314` там
   молча падает на каждой установке (best-effort). Per-user обязателен.
2. **Маскировкой файрвол не обмануть**: слушающий сокет = правило, точка. Но у
   Матрицы уже есть слушающий сокет `0.0.0.0:38080` (раздача соседям), правило под
   него и доверенный exe. Поэтому serve слушает только loopback, а наружу —
   только через exe Матрицы.
3. **Касперский уже покрывает**: у доверенной Матрицы флаги «Не контролировать
   активность дочерних программ» и «Не проверять сетевой трафик» — serve,
   запущенный самим клиентом, и его трафик через exe клиента под существующим
   доверием. Папка бинаря добавляется в `Get-ExclusionPlan` (та же процедура
   импорта, новой нет).

## PR-A (эта ветка) — клиент сам ведёт узел

- `main/services/opencodeServeManager.ts` (new): per-user каталог
  `%LOCALAPPDATA%\Programs\MatricaRMZ-OpenCode`, `opencode.exe`; состояния
  missing → downloading → ready → running; `ensureOpencodeNode()` на старте
  (fire-and-forget, best-effort, только win32); версия — маркер `.version`,
  обновление в фоне не чаще раза в сутки; скачивание fetch-стримом + SHA256
  (`digest` релиза GitHub, как harness) + тихая распаковка `Expand-Archive`
  (нулевых новых зависимостей); запуск `serve --port 3080 --hostname 127.0.0.1`
  скрыто (`windowsHide`); PID-файл + health `/global/health`; стоп на quit;
  upsert локального узла `{COMPUTERNAME, http://127.0.0.1:3080}` в реестр.
- IPC `opencodeNodes:status` + preload + shared-тип + строка статуса в разделе.
- Старт в `main/index.ts` после создания окна (не блокирует), стоп в `before-quit`.
- Удалить `InstallOpencode` из `installer.nsh` + `extraResources`-запись harness
  (админ-путь остаётся ручным через zip-окно обслуживания).
- `kaspersky-matrica.ps1`: `OpencodeDir` в `Get-MatricaInfo` + план исключений.
- Сторожа + unit-тесты чистых помощников. Письмо-отчёт Мозгу (смена дизайна мандата).

## PR-B — релей через 38080 (следующий)

Маршрут `/opencode/*` в `lanUpdateService` (тот же сокет/правило/exe; GET+POST+SSE
стримом, без буферизации), только при включённом `isLanUpdateEnabled()` (готовый
выключатель). Проба релейных URL, адрес пира для LAN. Без авторизации сознательно
(тот же периметр подсети и тот же уровень, что раздача файлов; решение владельца).

## Не делаем

- Серверный claim-relay через прод (будущее, отдельным мандатом).
- `opencode auth login` автоматом — секреты провайдеров вводит оператор; в разделе
  подсказка.
- Скачивание при отсутствии сети — статус в разделе, ретрай следующим запуском.
