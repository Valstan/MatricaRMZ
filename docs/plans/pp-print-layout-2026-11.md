# Печатная форма производственной программы: неразрывные блоки на странице

**Основание:** промты КАРМАНА (раздел `MatricaRMZ`) **#74** (задача владельца) + **#75**
(план). Нитка — 23.11.2026, PR [#1957](https://github.com/Valstan/MatricaRMZ/pull/1957).

**Что уже сделано рядом (не дублируем):** ширины колонок под «одну строку» — в #1950
(план [`pp-print-columns-one-line-2026-11.md`](pp-print-columns-one-line-2026-11.md)).
Этот файл — про вторую часть промта: чтобы блок контракта и блок подписей не рвались
между страницами.

**Зона:** `electron-app/src/renderer/src/ui/utils/productionProgramPrintHtml.ts` и его
юнит. Домен печатной модели ПП (`shared/src/domain/productionProgram.ts`) не трогаем:
разрывы — свойство вёрстки, а не данных.

## 1. Заказ владельца

«Нужно стараться располагать списки двигателей и подписи так, чтобы они не разрывались
между страницами… если блок контракта не помещается на странице и делится на две —
перенести его целиком на следующую страницу. Подписи не должны разрываться так же».

## 2. Причина, почему блок рвался

Вся таблица строк была одним `<tbody>` — единицы разрыва у браузера не было, и контракты
рвались по строкам как попало, а шапка контракта могла остаться внизу страницы («висячая»
шапка).

Сделано: каждая группа (контракт) — отдельный `<tbody>`, плюс правила неразрыва
(`break-inside: avoid` для `<tbody>` и строк, `break-after: avoid` для шапки группы) и
такое же правило для блока подписей (класс `pp-signatures`).

## 3. Проверка печатью, а не на глаз

Форма собрана на 45 строках и 3 контрактах и напечатана движком Chromium
(A4 landscape, полоса 184,6 мм — 210 минус поля):

- **было** (6 страниц): шапка второго контракта оставалась внизу первой страницы, а его
  строки уезжали на следующую — блок рвался по строкам;
- **стало** (5 страниц): первый контракт (97,1 мм) целиком на первой странице, второй
  (916,8 мм — длиннее страницы, поэтому рвётся неизбежно) начинается с новой страницы
  вместе со своей шапкой, третий (89,4 мм) целиком на последней странице, блок
  подписей (46,6 мм) — целиком, не разорван.

**Чего правило не может:** блок длиннее страницы (контракт с десятками двигателей)
неразрывным не станет — движок всё равно разорвёт. Правило применяется к блокам,
которые влезают.

  тело), гейты `typecheck`, `typecheck:test`, `lint`, `electron-app`.
