# ДС в карточке двигателя — появляются сразу после ввода договора, без «Сохранить»

> **Тип:** plan · **Статус:** active · **Создан:** 2026-10-21 · **Релиз:** 3.85.0

## Симптом (владелец, 21.10.2026)

В карточке двигателя выбирается номер контракта, вторым полем — дополнительное соглашение
этого контракта. Но ДС в списке не видно: показывается только «договор номер такой-то».
После нажатия «Сохранить» ДС появляются. Оператору нужен выбор ДС **сразу после ввода
контракта**, без промежуточного сохранения.

## Причина (по коду)

`EngineDetailsPage` строит опции секций в `useEffect` по `contractId`:
`window.matrica.admin.entities.get(contractId)` → `parseContractSections` →
`buildContractSectionOptions`. Эффект висит **на изменении выбранного договора** и больше
ни на чём: перечитанный договор (ДС завели в карточке договора, пока карточка двигателя уже
открыта; или данные пришли синком) список не обновляет. Обновляет его перезагрузка карточки —
её и делает «Сохранить». Отсюда симптом.

Вторая половина той же ловушки — поле ДС было `disabled` при пустом списке опций: если
секции не прочитались (ошибка запроса), поле выключалось, и повторить запрос оператору было
**нечем** — оставался только «Сохранить». Ввод номера договора при этом работал: поле
контракта и так разбирает набранный текст на уходе фокуса (`resolveOnBlur` →
`findUniqueExactReference`), так что отдельный «резолв по номеру» не нужен.

## Решение (сделано)

1. **Секции перезапрашиваются**, когда оператор тянется к выбору ДС (нажатие/фокус на поле)
   и когда окно возвращается в фокус (`focus` / `visibilitychange`). Отдельного тика по
   «договор изменился» не заводим: источник события — само обращение к полю, и это ровно
   тот момент, когда список нужен свежим.
2. **Поле ДС больше не выключается** из-за пустого списка опций: выключено только пока нет
   договора. Пусто ≠ «нельзя» — иначе оператору нечем повторить запрос.
3. **Состояние чтения секций видно**: «Загружаю ДС…» в плейсхолдере и строка «Не удалось
   прочитать ДС договора — нажмите на поле, чтобы повторить» при отказе. Молчащий пустой
   список — это и есть «ДС не появляются».
4. Резолв номера договора по вводу **не понадобился** — он уже есть в `EntityReferenceField`
   (разбор набранного текста на уходе фокуса). Дублировать его в карточке было бы второй
   дорогой к тому же полю.

## Код

- `electron-app/src/renderer/src/ui/pages/EngineDetailsPage.tsx` — тик перезапроса секций,
  состояние чтения, обработчики фокуса, поле ДС без «мёртвого» выключения.
- `electron-app/src/renderer/src/ui/pages/EngineContractSections.guard.test.ts` — сторож:
  перезапрос по обращению и по фокусу окна, поле не запирается пустым списком, отказ чтения
  виден оператору.
- CDP-смоук: контракт с двумя ДС → открыть карточку двигателя → выбрать договор → ДС видны
  без сохранения.

## Гейты и выпуск

Обычные гейты монорепо + CDP-смоук шага. Едет в 3.85.0 вместе с пачкой приёма.
