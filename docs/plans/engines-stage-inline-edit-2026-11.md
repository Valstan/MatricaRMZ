# Список двигателей: этап меняется прямо в таблице + печать «Сейчас на заводе» с разрезом по этапам 🗓 since:2026-11-26

**Промт КАРМАНА #168** (зачитка владельца 26.11.2026, раздел `MatricaRMZ`).

**Суть:** колонка «Этап» в списке двигателей должна не только показывать, но и позволять
менять этап прямо в строке — тем же путём, что в производственной программе; а печать
режима «Сейчас на заводе» должна идти с разрезом по этапам.

## Глобальная линза

`Глобальная линза: запись этапа ремонта · дубль: нет (готовый путь — `electron-app/src/renderer/src/ui/components/ProductionProgramStageDialog.tsx` + IPC `workSheets:stages:save` → `repairStageService.saveRepairStageRow`; печать списка — `ListPrintDialog` с `rowGroupLabel`, группировка в печати слита в PR #2097) · действие: доработать существующий модалку (одна на два экрана) и переиспользовать печать списка — новый модуль не нужен.`

**Заводская линза**

`Заводская линза: движение двигателя по этапам (приёмка → разборка → … → отгрузка) · затор: не касается (затор модели — начало сборки, ручной подбор деталей из обезличенного фонда; этап из списка его не двигает) · поток: не ломает — этап пишется тем же путём, что и в карточке (общий путь `saveRepairStageRow` с гейтами субординации дат, дубля по дню и возврата), маршрут двигателя, маршрутный лист и подпись ответственного не меняются.`

## Решения (промт выносил их владельцу; идём по предложению промта)

1. **Меню или полная модалка.** Берём предложение промта: в ячейке — список этапов, по
   выбору открывается **та же** модалка с предзаполненным этапом и сегодняшней датой.
   Основание — не только пожелание: этап без даты в историю ремонта не пишется, поэтому
   «сменить статус одним кликом» физически невозможно — это гейт домена, а не наш выбор.
2. **Право.** Новое право **не заводим**: переиспользуем доменный гейт
   `canWriteRepairHistory(perms, 'stage')` — тот же, что в карточке двигателя и на сервере.
   Новое право — это новая граница, а решение по ней за владельцем; обойтись можно.
3. **Случайный клик.** Список в ячейке + запись только после «Записать этап» в модалке:
   промах по строке ничего не пишет (запись — явное действие). Клик по строке открывает
   карточку, поэтому клик по списку гасится (`stopPropagation`).

## Шаги

1. **Колонка «Этап» — изменяемая.** Проп `canEditWorkSheets`/`canEditOperations` → доменный
   гейт `canWriteRepairHistory(..., 'stage')`; без права колонка остаётся только для чтения
   (текст, как сейчас). С правом — список этапов в ячейке; выбор этапа открывает модалку.
   — *проверяемый результат: колонка даёт выбор этапа; без права — read-only.*
2. **Запись общим путём.** `window.matrica.workSheets.stages.save` (тот же IPC, что из
   карточки и из ПП), ответы гейтов (дубль за день, смена даты дефектовки) решает модалка.
   После записи — перечитываем список двигателей (`props.onRefresh`) и шлём
   `matrica:engines-changed`: колонка, дата этапа, статус и группа обновляются без
   перезагрузки страницы. — *проверяемый результат: после записи строка показывает новый этап.*
3. **Печать.** Проверяем, что режим «Сейчас на заводе» печатается тем же срезом, что экран
   (`rows={displayRows}`), и несёт заголовки групп; заголовок листа называет режим среза.
   — *проверяемый результат: на листе заголовки этапов, двигатели без этапа — своей группой.*
4. **Сторож.** `EnginesPage.stageColumn.guard.test.ts`: колонка не откатывается в «только
   показывает», запись идёт общим путём (`workSheets:stages:save`), модалка — общая,
   право проверяется. — *проверяемый результат: тест падает при откате (проверено временной правкой).*
5. **Гейты.** `corepack pnpm -F @matricarmz/electron-app test`, `-F @matricarmz/shared test`,
   typecheck, lint — зелёные; CDP-смоук на живом клиенте — этап меняется за два клика.

## Критерии приёмки

- [ ] В списке двигателей выбор этапа в ячейке открывает модалку; этап записывается в историю ремонта.
- [ ] Запись идёт общим путём с карточкой и ПП: гейты (субординация дат, дубль этапа за день, смена даты дефектовки) срабатывают одинаково.
- [ ] Без права на запись этапов колонка «Этап» остаётся только для чтения; право проверяется на сервере.
- [ ] После смены этапа колонка, дата этапа, статус двигателя и группа «По этапу на заводе» показывают новое без перезагрузки страницы.
- [ ] Фильтр «История», сортировка по этапу и счётчики «на заводе» после смены этапа не разъезжаются.
- [ ] Печать списка в режиме «Сейчас на заводе» с разрезом по этапам содержит заголовки этапов и строки внутри них; двигатели без этапа — отдельной группой.
- [ ] На планшете список этапов в ячейке открывается и помещается в экран.
- [ ] Сторож падает, если колонка «Этап» снова станет только показывающей или запись уйдёт отдельной дорогой.
- [ ] `corepack pnpm -F @matricarmz/electron-app test` и `-F @matricarmz/shared test` — зелёные.

## Границы и риски

- **Сервер не трогаем:** гейт записи (`work_sheets.edit` ИЛИ `operations.edit`) и серверный
  `ledgerAuthzGuard` уже смотрят на то же право — новая граница не заводится.
- **Серверная дата:** гейты субординации дат и «смена даты дефектовки» живут в
  `saveRepairStageRow`; из списка они срабатывают так же, как из карточки.
- **Этап задним числом:** дата в модалке редактируется — это влияет на счётчики «на заводе»
  и сроки. Гейты из карточки применяются, список даёт ту же возможность.
- **Двигатели без этапа:** в размере «По этапу на заводе» они попадают в свою группу
  («Заведён» / «Принят» / «На заводе»), а не пропадают.
- **Группировка в печати** уже слита (PR #2097, промт #164) — здесь не заводим вторую
  правку, а проверяем, что этот случай закрыт (шаг 3).
