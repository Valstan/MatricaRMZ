# Фильтры: панель всегда открыта, меню непрозрачное, плашка отключает значение

- **Заказ владельца:** 2026-11-12 (устно, в сессии, после правки панели фильтров)
- **Статус:** сделано, ждёт PR
- **Ветка:** `feat/facet-panel-always-open` (стеком на `feat/facet-no-spoiler-floating-chips`)

## Замысел владельца (дословно по смыслу)

1. «Убери кнопку „Фильтры“ отовсюду, пусть панель фильтров будет всегда открыта и активна и видна
   под панелью управляющих кнопок карточки или списка» — **везде, где была кнопка «Фильтры»,
   кнопки больше нет; панель всегда на виду** под тулбаром.
2. «Прозрачность выпадающего меню фильтров убери, то есть фон выпадашки должен быть непрозрачным».
3. «Сделай так, чтобы при нажатии на плашку фильтра он активировался и деактивировался» — щелчок
   по плашке снимает значение ступени, без захода в выпадашку. «Выпадашка работает хорошо, пусть
   так и будет» — меню по наведению остаётся как было.

## Что было (факты, а не догадки)

- Кнопка «Фильтры» жила в двух компонентах: `FacetToggleButton`
  (`electron-app/src/renderer/src/ui/components/FacetFilter.tsx`) и `EngineFacetToggleButton`
  (`electron-app/src/renderer/src/ui/components/EngineFacetFilter.tsx`). Использовались на
  **восьми** экранах: списки двигателей, контрактов, сотрудников, СИЗ, нарядов + отчёты
  «Двигатели», «Сейчас на заводе», «Наряды».
- Состояние раскрытости жило в состоянии списка (`facetsOpen` / `ui.facetsOpen`), а сама панель
  при закрытом флаге не рендерилась вовсе (`if (!props.open) return null;`).
- **Панель и так уже стоит ровно там, где просит владелец**: на всех восьми экранах это
  `<div style={{ marginTop: 8, flex: '0 0 auto' }}>` сразу под `<PageToolbar>`. То есть снять
  кнопку — значит просто всегда рисовать панель в этом месте.
- Фон выпадающего меню — `background: tone.panel`, а `tone.panel` это `hsl(H 70% 50% / 0.08)`:
  **8 % непрозрачности**, сквозь меню видно список под ним.
- Щелчок по плашке выбранного значения вызывал `togglePin(facet.id, option.value)` — то есть
  **прикалывал меню**, а значение не снимал. Снять значение можно было только из выпадашки:
  навести на плашку → выбрать значение в меню → оно исчезнет. Два лишних движения.

## Решение

### 1. Кнопки «Фильтры» больше нет

- `FacetToggleButton` и `EngineFacetToggleButton` **удалены** вместе с кнопкой.
- Проп `open` у `FacetFilter` / `EngineFacetFilter` **удалён**: панель не может быть свёрнутой.
- Состояние `facetsOpen` / `ui.facetsOpen` убрано из состояния списка на всех восьми экранах
  (оно жило только ради кнопки; в сохранённом состоянии остаётся безвредный хвост — читается как
  обычное поле, значение игнорируется).
- Снимок рейтинга ступеней (порядок кнопок) теперь снимается при монтировании панели и при
  смене набора ступеней — раньше он снимался в момент «открытия» панели.

### 2. Выпадающее меню непрозрачное

- Фон меню — `var(--surface)`: в темах он **непрозрачен** (светлая `#ffffff`, тёмная `#0f172a`,
  сепия `#fffaf0`), а цвет ступени остаётся виден по полосе слева (`borderLeft: 3px solid tone.accent`)
  и по цвету выбранного значения.

### 3. Щелчок по плашке снимает значение

- Обработчик плашки — `toggleFacetValue(props.selection, facet.id, option.value)`: значение
  **уходит из отбора** (toggle: было выбрано → снято, выбрано снова → снято).
- Меню, привязанное к этой плашке, закрывается: плашка могла исчезнуть, и приколотое меню
  осталось бы висеть на несуществующем элементе.
- **Выпадашка по наведению осталась как была** (владелец: «работает хорошо, пусть так и будет»):
  ячейка ступени и плашка по-прежнему открывают меню по наведению, щелчок по ячейке прикалывает
  его для планшета.

## Проверки

- Сторож `FacetFilter.guard.test.ts` — добавлены проверки: кнопки «Фильтры» нет ни в компоненте,
  ни на восьми экранах; панель не может исчезнуть (`if (!props.open) return null` запрещён); фон
  меню непрозрачный; щелчок по плашке снимает значение.
- Сторож `EnginesFacetFilter.guard.test.ts` — переписаны две проверки, которые требовали кнопки
  «Фильтры» в тулбаре и сворачиваемой панели.
- CDP-смоуки стенда: 12 файлов ссылались на `[data-facet-toggle]` — 6 из них требовали кнопки
  (переписаны под «панель всегда на виду»), 6 использовали её как запасной путь (запасной путь
  убран — панели без кнопки свёрнуться не может).

## Заводская линза

Задача не трогает производственный поток (наряды, этапы движения двигателя, акты/дефектовка,
склад/номенклатура, BOM/комплектование, прогноз сборки, бригады/сдельные расценки, отчёты ППО) —
это контур отбора в списках и отчётах. Главный затор по модели (начало сборки) не кормится и не
ломается.
