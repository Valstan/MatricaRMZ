### Контур A — что установлено и чем проверено

- OpenCode **v2.0.32**, Linux x86_64 — бинарь из npm-пакета `@opencode/cli-linux-x64@2.0.32` → `/usr/local/bin/opencode`.
- Юнит `opencode-web.service`: пользователь `opencode` (uid 1001), `serve --hostname 127.0.0.1 --port 49374`, `MemoryHigh=384M` / `MemoryMax=640M`, `PrivateTmp=yes`, `NoNewPrivileges=yes`, `Restart=on-failure`.
- Токен — `/etc/opencode-web/anon.env` (600 root), читает только юнит.
- **Авторизация — HTTP Basic** (`-u opencode:<токен>`), не Bearer: с верным токеном в `Authorization: Bearer` сервер отвечает `401 UnauthorizedError`. Рабочая переменная в v2.0.32 — `OPENCODE_SERVER_PASSWORD` (одна `OPENCODE_PASSWORD` из инструкции Мозга не взлетела; в env стоят обе).
- **Free-тир с прод-IP работает:** 12 последовательных вызовов модели `big-pickle` (provider `opencode`), `cost: 0`, ни одной ошибки. Гипотеза «серые IP хостера режет free-тир» на 20.10 **не подтвердилась**.
- RSS движка после 12 вызовов — ~340 МБ. Прод-сервисы не затронуты (оба `active`).
- **API v2 фактически отличается от рецепта #373:** `POST /api/session {title}`; `POST /api/session/<id>/prompt {"text": …}` (поле `prompt` → `Missing key at ["text"]`); `/api/session/<id>/wait` → **404**, ждать надо опросом `GET /api/session/<id>/message` (новейшие первыми; у сообщения `type=assistant` есть `completed`, а итог сессии — в отдельном сообщении `type=idle` с полем `outcome`); `DELETE /api/session/<id>` → 204.
- **Модель и запреты задаются при создании сессии** (спека — `/openapi.json` на самом движке): `model: {providerID, id}` фиксирует модель; `permissions` — массив правил `{action, resource, effect}` (`allow`/`deny`/`ask`), объектом-словарём не принимается (`Expected Permission.Ruleset | null`).
- **Замер реального запроса** (вопрос в 2 строки, ответ 500 токенов, запреты `shell`/`edit`/`write`/`webfetch`, модель `big-pickle`): ответ по-русски по делу, **96 с**, `cost: 0`. Медленно для чата — сравнить с текущим DeepSeek и с другими free-моделями до выбора.

### Контур B — спайк на PC79

- Тот же движок v2.0.32, Windows-сборка (`@opencodedesktop\resources\opencode-cli.exe`), запущен **под обычным пользователем**: `serve --hostname 127.0.0.1 --port 49380`, скрытое окно, без служб и без HKLM.

### ВПН-egress — поставлен, замерен (20.10)

Подписка NextGenVPN получена от владельца и лежит **только на боксе** (`/etc/neural/vpn/subscription.url`, 600 root) — в репо её нет и не будет.

- Разобрано **21 сервер**; `xray` + юниты `neural-vpn` / `neural-egress-redirect` + `nftables` поставлены.
- nft-таблица `ip neural` заворачивает в туннель **только TCP uid движка (1001)**; loopback и IP бокса исключены — прод-трафик (uid `valstan`) идёт напрямую, `/health` 200, оба сервиса `active`.
- Ротация работает: PL → AT, выход сменился (`91.108…` → `169.40…`), **`ActiveEnterTimestamp` движка не изменился** — перезапуска нет, как и обещал Мозг.
- **Скорость через ВПН хуже:** ответ «ok» через ВПН — **185 с** против 10–20 с без ВПН; реальный ответ (500 токенов) без ВПН — 96 с. Поэтому **ВПН — только аварийный сброс лимитов, по умолчанию трафик прямой.**

## Контур B — сделано (20.10, ветка `feat/neural-contours`)

Режим «Ииваныч на этом компьютере» собран и проверен сквозным прогоном. Что стоит в коде:

- **Менеджер движка** (`electron-app/src/main/services/localAiEngine.ts`): per-user каталог `%LOCALAPPDATA%\Programs\MatricaRMZ\engine`, скачивание npm-пакета `@opencode/cli-windows-x64@2.0.32` с проверкой **sha512** из метаданных реестра, распаковка штатным `tar.exe`, запуск скрыто (`windowsHide`, `cwd` = каталог движка), health-опрос, токен на запуск, гашение при выходе клиента. Прав администратора не требует.
- **Переключатель в окне Ииваныча**: «Сервер» / «Этот ПК», режим хранится локально (`ai.engineMode`) и применяется без перезапуска клиента. В локальном режиме строка полосы показывает состояние движка (скачивание с процентом, запуск, готов, ошибка).
- **Локальный ответ** (`localEngineSession.ts`, `localAiChat.ts`): сессия движка v2 (HTTP Basic), опрос сообщений до `idle`, ответ ложится в ту же очередь `ai_chat_requests`, но строке сразу ставится `syncStatus: 'synced'` — **вопрос и ответ не уезжают на сервер**, живут только на машине оператора.
- **Модель выбирается из каталога движка** (`GET /api/model`), а не жёстко: каталог зависит от сборки — `minimax-m3.1-flash-free` (был в спайке) на этой машине отсутствует, работает `deepseek-v4.1-flash-free`. Жёсткий id давал `provider.no-route`.
- **Доступ к базе — только чтение** (`aiLocalTools.ts`, `aiMcpProxy.ts`): движку поднимается MCP-сервер `matrica-db` с инструментами `db_schema` / `db_table` / `db_query`. Запросы исполняет клиент в loopback-мосте с одноразовым токеном; пишущий запрос отбивает **сам SQLite** (`Statement.readonly`), а не регулярка по тексту. Файлы конфига и прокси пишутся в каталог движка при каждом старте.
- **Сквозная проверка на живой машине:** движок v2 + наш конфиг + MCP-прокси + настоящая SQLite. Вопрос «сколько двигателей в базе» → модель сама сходила `db_schema`/`db_table`/`db_query` и ответила верно (2 двигателя, марки и номера). Это не юнит: проверена вся цепочка, включая чтение конфига движком (`GET /api/config` его видит) и запуск прокси.

### Открытые хвосты контура B

- **Файловые инструменты движка (`read`/`glob`/`grep`) не запрещены.** Добавление их в deny в прогоне совпало с ответом free-тира `403 FreeTierError`; причинность не доказана (возможен лимит на IP), поэтому запрет отложен и требует отдельной проверки. Риск ограничен: движок запускается с `cwd` в своём каталоге, но прочитать чужие файлы пользователя теоретически может.
- **Качество free-моделей** (96 с на реальный ответ против секунд у DeepSeek) — сравнить на пилоте, при необходимости поднять `glm-5.3-flash-free` первым кандидатом.

## Границы

- Секреты в репо не кладём: токен движка живёт только в `/etc/opencode-web/anon.env`, подписка — только на боксе.
- Движок слушает исключительно loopback; наружу не открываем.
- Инструменты `shell`/`edit`/`write` движку в продуктовых сценариях запрещаем на уровне сессии (permissions), широкий `read`-deny не ставим — ломает сам free-вызов (#373).
