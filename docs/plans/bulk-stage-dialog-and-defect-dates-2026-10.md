# Поиск и «с предыдущего этапа» в диалоге массового этапа + чистка дат дефектовки

Запрос владельца 01.10.2026. Два независимых PR.

## PR-1. BulkStageAddDialog: поиск по номеру + приоритет «с предыдущего этапа» + кнопка

Файл: `electron-app/src/renderer/src/ui/components/BulkStageAddDialog.tsx`
(открывается кнопкой «Добавить этап на движки» в `WorkSheetsPage.tsx:345`).

1. **Поиск по номеру двигателя**: `Input` над списком (`data-bulk-stage-search`,
   плейсхолдер «Поиск по номеру двигателя…»), фильтр-подстрока по подписи
   (номер + «Без номера»), как в остальных списках.
2. **«С предыдущего этапа» первыми**: при выбранном этапе двигатели, чей последний
   этап ниже по линейке, показываются группой «С предыдущего этапа» выше остальных
   («Остальные»). Поиск работает по всем двигателям завода, а не только по группе.
   - Последний этап пачкой — **новый мост** `workSheets:stages:lastMarks(engineIds)`
     поверх готового `loadEngineStageMarks` (`repairStageService.ts:329`):
     `register/workSheets.ts` (гейт `operations.view`) → `preload/index.ts` →
     тип в `shared/src/ipc/types.ts` (MatricaApi — источник правды).
     Цикл `stages:list` по каждому двигателю не годится (N IPC на сотни двигателей).
   - Ранг — по загруженным `stages.templates.list()` (`sortOrder`, учитывает
     пользовательский порядок), запасной — статичный `repairStageRank` из shared.
   - Правило приоритета: `!hasScrapBranch && (lastStageCode === null || (rank > 0 && rank < selRank))`.
     Без этапов (rank 0) — тоже в приоритете (ещё не начинали). Утиль и неизвестные
     коды — только в «Остальных». Этап не выбран — групп нет, один список + поиск.
   - Нюанс: в селекте — **виды работ** (`ukladka/val/sborka/obkatka`), а ранги —
     линейки этапов. У `val` ранга нет (= 0) → группа не строится, только поиск.
3. **Кнопка**: `Добавить на N двигателей` → `Сохранить этап для выбранных (N)`,
   busy — `Сохранение…`, статус `Добавлено:` → `Сохранено:`. Заголовок диалога не трогаем.
4. Сторож `BulkStageAddDialog.guard.test.ts` — дописать новые `data-*`/строки.
