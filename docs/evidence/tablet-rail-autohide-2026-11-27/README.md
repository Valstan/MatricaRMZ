# Живая приёмка: левое меню планшета само уезжает за край после паузы

**Дата:** 2026-11-27 · **Стенд:** `lane1` (backend 3002, БД `matricarmz_dev_lane1`, renderer 5174, CDP 9223)
**Драйвер:** `.claude/skills/verifier-electron/scripts/cdp-rail-autohide.mjs`
**Итог:** **7/7 PASS**

## Жалоба, которую закрываем

> «На планшете исчезла функция скрытия левой панели меню с плашками, надо вернуть, чтобы на
> автомате она после паузы сама исчезала» (владелец, 27.11.2026).

## Что проверялось

- приложение поднялось в планшетном режиме (платформа подменена **до** загрузки приложения —
  иначе признак «машина — планшет» решается один раз при подъёме, и подмена после старта не
  подействует);
- левая полоса разделов на месте, кнопка «Меню» (свернуть вручную) есть;
- **после паузы без действия полоса сама уехала за край**;
- ручка возврата появилась (на тач-экране вернуть меню больше нечем);
- тап по ручке вернул меню.

## Что стенд НЕ проверял

Живой планшет с настоящим сенсорным экраном: «палец на полосе» там ведёт себя иначе, чем у
эмуляции мыши (жест, начатый на полосе, превращается в скролл ⇒ `pointercancel` вместо
`pointerup` — именно этот случай закрыт в коде и юнит-тестом правила).
