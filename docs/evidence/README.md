# Доказательства приёмки: мигание кнопки «Перезапуск» (промт КАРМАНА #150)

Кадры сняты живьём на стенде `lane3` (26.11.2026) через
`.claude/skills/verifier-electron/scripts/cdp-update-restart-pulse.mjs` — клиент запущен
с `MATRICA_SIMULATE_UPDATE_BAR=quiet`, то есть состояние «обновление скачано» без реальной
закачки. Отчёт прогона: `.verifier-electron/cdp-update-restart-pulse-report.json`.

| Файл | Что показывает |
|---|---|
| `pulse-150-bright.png` | кнопка в момент пика мигания: красная рамка, красное свечение, розовая подложка |
| `pulse-150-dim.png` | та же кнопка в момент спада: красная рамка, свечения нет |
| `pulse-150-reduced-motion.png` | системная настройка «уменьшить движение»: анимации нет, **красный признак остался** |
| `pulse-150-calm.png` | обновления нет: кнопка выглядит как раньше — без красного и без мигания |

`pulse-150-dim.png` и `pulse-150-reduced-motion.png` **побайтово одинаковы** — и это не
ошибка кадра: спад мигания и режим «уменьшить движение» дают ровно одну картину (красная
рамка есть, свечения нет). Различие видно по соседним кадрам: пик мигания — с
красным свечением, которого в этих двух нет.

Проверено на стенде: `animationName = v3-restart-ready-pulse`, период 1.4 с, `infinite`;
прозрачность подложки дышит в диапазоне 0.10 → 0.24 (298 замеров за 3 с), свечение меняется
(220 различных значения `box-shadow`).
