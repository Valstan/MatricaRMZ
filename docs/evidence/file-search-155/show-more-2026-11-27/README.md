## Что проверено драйвером (33 проверки, все `PASS`)

Новое (по решению владельца):

1. по умолчанию в списке **12** подсказок (как было);
2. под списком — кнопка **«Показать ещё 8»**;
3. после клика — **20** подсказок (потолок);
4. потолок показан **честной заметкой** «Показаны первые 20 из 29», а не молча;
5. после раскрытия кнопки «показать ещё» больше нет.

Старое (переиграно тем же драйвером — правка не должна была ничего сломать):

6. три кнопки режима есть рядом со строкой поиска, выбранный режим виден заливкой и подписан словами;
7. ввод 4+ цифр даёт подсказки с полными номерами из базы, порядок — точное → суффикс → вхождение;
8. выбор подсказки **подставляет** полный номер в строку;
9. ввод словом («акт») подсказок не даёт — выпадашка не мешает вводу;
10. режим «Фото двигателя»: совпадение только по названию папки, находка — папка со всеми фотографиями; находка-файл не появляется (проверено и по экрану, и по ответу моста `fileSearch.searchFolders({ scope: 'folder' })`);
11. старый режим «В папках по названию» не сломан;
12. переключение режимов не сбрасывает отбор отмеченных картинок.

## Что вскрыл прогон: клик по подвалу гасил выпадашку

Первый прогон новой проверки дал **два FAIL** — «после „показать ещё“ — 20 подсказок» и
«потолок показан честной заметкой»: после клика список был пуст.

Причина — **в продукте, а не в измерении**: выпадашка гаснет по автоскрытию через 3 с
(общее решение владельца для всех подсказок программы), а клик по подвалу это
автоскрытие **не продлевал**. Оператор нажал «показать ещё» — и список исчез, не показав
ничего. У мыши это обычно не воспроизводится (движение мыши над выпадашкой продлевает
таймер), но полагаться на это нельзя: клик по подвалу — это взаимодействие, значит он
продлевает жизнь выпадашки.

Правка: `SuggestInput` продлевает автоскрытие при клике по подвалу (`bumpAutoHide` перед
`props.footer.onClick`). После правки — **33/33 PASS**.
