1. три кнопки режима есть рядом со строкой поиска, выбранный режим виден (заливка активной

3. выбор подсказки **подставляет** полный номер в строку (в строке ровно `Э06АТ0889`,

5. режим «Фото двигателя»: совпадение только по названию папки, находка — папка со всеми

6. старый режим «В папках по названию» не сломан: и папка, и файл находятся как раньше;
7. переключение режимов не сбрасывает отбор отмеченных картинок.

## Правка драйвера: почему в первом прогоне было 22/24

Первый прогон на этом же коде дал **два FAIL** — «в подсказках полные номера» и «порядок выдачи».
Причина — **в измерении, а не в продукте**: строка подсказки состоит из ДВУХ блоков — жирный
номер двигателя и второстепенный пояснительный текст (внутренний номер · номер РМЗ), — а драйвер
читал текст строки целиком и резал его по пробелу. Номер и порядок при этом были верными:
на кадре `04-suggestions.png` видно `0889` → `Э06АТ0889` → `Э07АТ0889` → `Э45АТ08891`.

Драйвер исправлен: номер берётся из **первого** блока строки (это и есть жирный номер двигателя),
пояснительный текст читается отдельно и попадает в отчёт. После правки — **28/28 PASS**.

Отдельно к модулю отношения не имеет: в первой приёмке (PR #2115) тот же стенд отдавал ошибку
синка `UNIQUE constraint failed: users.login` — давний артефакт общего клиентского профиля
`electron-app-cdp-9223`. Профиль стенда снесён перед прогоном, синк на этот прогон не влияет
(состояние `idle`), но ошибка — не следствие этого промта и в правках кода не участвует.
