## Что приёмка вскрыла (и что починено в этом же PR)

1. **Панель действий уезжала за нижний край окна.** Она позиционировалась как «низ полотна + 12»
   (`top = rect.top + rect.height + 12`), то есть **под** полотном: на живом клиенте низ полотна —
   1019 px при высоте окна 1025 px, и панель уезжала на 1031 px. Оператор выделял файлы и **не видел
   панели совсем** — а смоук, кликавший по кнопке из DOM, был зелёным. Починка: привязка к нижней
   кромке полотна (`bottom`), плюс сторож `DesktopPane.guard.test.ts` и проверка в самом смоуке
   («панель лежит внутри окна»), чтобы приёмка больше не могла пройти по невидимой панели.
2. **Карточка-цель не находилась поиском.** Диалог искал только серверным поиском (`GET /search`),
   а он смотрит только номенклатуру и складские документы — **двигателя в нём нет никогда**. Теперь
   диалог берёт оба слоя глобального поиска: справочники (L2 — тот же заход, что у палитры Ctrl+K) и
   сервер (L3).
3. **Оба индекса памяти — у потолка** (побочная находка): `docs/COMPLETED.md` — 153 571 байт из
   153 600, `docs/GOTCHAS.md` — 51 198 из 51 200. Новая грабля в индекс не влезает, а гейт требует
   строку индекса за каждым `gotchas/M<N>.md`. Заведена грабля [`M239`](../../gotchas/M239.md)
   (файл + строка индекса); правило то же: **упёрлись — сокращаем формулировки, а не поднимаем
   потолок**. Системная ротация индекса — решение владельца
   ([`pending/indeks-grabeley-u-potolka.md`](../../pending/indeks-grabeley-u-potolka.md)).

## Грабли смоука (не продукта)

* Неактивная панель вкладки прячется через `visibility:hidden` — по размеру её не отсечь, искать
  надо в `.v3-tab-pane[data-pane-active="1"]` (грабля M90).
* Клик мышью по строке списка доходит до React только событиями **из страницы** (mousedown+mouseup+click
  с bubbles) — `Input.dispatchMouseEvent` не годится (грабля M160).
* Меню действий живёт в **портале** (`PopupLayer`) — он вне панели вкладок, искать по всему документу.
* Оверлей МЕНЮ накрывает всё окно: пока он открыт, клик мимо по Верстаку не доходит.
* Профиль клиента `electron-app-cdp-9223` содержит дубль пользователя ⇒ синк падает
  `UNIQUE constraint failed: users.login`; лечится свежим профилем (свой CDP-порт), а не повтором прогона.
* **Список вложений длиннее порога сворачивается** в кнопку «▶ Показать файлы (N)» — тогда ИМЁН файла
  в тексте страницы нет (есть счётчик и галерея). Приёмка должна развернуть список, как это делает
  оператор, иначе проверка «видно ли имя» врёт: файлы приложены, а имя лежит за кнопкой.
* Проверка «панель на экране» — по прямоугольнику панели против окна: кнопки в DOM есть и при
  панели за нижним краем окна (клик из DOM сработает, оператор ничего не увидит).
