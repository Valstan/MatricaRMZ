# M199 — Спойлер `<details>` помнит раскрытость, пока панель смонтирована: замер «на виду пять ступеней» краснеет на размонтированной панели

**Область:** панель фильтров (`electron-app/src/renderer/src/ui/components/FacetFilter.tsx`), CDP-смоук `cdp-facet-panel.mjs`

- **Симптом:** CDP-смоук панели фильтров падает на проверке «на виду ступеней не больше пяти» —
  пересчитывает **23** ступени, хотя спойлер «Ещё 18 ▾» на экране закрыт. Скриншот при этом
  показывает либо закрытый спойлер (хвоста нет), либо раскрытый хвост — в зависимости от того,
  когда снят кадр. Проверено 12.11.2026 на списке двигателей.

- **Корень:** **раскрытость `<details>` — состояние DOM-узла, а не состояние React.** Пока
  панель смонтирована (она живёт, пока открыта), узел `<details data-facet-more="fields">`
  помнит, был ли он раскрыт: React не управляет атрибутом `open` (свойства у элемента нет),
  поэтому перерисовка панели — сброс отбора, выбор значения, рейтинг — **не закрывает**
  раскрытый спойлер. Сворачивание панели фильтров (`if (!props.open) return null`) размонтирует
  её, и следующий показ открывает **чистый** (закрытый) спойлер. Итог: в одном прогоне панель
  «помнит» раскрытый хвост, в следующем — нет, и замер даёт то 5, то 23 ступени.

- **Второй слой ловушки:** закрытый `<details>` в Chromium **не рисует** содержимое, но
  **сохраняет геометрию** (скрытие идёт через `::details-content`/`content-visibility`, см.
  [M178](M178.md)). Поэтому `getBoundingClientRect` у спрятанных кнопок не нулевой, и
  «нарисован ли элемент» нельзя судить по прямоугольнику — только по предку-`<details>`
  (функция `painted()` в CDP-драйверах).

- **Диагностика:** спросить у узла прямо, а не выводить по картинке:

  ```js
  const d = document.querySelector('[data-facet-more="fields"]');
  ({ openProp: d.open, openAttr: d.getAttribute('open'), cells: d.querySelectorAll('[data-facet-field]').length });
  ```

  `openProp === false` при нарисованном хвосте = хвост раскрыт **и** рисуется (значит, спойлер
  открыт); `openProp === false` при спрятанном хвосте = нормальное закрытое состояние.

- **Лечение:** перед замером закрывать спойлер **руками** и ждать отрисовки:

  ```js
  const more = document.querySelector('[data-facet-more="fields"]');
  if (more && more.open) { more.open = false; await wait(400); }
  ```

  Так и сделано в `cdp-facet-panel.mjs` (шаг «Ряд ячеек»). Второй путь — перемонтировать
  панель (свернуть и развернуть), но это медленнее и теряет отбор.

- **Чего НЕ делать:** не судить о «видимости хвоста» по `getBoundingClientRect` (см. [M178](M178.md))
  и не считать, что панель «перерисовывается чисто» — раскрытость спойлера переживает любую
  перерисовку, пока узел жив.
