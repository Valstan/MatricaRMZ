# M125 — хэш chat id совпал у двух ботов, а чат не общий

**Область:** Telegram / идентификаторы

- **Симптом:** `sha256(MATRICA_TELEGRAM_ALERT_CHAT_ID)` совпал с хэшем у соседнего проекта — вывод «чат оповещений общий», решение владельца развести чаты (D-083). У владельца при этом «1 общая группа» с ботом, тревоги приходят в личку.
- **Корень:** номер личного чата в Telegram равен номеру пользователя и осмыслен только в паре «бот — пользователь». Одно значение у двух ботов — две разные лички. Хэш доказал совпадение значения, а не объекта.
- **Проверка до вывода:** `getChat?chat_id=…` → `type` (`private` / `group` / `supergroup` / `channel`). Один вызов на чтение, значение печатать не нужно. `leaveChat` к личному чату неприменим.
- **Попутно:** бот не отвечал владельцу на `/sync_chat_id` ни в группе, ни в личке — отвечает только суперадмину по `telegram_login` карточки, а там было другое имя. Отброшенные сообщения не логировались; с 10.09 — след `telegram bot ignored a message…` с чатом и отправителем.
- **Общая форма:** совпадение идентификатора из локального пространства имён не доказывает совпадения объекта — спроси у владельца пространства имён тип объекта за значением.
- **Поймано:** 2026-09-10, скриншот владельца + `getChat`.
