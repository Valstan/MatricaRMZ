# M233 — Смоук снял оверлей приветствия, а не карточку: кнопка «За работу! (Enter)» не находилась точным сравнением

**Область:** CDP-смоуки `verifier-electron` (`.claude/skills/verifier-electron/scripts/cdp-*.mjs`), окно приветствия релиза (`release-welcome-overlay`, `electron-app/src/renderer/src/ui/App.tsx`).

- **Симптом:** смоук зелёный (`PASS`, exit 0), в логе правдоподобные замеры (просвет между счётчиком и первой кнопкой 8 px, правый край самой правой кнопки 798 px при экране 1024 px), а **снимки экрана показывают полноэкранное окно «Что нового в программе»** вместо проверяемой карточки. Правка выглядит проверенной, но картинка этого не доказывает.
- **Корень:** кнопка закрытия окна приветствия называется **«За работу! (Enter)»** (`App.tsx`), а смоуки искали её **точным** сравнением `x.textContent.trim() === 'За работу!'` ⇒ кнопка не находилась, оверлей оставался на экране. При этом DOM за оверлеем был живой: замеры `getBoundingClientRect` шли по нужным элементам и были **верными** — расходились только снимки. Второй признак той же болезни: на снимке бейдж старой версии («Обновление 3.146.0», «Прошлая версия здесь: v3.145.0») — то есть снимок снят не с того клиента, который проверяем.
- **Диагностика:** (1) **открыть снимок и посмотреть, что на нём** — картинку проверяют глазами, а не по факту, что файл создался; (2) в смоуке печатать, какие кнопки оверлея нашлись при гашении (пустой список — уже приговор); (3) спросить у живого рендерера `Boolean(document.querySelector('.release-welcome-overlay'))` — если оверлей есть, снимок бесполезен; (4) сверить версию в бейдже на снимке с текущей — расхождение = снимок не с того клиента.
- **Лечение:** искать кнопку по **началу** подписи (`t.startsWith('За работу')`), а не по точному равенству; после гашения оверлея **проверять его отсутствие** и только потом снимать скриншот; помнить: **скриншот — не ассерт**, ассертом считается геометрия из DOM. Обход гашения оверлеев по смоукам — 16 скриптов с точным сравнением (список в [`pending/knopki-vpravo-obhod-renderer.md`](../pending/knopki-vpravo-obhod-renderer.md)).
- **Понятки:** 2026-11-26, полоса 2 (worktree `.claude/worktrees/m2`), промт КАРМАНА #141. Смоук `cdp-history-buttons-left.mjs` (добавлен PR #2048) отработал «зелёно», но все три снимка были оверлеем. После починки гашения перепрогон на стенде `lane2` (PC79, backend 3003, renderer 5175, CDP 9230) дал **тот же** результат по замерам (просвет 8 px, правый край 839 px при экране 1024 px, `scrollWidth = clientWidth = 900`) и настоящую картинку карточки: «История ремонта» → счётчик → «Добавить запись» → «Добавить этап ремонта» → «Перенести этапы…» слева.
- **Правило на будущее:** смоук, который снимает скриншот, обязан **сначала доказать, что снимает нужный экран** (оверлей закрыт, элемент виден), иначе «доказательство» — картинка чужого экрана, а её легко принять за успех. И **снимок смотришь глазами** — это дешёвый шаг, который ловит ровно эту поломку.
