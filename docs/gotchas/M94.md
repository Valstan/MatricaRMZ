# M94 — запущенный `.ps1` исчезает с диска, `powershell` выходит с кодом 21 и пустым выводом

**Область:** антивирус / инструменты

- **Симптом:** скрипт отработал два-три раза нормально, потом запуск стал давать `exit=21` без единой строки вывода (ни stdout, ни stderr), а сам файл `.ps1` **пропал с диска**. Соседние файлы того же каталога на месте, копия, которую не запускали, — тоже. В журнале Windows (`Application`) ни одной записи.
- **Корень:** Касперский. Скрипт опрашивал `avp.com`, реестр, планировщик и резолвил адрес сервера — для неподписанного PowerShell это готовый профиль поведения; вердикт «созревает» не с первого запуска, поэтому начало выглядит рабочим. Тот же почерк, что уносил каталог приложения и плановые задачи (brain #192, D-044).
- **Диагностика:** разделить «удаляет при запуске» и «удаляет фоновым сканом» — положить файл и НЕ запускать (у нас пролежал спокойно), затем запустить и проверить наличие сразу и через минуту. Пустой вывод при этом легко списать на обрыв пайпа — проверять редиректом в файл, а не через `| head`.
- **Лечение:** сначала исключение антивируса на каталог, потом запуск. Файл держать в git — тогда он восстанавливается `git checkout -- <путь>`, а не переносится заново из источника.
- **Цена ошибки:** инструмент, который настраивает исключения антивируса, сам удаляется антивирусом до того, как исключения внесены. Порядок «инструмент → исключения» не работает; работает только «исключения → инструмент».
- **Поймано:** 2026-08-26, перенос `scripts/client-ops/` (три воспроизведения подряд).
