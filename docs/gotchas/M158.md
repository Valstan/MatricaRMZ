# M158 — Свежий `data-`атрибут есть в файле компонента, но не в DOM: dev-сервер отдаёт прежний модуль

**Область:** стенд / HMR

- **Симптом:** правишь компонент (например, добавляешь `data-wo-print-export="word"`), гоняешь CDP-смоук — атрибута в DOM нет, хотя кнопка, добавленная правкой раньше, на месте и живая. `querySelector` возвращает `null`, и смоук честно докладывает «кнопки нет», хотя она есть.
- **Корень:** стенд живёт между прогонами, а Vite/HMR доносит не каждую правку в уже собранный модуль. `fetch('/src/ui/…/X.tsx').then(r => r.text()).includes('data-…')` = `false` при `true` в файле: сервер отдаёт прежнюю сборку, DOM показывает её же. Перезагрузка окна в начале прогона это лечит, но **закладываться на свежесть нельзя**.
- **Что делать:** начало смоука — `Page.reload` с `ignoreCache: true`; проверку двери строить по подписи внутри контейнера (атрибут — приоритетный путь, подпись — запасной), а не только по атрибуту-новинке. Быстрый вопрос «что реально отдаёт сервер» — одноразовый зонд (`.verifier-electron/probe.mjs`: подключиться к окну и выполнить выражение).
- **Поймано:** 2026-10-19, `cdp-card-export.mjs` (P5b-1).
