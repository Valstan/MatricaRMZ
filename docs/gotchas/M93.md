# M93 — плановая задача «при входе» отсутствует на всех машинах, а лог твердит `schtasks create failed`

**Область:** watchdog / Windows

- **Симптом:** `Get-ScheduledTask -TaskPath '\MatricaRMZ\*'` возвращает одну задачу вместо двух — `Watchdog Periodic` есть, `Watchdog Logon` нет. В `matricarmz.log` при каждом старте клиента `watchdog heal: schtasks create failed for MatricaRMZ\Watchdog Logon`, а следом текст в cp866, который в UTF-8-консоли выглядит мусором и потому не читается: «ОШИБКА: Отказано в доступе».
- **Корень:** `schtasks.exe` **не умеет** создать logon-задачу для текущего пользователя без прав администратора. Замер (Windows 11 22631): `/SC ONLOGON` → отказ, `/SC ONLOGON /RU <имя>` в любой форме имени → отказ, `/SC ONSTART` → отказ, `/SC MINUTE /MO 15` тем же вызовом → успех. PowerShell-API это умеет (`New-ScheduledTaskTrigger -AtLogOn -User <имя>` проходит; без `-User` — тоже отказ, потому что это «при входе любого пользователя»), но powershell как дочерний процесс запрещён ADR-0002 как LOLBin-триггер.
- **Диагностика:** не гадать про антивирусный свип — свип уносит задачу разово, а тут ровный ряд неудач. Отделяется одним опытом: создать пробную задачу в **своём** пространстве имён двумя расписаниями (`/SC MINUTE` и `/SC ONLOGON`) и сравнить коды возврата. Разные исходы = ограничение прав, одинаковые = что-то внешнее. Пробы потом снять.
- **Лечение:** автозапуск при входе — **ярлык в папке автозагрузки** (`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`), нативным `shell.writeShortcutLink`; прав не требует, powershell не поднимает. Сторож собран `-H=windowsgui`, поэтому консоль при входе не мелькает.
- **Цена ошибки:** самолечение годами делало невозможное и молчало об этом в локальный файл. Отсюда правило: неудача самолечения обязана иметь канал наружу (у нас — `POST /client/watchdog/report`, kind `autostart_broken` → «Критические события»), иначе поломки страховки не видит никто.
