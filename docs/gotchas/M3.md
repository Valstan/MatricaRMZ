# M3 — ложный TS2305 на @matricarmz/shared

**Область:** monorepo / typecheck

- **Симптом:** `corepack pnpm -r typecheck` выдаёт на `@matricarmz/shared` ложные `TS2305` (нет экспорта), `TS2339` (нет свойства) или `TS2353` (лишний ключ) — хотя в исходниках `shared/src` всё есть.
- **Корень:** гонка пересборки `shared/dist` — параллельные пакеты тайпчекаются против полу-собранного dist. Первый пакет, попавший на гонку (обычно `android-app`), и получает ошибки.
- **Диагностика:** проверить, есть ли экспорт в исходнике и в `shared/dist`: если в `shared/src` есть, а ошибка есть — это гонка, а не правка. **Второй прогон того же `pnpm -r typecheck` (dist к этому моменту уже пересобран) — зелёный.**
- **Лечение:** гонять typecheck **по пакетам последовательно**, не `-r` разом. Второй прогон после `corepack pnpm --filter @matricarmz/shared build` — тоже зелёный.
