# M189 — `signtool sign` не заменяет чужую подпись, а добавляет вторую: подписавший остаётся прежним

**Область:** [M189](#m189--signtool-sign-не-заменяет-чужую-подпись-а-добавляет-вторую-подписавший-остаётся-прежним)

- **Симптом:** файл подписан Microsoft (`d3dcompiler_47.dll`, `dxil.dll` из поставки Electron). Скрипт подписи отработал без ошибки («Successfully signed»), но `Get-AuthenticodeSignature` по-прежнему показывает подписавшего **Microsoft**. Ощущение, что подпись не легла. Повторный прогон подписывает ещё раз — файл растёт, подписавший не меняется.
- **Корень:** `signtool sign` **не заменяет** существующую подпись, а **добавляет** вторую в таблицу сертификатов PE. Первичной остаётся старая (та, что в слоте 0). Проверено на PC79 04.11.2026: `where.exe` (подписан Microsoft) после `signtool sign` — размер 65 536 → 67 448 байт, подписавший в `Get-AuthenticodeSignature` прежний. `signtool remove /s` (попытка снять чужую подпись) падает с `CryptSIPRemoveSignedDataMsg returned error: 0x00000057` — снять чужую подпись штатно нельзя.
- **Почему это ломает логику «подписать всё своим ключом»:** наша подпись встаёт вторичной, а доверенным файл остаётся по подписи Microsoft. Значит подписывать поверх чужой подписи бессмысленно — правильнее не трогать такой файл вовсе.
- **Диагностика:** отвечать на вопрос «подписаны ли мы» надо **отпечатком подписавшего**, а не статусом цепочки: статус `Valid» означает «подпись есть и цепочка сходится» — и для подписи Microsoft он тоже `Valid`. У неподписанного файла `SignerCertificate` = null вовсе.
  ```powershell
  $sig = Get-AuthenticodeSignature $file
  $sig.SignerCertificate.Thumbprint   # '' → подписи нет; иначе — кто подписал
  ```
- **Лечение:** правило в инструменте — подписывать только то, что не подписано ничем; уже подписанное **нашим** ключом пропускать (идемпотентность); подписанное чужим — не трогать (у нас это `d3dcompiler_47.dll` и `dxil.dll`, подписанные Microsoft: публичный CA, Касперский доверяет им сам). Реализация — [`scripts/signing/sign-matrica.ps1`](../../scripts/signing/sign-matrica.ps1), функция `Invoke-Sign`; приёмка — `sign-matrica.tests.ps1`.
- **Сторожа:** [`scripts/signing/sign-matrica.tests.ps1`](../../scripts/signing/sign-matrica.tests.ps1) (16 проверок, включая случай «файл с чужой подписью не переписывается»).
