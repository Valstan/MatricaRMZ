# M170 — `logger -t <tag>` на боксе не виден ни в journald, ни в syslog

**Область:** прод / журналы

- **Симптом:** сторож пишет `logger -t tunnel-watchdog -- "..."`, а `journalctl -t tunnel-watchdog` отвечает `-- No entries --`; `grep tunnel-watchdog /var/log/syslog*` — пусто, хотя `rsyslog` активен. Сторож молчит, и «он же пишет» — иллюзия (тот же класс, что M164: логи не там, где ищем).
- **Корень:** на боксе `/dev/log` не доходит до journald так, как ожидается, а rsyslog фильтрует facility/уровень. Записи теряются молча — диагностического сигнала нет вовсе.
- **Лечение:** писать **файл** (`/var/log/neural/<служба>.log`, `640`), а `logger` оставлять best-effort. Проверять появление записи сразу после установки — «включил журнал» без проверки считается невключённым.
- **Поймано:** 2026-10-24, установка сторожа туннеля: `journalctl -t tunnel-watchdog` пуст после успешного `--force-rotate`.
