# M174 — вопрос висит в `pending` вечно, потому что счётчик попыток обнуляется в ветке исключения

**Область:** AI / очередь / счётчик попыток

- **Симптом:** строка `ai_chat_requests` не отвечена и не эскалирована, живёт часами; каждые ~9 минут в журнале `credit exhausted`, а суперадмину не приходит ничего. Ощущение «очередь работает, но не по этому вопросу».
- **Корень:** в ветке «счёт LLM кончился» (`isCreditExhausted`) стоял `attempts.delete(id)` — счётчик неудач обнулялся на каждом круге, поэтому `failed >= MAX_ATTEMPTS` не наступал **никогда**. Классическая ловушка: «отпустить строку в очередь» и «считать попытки» — разные вещи, и `delete` рядом с `return` выглядит как уборка, а на деле отключает предохранитель.
- **Лечение:** в любой ветке, где строка **возвращается** в очередь, счётчик попыток инкрементируется, а `delete` — только вместе с эскалацией. Тест-сторож: `aiChatAnswerService.test.ts` (три падения по 402 → `escalated` + DM суперадмину).
- **Поймано:** 2026-10-25, разбор зависшего вопроса оператора: код читался «правильно», пока не спросили, где именно обнуляется счётчик.
