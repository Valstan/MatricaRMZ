# M157 — CDP-скрипт не завершается после отчёта; форс-выход роняет node ассершеном libuv

**Область:** скрипты / CDP

- **Симптом:** `.mjs`-смоук дописал отчёт и все проверки, а процесс живёт: терминал ждёт, `Select-Object -Last N` ничего не показывает до самого конца — выглядит как зависание на середине прогона. Если добавить `process.exit()` сразу после закрытия сокетов — падение `Assertion failed: !(handle->flags & UV_HANDLE_CLOSING)` и код `0xC0000409` при полностью зелёных шагах.
- **Корень:** открытые `WebSocket`-сокеты CDP держат цикл событий — node выходит не тогда, когда скрипт закончил, а когда сокеты закрылись по-настоящему. Закрывать их надо с ожиданием события `close`, а форсированный выход поверх незакрытых дескрипторов ломает libuv (только Windows).
- **Лечение:** `closeAll()` — `terminate()` и ожидание `close` по каждому сокету; выход **без** `process.exit()`: выставить `process.exitCode` и дать циклу опустеть; на случай залипшего сокета — `unref()`-сторож на 15 с, который просто завершает процесс.
- **Поймано:** 2026-10-19, `cdp-list-print.mjs` (P4).
