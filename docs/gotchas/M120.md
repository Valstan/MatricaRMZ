# M120 — замер ширины в скрытой вкладке и признак, потерянный горячей перезагрузкой

**Область:** UI / замеры

Одна и та же правка (ряд кнопок в одну строку) принесла два независимых промаха; оба видны только в живом окне.

- **Нуль вместо ширины.** Закрытые вкладки остаются в DOM скрытыми, и `getBoundingClientRect()` в них даёт нули. Кэш «ширины на состав ряда» пишется один раз, поэтому замер, случившийся до показа вкладки, навсегда объявлял ряд шириной 0 — переполнение не срабатывало ни при какой ширине окна. Лечение: пока `row.clientWidth <= 0`, замер не запоминается; эффект перезапустится, когда ряд появится на экране.
- **`child.type === Component` не переживает Fast Refresh.** Признак «не убирать в меню» определялся сравнением типа обёртки. После горячей перезагрузки React подменяет функцию, сравнение перестаёт совпадать — и в меню уезжает всё подряд, включая поле поиска. То же будет и от минификации имён. Лечение: признак ставится РАЗМЕТКОЙ (`data-toolbar-pin` + `display: contents`) и читается из DOM при замере.
- **Следствие для смоуков:** любой запрос вида `document.querySelector(...)` на этом экране может попасть в копию со скрытой вкладки — щелчок «сработает» и ничего не сделает. Все запросы драйвера фильтруются по видимости (`getClientRects().length > 0`), а тулбар и панель ищутся ОТ таблицы своего списка: на экране бывает две панели с двумя списками сразу.
