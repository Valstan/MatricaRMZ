# M161 — прогоны смоука копят карточки в полосе вкладок, закрывать их приходится человеком

**Область:** стенд / смоук

- **Симптом:** после серии прогонов полоса вкладок забита карточками («🛠 Наряд № 6» … «№ 15», «⚙ TEST-001»); владелец закрывает их руками. Со стороны это выглядит как «карточка не открывается кликом», а на деле падение смоука совпало с тем, что владелец в этот момент чистил вкладки.
- **Корень:** смоук открывает карточку и не закрывает её, а стенд живёт между прогонами — полоса растёт от прогона к прогону. Жёсткого потолка вкладок в приложении нет (`shouldWarnTabsCount` только предупреждает начиная с 11), поэтому копится до вмешательства человека. Штатной команды «закрыть все вкладки» в UI тоже нет: закрыть можно кнопкой `button.v3-tab-close` внутри `.v3-tab` (или контекстным меню, но там только «на Верстак»).
- **Что делать:** смоук убирает за собой — метла при старте и закрытие в конце по подписям **своих** карточек (`Наряд\s*№\s*\d+`, `^⚙`). Чужую несохранённую работу не трогать: если при закрытии всплыл dirty-guard («Не сохранять») — закрытие **отменить** («Перейти в карточку»), вкладку оставить. Карточки закрываются через `closeTabById` (`App.tsx`), закрытие карточки пишется через `closeV2Card`.
- **Поймано:** 2026-10-19, `cdp-card-export.mjs` (P5b-2); владелец закрыл ~15 накопленных карточек вручную.
