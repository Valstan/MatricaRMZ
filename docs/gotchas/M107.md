# M107 — два счётчика номеров против одного первичного ключа: смена генератора на живой системе

**Область:** выкат / sync

- **Симптом (поймано ДО прода, состязательной ревизией 06.09.2026):** при выкате журнала в PostgreSQL миграция ставила `setval('ledger_seq', max(server_seq), true)`, а порядок выката был «мигрировать → собрать → перезапустить инстансы». В этом окне старая сборка ещё работает и раздаёт номера из своего файлового счётчика (`index.json` цепочки), записывая их в ту же `ledger_tx_index`, где `server_seq` — первичный ключ.
- **Два исхода, и второй хуже первого.** (1) Новый инстанс берёт номер, который старый уже занял: `duplicate key value violates unique constraint`, вся транзакция журнала откатывается, `/ledger/tx/submit` отвечает 400. nginx балансирует между старым и новым инстансом, поэтому примерно половина пушей парка падает, вторая проходит. (2) Наоборот, старый инстанс берёт номер, который новый уже отдал: его вставка в журнал шла с `onConflictDoNothing`, то есть **молча** пропадает, а строку sync-таблицы он всё равно штампует этим номером. Клиент, чей курсор уже прошёл это число, не получит строку никогда — pull отбирает по `last_server_seq > since`.
- **Почему не ловится глазами:** первый исход громкий, второй бесшумный, и оба выглядят как «сеть барахлит». Метрика отставания журнала при этом показывает ноль: она сравнивает таблицу саму с собой.
- **Правило:** генератор номеров (последовательность, счётчик, id-сервер) меняется только при **остановленных писателях**. Ротацию «на живую» не спасает ни точный `setval` (он устаревает между `SELECT` и `COMMIT`), ни зазор в номерах (он закрывает отказ записи, но не невидимую строку).
- **Страховка в коде:** `ledgerService.ensureSequenceAheadOfJournal` поднимает последовательность до максимума таблицы и повторяет запись при `23505` — это делает занятый номер восстановимым состоянием, а не отказом. От второго исхода не спасает ничто, кроме останова писателей.
- **Родня:** M30 (тот же класс с другой стороны — писатель со своим, отставшим счётчиком), M104 (журнал и хранилище расходятся при обрыве).
