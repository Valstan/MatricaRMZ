# M242 — Джоб CI падает «unhandled ENOENT» при зелёных тестах: отменённый поиск оставляет промис чтения без обработчика

**Область:** `electron-app/src/main/services/searchAbort.ts` (`raceWithAbort`) и всё, что через
неё читает диск: `fileSearchFolderService.ts`, `fileSearchService.ts`. Симптом видно в тестах
обхода папок (`fileSearchFolderService.progress.test.ts`), но бьёт по любому прогону electron-app
в CI.

- **Симптом:** джоб CI «Test electron-app» падает при **полностью зелёных тестах**
  («Tests 3299 passed», «Errors 1 error»), а в логе — `Unhandled Rejection`:
  `ENOENT: no such file or directory, scandir '/tmp/matrica-folder-progress-XXXX'` и
  «This might cause false positive tests». Красный джоб при зелёных проверках читать как
  «моя правка сломала» — не надо: это висящий отказ, а не проваленный тест.
- **Корень (найден 27.11.2026):** в `raceWithAbort` ветка «сигнал УЖЕ отменён» возвращала
  `Promise.reject(new SearchCancelledError())`, **не взяв исходный промис под руку**. Дальше
  тест сносил временный каталог (`rmSync(dir)` в `afterEach`), а фоновое чтение папки ещё жило:
  его поздний ENOENT прилетел без обработчика ⇒ необработанное отклонение ⇒ vitest роняет
  прогон. На живом сигнале (отмена во время чтения) ветка была другой, и там промис брался под
  руку — потому симптом и был «от случая к случаю».
- **Диагностика:** прогнать файл в одиночку — `corepack pnpm -F @matricarmz/electron-app exec
  vitest run src/main/services/fileSearchFolderService.progress.test.ts`. Часто зелёный (гонка по
  времени: при тёплом кэше чтение успевает завершиться) ⇒ симптом не воспроизводится локально,
  но он РЕАЛЕН: в CI он случился дважды (PR #2134 и PR #2135).
- **Лечение:** починена **по построению** — в ветке «сигнал уже отменён» исходный промис
  берётся под руку (`promise.catch(() => undefined)`): отказ, который придёт позже, больше не
  станет необработанным. Сторож — новый тест `searchAbort.test.ts` (поздний отказ при уже
  отменённом сигнале).
- **Понято:** 27.11.2026. PR **#2134** (docs-only) — красный джоб при 3294/3294 зелёных,
  перезапуск помог. PR **#2135** («проставить вид пачкой») — тот же симптом: `Unhandled
  Rejection … scandir '/tmp/matrica-folder-progress-SOmjPl'`, все 3299 тестов зелёные.
  Починка — в этом же PR.
- **Правило на будущее:** красный джоб при зелёных тестах и `ENOENT` по временной папке — это
  висящий отказ фонового чтения, а не твоя правка. Порядок: файл в одиночку → перезапуск
  джоба → (если повторяется) смотреть `raceWithAbort` и тесты, снимающие каталоги под фоном.
