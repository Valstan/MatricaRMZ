# M130 — `,$array` из функции PowerShell не разворачивается в конвейере, и отчёт печатается одной строкой

**Область:** [M130](#m130--array-из-функции-powershell-не-разворачивается-в-конвейере-и-отчёт-печатается-одной-строкой)

- **Симптом (14.09.2026):** `lan-share-firewall.ps1 -Verify` вывел три строки отчёта склеенными через пробел в одну. Ни ошибки, ни обрезки — просто нечитаемо.
- **Корень:** идиома `,$lines` в конце функции нужна, чтобы массив из ОДНОЙ строки не схлопнулся в скаляр — она оборачивает результат, и обёртку разворачивает выводом ровно один раз. Дальше по конвейеру уезжает **сам массив как один элемент**, и `| ForEach-Object { Write-Host $_ }` печатает его через строковое представление массива.
- **Лечение:** потребителю — `foreach ($line in (Get-Отчёт …)) { … }` вместо `| ForEach-Object`. Присваивание (`$x = Get-Отчёт`), `+=` и передача в параметр `[string[]]` с `,` работают правильно — ломается именно конвейер.
