# M144 — строка списка открывает карточку только настоящим кликом мыши, а панели закрытых карточек остаются в DOM

**Область:** смоук / CDP / клики

**Симптом.** CDP-смоук находит строку списка, шлёт ей `mousedown`/`mouseup`/`click`, ждёт карточку — карточки нет. Драйвер честно повторяет клик десяток раз и сдаётся с «панель не появилась», хотя строка на месте, права есть и карточка открывается руками. Поймано 22.09.2026 на списке нарядов.

**Корень.** Строка списка открывает карточку обработчиком на `<tr>` (`rowProps` в `WorkOrdersPage`, `onClick` → `props.onOpen(row.id)`), и синтетический `MouseEvent`, собранный в странице, до него не доходит. Лечится доменом CDP `Input`, то есть настоящим кликом по координатам:

```js
const r = await evaluate(ws, `const q = rows[0].getBoundingClientRect(); return { x: Math.round(q.x + q.width/4), y: Math.round(q.y + q.height/2) };`);
await send(ws, 'Input.dispatchMouseEvent', { type: 'mousePressed', x: r.x, y: r.y, button: 'left', clickCount: 1 });
await send(ws, 'Input.dispatchMouseEvent', { type: 'mouseReleased', x: r.x, y: r.y, button: 'left', clickCount: 1 });
```

Тем же способом жмутся **вкладки карточки**: синтетику они игнорируют так же. Кнопки диалогов и меню при этом синтетику принимают — правило не «всё через Input», а «строки и вкладки через Input».

**Вторая половина той же грабли — keep-alive.** Закрытые карточки остаются в DOM скрытыми, поэтому `document.querySelector('[data-card-tab="signatures"]')` отдаёт панель ЧУЖОЙ, давно закрытой карточки: смоук меряет её геометрию, видит нули и рапортует «вкладка пустая», хотя открытая карточка в порядке. Брать только видимые узлы (`vis(...)`), и это же правило — в `cdp-engine-act-tabs.mjs`.

**Третья ловушка прогона:** модал «Карточка закрывается» переживает падение драйвера и достаётся следующему прогону, перекрывая собой карточку целиком — все клики уходят в оверлей. Смоук обязан гасить его на входе наравне с «За работу!» и «Отклонить».

**Сторож класса:** `.claude/skills/verifier-electron/scripts/cdp-owner-batch-work-orders.mjs` — все три приёма записаны в нём комментариями.
