# M114 — `Boolean('false')` — это истина: булев флаг из EAV имеет три представления

**Область:** EAV / отчёты

- **Симптом:** двигатель числится утильным / отремонтированным / забракованным, хотя в карточке галочка снята. Ошибок нет, у большинства строк всё верно, воспроизводится только на «тех самых» записях.
- **Корень:** в EAV одно и то же «нет» лежит **тремя** способами — настоящим булевым `false` (так пишет карточка), строкой `'false'` (импорт 11.06.2026) и отсутствием строки вовсе. Код снимал флаг как `Boolean(attrs[code])`, а `Boolean('false') === true`. На проде 23 значения-строки, из них 14 — `'false'`: `status_rejected` ×4, `status_repaired` ×3, `status_repair_started` ×3, `status_rework_sent` ×3, `status_customer_sent` ×1.
- **Зеркальная форма, не менее тихая:** строгое `value === true` роняет строковое `'true'` из того же импорта. Так читал гейт выдачи наряда сборки: утильный двигатель со строковым флагом гейт бы пропустил. На проде утильных флагов строкой `'true'` не оказалось — повезло, а не защитило.
- **Третья форма, худшая:** `normalizeText(attrs.flag, '')` — он возвращает **строку**, и `'false'` в условии истинна. Так селектор «Комплектование двигателя» прятал 147 живых двигателей из 378, у которых метку утиля когда-либо ставили и снимали.
- **Почему держалось:** на подавляющем большинстве записей все три разбора дают одно и то же — расходятся они ровно на строках-исключениях, которых в фикстурах не было. Плюс разнобой внутри одного файла: `resolveEngineShippingState` читал те же поля строгой проверкой и отвечал правильно, а `statusFlags` рядом — нет.
- **Диагностика:** `SELECT ad.code, av.value_json, count(*) … WHERE av.value_json LIKE '"%'` — сколько булевых атрибутов лежит строками. Если больше нуля, любой `Boolean(...)` и любой `=== true` по этому полю подозрителен.
- **Лечение:** один разбор на весь проект — `isEavFlagSet` (`shared/src/domain/contract.ts`), плюс `statusFlagsFromAttrs` для снимка всех статусов. Ручных `Boolean(attrs[flag])` по EAV в коде не остаётся. Данные не чинили: чинить представление в БД можно, но читатель обязан быть устойчив и без этого.
- **Поймано:** 2026-09-07 сплошной ревизией отчётов после M113. Родня: M112 (то же «два представления одного значения», но на ссылке против текста).
