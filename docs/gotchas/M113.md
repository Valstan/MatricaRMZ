# M113 — «всего» больше суммы своих подколонок: разбивка не покрывает всё множество

**Область:** отчёты / инварианты

- **Симптом:** владелец читает бумагу и спрашивает, куда делись строки. «Движение двигателей по заказчикам»: утиль всего **5**, утиль на заводе **3**, утиль отправлен **0** — двух двигателей нет нигде, при том что общий итог сходится (`пришло 20 = отгружено 11 + утиль отправлен 0 + на заводе 9`) и подпись под таблицей уверенно печатает «из них ещё на заводе 3, возвращено заказчику 0».
- **Корень:** «утиль» — это признак, а состояний у двигателя три (уехал утилем · уехал не утилем · на заводе), и разбивка накрывала только два из них. Утильным двигатель признаётся флагом `status_scrap_confirmed` **или** `status_rework_sent`, а колонка «утиль отправлен» читала **только второй** флаг. Двигатель, признанный утильным и уехавший заказчику обычной отгрузкой, попадал в «отгружено заказчику» и выпадал из разбивки утиля. На проде 07.09.2026 таких **39** из 231 утильного (188 на заводе, 5 по флагу возврата, 39 потерянных).
- **Почему держалось:** проверялись инварианты `пришло = отгружено + утиль отправлен + на заводе` и `на заводе = утиль на заводе + в ремонте` — оба **истинны** и при дыре, потому что потерянные строки честно лежат в «отгружено». Третьего инварианта — `утиль всего = утиль на заводе + утиль отправлен` — не было ни в коде, ни в тестах, а фикстура не содержала ни одного двигателя этого класса: тест покрывал ровно те два состояния, которые код и умел различать.
- **Диагностика:** для каждой колонки «всего» выписать её подколонки и проверить, что их условия **разбивают** множество, а не выбирают из него два удобных случая. Быстрая проба на данных: `count(*) FILTER (WHERE признак) - сумма count(*) FILTER (WHERE подколонка)` — ненулевая разница и есть класс строк, которого нет в бумаге.
- **Лечение:** состояния строить взаимоисключающими от одного признака (`leftFactory` → `scrapSent = утиль && ушёл`, `shipped = не утиль && ушёл`, `atFactory = остался`), а сумму частей печатать в пояснении рядом с «всего» (`Утиль всего = утиль на заводе + утиль отправлен (5 = 3 + 2)`) — тогда следующая дыра видна на бумаге сразу, без вопроса владельца. Инвариант — в тест, на каждую строку отчёта.
- **Поймано:** 2026-09-07 по вопросу владельца «а куда делись два утильных двигателя?». Родня: M111 и M112 (та же семья «отчёт уверенно печатает неполную правду»), M103 (вывод из отсутствия улик).
