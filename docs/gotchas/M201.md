# M201 — CDP-смоук: окно или оверлей от прошлого прогона перехватывает клики — «кнопка не найдена» в зависимости от порядка прогонов

**Область:** CDP-смоуки `.claude/skills/verifier-electron/scripts/cdp-*.mjs`, живой стенд Electron

- **Симптом:** тот же смоук на том же стенде то проходит, то падает на самом первом шаге:
  «окно „Скрипты обслуживания“ открыто — кнопка МЕНЮ не найдена», хотя кнопка **есть на экране**
  (видно на скриншоте прогона). Повторный запуск сразу после — зелёный. Поймано 12.11.2026 на
  `cdp-kaspersky-setup.mjs`.

- **Корень:** **смоук не убирает состояние, оставленное предыдущим прогоном.** Окно инструкции
  или окно обслуживания остаётся открытым и перекрывает кнопку «МЕНЮ»; оверлей меню
  (`.v3-menu-overlay`) остаётся висеть и перехватывает клики. Сценарий ищет кнопку через
  `elementFromPoint` — а под ней оверлей, а не кнопка. Результат зависит от того, чем закончился
  предыдущий прогон, то есть **прогон не воспроизводим**.

- **Диагностика:** снять скриншот **до** первого шага и посмотреть, что на экране:

  ```js
  document.querySelector('[data-kaspersky-setup-dialog]');   // окно инструкции
  document.querySelector('[data-client-ops-dialog]');        // окно обслуживания
  document.querySelector('.v3-menu-overlay');                // оверлей меню
  ```

  Любой не-null означает: остаток от прошлого прогона.

- **Лечение:** **убирать остатки в начале сценария** — до поиска кнопки:

  ```js
  // окно инструкции / окно обслуживания — закрыть кнопкой
  const d = document.querySelector('[data-kaspersky-setup-dialog]');
  if (d) { const b = [...d.querySelectorAll('button')].find((x) => txt(x).includes('Закрыть')); if (b) click(b); }
  // оверлей меню — закрыть Escape
  if (document.querySelector('.v3-menu-overlay')) {
    document.dispatchEvent(new KeyboardEvent('keydown', { key: 'Escape', bubbles: true }));
  }
  ```

  Так сделано в `cdp-kaspersky-setup.mjs` (шаг `closeLeftovers`) — в остальных CDP-смоуках
  стенда правило то же: **сценарий начинает с чистого экрана**.

- **Чего НЕ делать:** не «подгонять» смоук под текущее состояние экрана (например, не искать
  кнопку обходным маршрутом, раз окно перекрывает её) — это маскирует остатки и оставляет смоук
  зависимым от порядка прогонов. Сценарий обязан **начинать с чистого экрана**.
