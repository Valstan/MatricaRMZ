# Матрица РМЗ — кадры для портфолио

Скриншоты сняты на **демо-стенде**: отдельная база `matricarmz_demo`, засеянная с нуля
скриптом [`seedPortfolioDemo.ts`](../../../backend-api/src/scripts/seedPortfolioDemo.ts)
(команда `pnpm -F @matricarmz/backend-api demo:seed`).

**Все данные на кадрах выдуманы.** ФИО сотрудников и названия контрагентов не существуют;
номера двигателей, суммы, даты и платежи порождены сидом. Настоящие только доменные
термины — марки двигателей (ЯМЗ, КАМАЗ, Д-245) и названия узлов и деталей: это словарь
отрасли, а не персональные данные. Рабочая база завода для съёмки не использовалась
и производных от неё кадров здесь нет.

Пересъёмка после редизайна — пересев стенда тем же сидом (порядок — в
[плане демо-стенда](../../plans/portfolio-demo-stand-2026-08.md)).
