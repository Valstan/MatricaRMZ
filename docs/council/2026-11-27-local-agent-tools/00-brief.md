# Бриф совета — клиентские инструменты нейросети: чтение данных и действия приложения

**Дата:** 2026-11-27 · **Промт КАРМАНА:** #176, разрез 2 (шаг 4 плана промта + пункты 8–11 промта)
**Режим:** тройка (зоны: права · производство · клиент) — в нитке вводится **новая граница**:
действие по команде агента.

## Первая линза (глобальные обработчики) — результат

> Глобальная линза: **кандидат — образец есть, но он СЕРВЕРНЫЙ**:
> `backend-api/src/services/ai/llmTools.ts` (реестр инструментов ИИваныча: чтение + проверка прав +
> свой текст отказа + предел выборки строк) · **дубль: нет** — клиентского реестра, который может
> звать агент, в программе не существует; читать данные агент умеет через
> `electron-app/src/main/services/localMiniMax/dbBridge.ts` (read-only мост к реплике) ·
> **действие: нужен НОВЫЙ клиентский модуль реестра — но он обязан ВЫЗЫВАТЬ существующие двери
> программы, а не переписывать их**: «Добавить списком» в производственной программе — локальная
> модалка страницы (`ProductionProgramAddEnginesByNumbersDialog.tsx`), публичного IPC нет, поэтому
> действие должно стать записью в реестре действий приложения, а его логика проверки дублей —
> остаться в домене (`shared/src/domain/productionProgram.ts`, `engineBulkIntake.ts`).

Подробно — [`05-global-lens.md`](05-global-lens.md).

## Что решаем

1. **Общий реестр клиентских инструментов — один на программу** (п. 11 промта): набор инструментов
   не должен дублироваться по разделам; новый инструмент подключается к общему реестру.
2. **Действие = команда приложения, а не запись агента в базу** (пп. 9–10 промта): мост «реплика →
   агент» read-only намеренно (база завода под защитой), поэтому действие выполняет приложение —
   с правами оператора и в его аудите. Неразрешённое действие — отказ с понятной причиной.
3. **Права оператора соблюдаются**: агент без права на раздел — отказ; проверка «есть ли уже такой
   двигатель» выполняется ДО добавления, в том числе при полном совпадении данных.
4. **Первый раздел — производственная программа** (пп. 8, 12 промта): кнопка нейросети рядом с
   «Добавить списком»; данные принимаются в любом виде (список, Excel, Word); нейросеть сама
   проверяет, что уже есть, и вызывает существующее «Добавить списком» — дубли не создаются.

  диалог `ProductionProgramAddEnginesByNumbersDialog.tsx:84`, запись через `applyRows` →

  (`AiAgentChat.tsx:116`) в запрос не идёт.

## Ограничения

- Мост к реплике **не расширяем** (решение владельца, закрыто по умолчанию — PENDING §2).
- Действия агента идут через существующие двери программы с проверкой прав; новая таблица в схеме
  реплики — не входит.
- Прод не трогаем; серверные инструменты (`llmTools.ts`) — чужая зона, только образец.
- Правки пишем в отдельной ветке; чужие worktree не трогаем.
