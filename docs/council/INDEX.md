# Советы Матрицы РМЗ — индекс

Проведённые советы: дата, тема, режим, состав, вердикт одной строкой. Протокол — [`PROTOCOL.md`](PROTOCOL.md). Реестр советников — [`../advisors/ROSTER.md`](../advisors/ROSTER.md).

Полные ответы советников живут **90 дней** с даты совета; потом остаются `00-brief.md` и `99-verdict.md` (вместе с блоком «кто против» и покрытием). История — в git: удаляем рабочую копию, а не память.

## Как открыть новый совет

Каталог: `docs/council/<YYYY-MM-DD>-<тема-слитно-через-дефис>/` · шаблоны — [`_template/`](_template/). В реестр советников добавляется строка.
