## Что вышло

- **Маршрут:** полный совет → вердикт → **развилка владельцу** (решение по объединению — за ним).
- **Совет:** вердикт — **доработать существующее** (пороги + контракт лестниц) · **завести новый**
  (`escapeHtml` в `shared/src/`) · **не делать** («копии в main», печать картинок). Шут: 2 идеи из 3
  переведены в применимые (вопрос владельцу в его терминах; «точка входа» — в бэклог).
- **Программист:** кода в этой нитке нет — **совет дал решение, а не патч**. Следующий шаг — нитка на
  пороги и контракт (отдельный PR).
- **Критик:** не звался — кода нет.
- **Стенд:** стенд `main` поднят (backend 3001, `/health` 200, v3.149.0); живые доменные функции
  прогнаны на **живых** строках этапов: расхождение «место по времени» ↔ «подпись состояния»
  **воспроизведено на 20 из 59 движков** стенда → **уходит в тупик**. UI (CDP) не гнался: ABI-свап
  `better-sqlite3` уронил бы тесты параллельных линий (M209).
- **Открыто:** за владельцем — три вопроса из вердикта; пункт PENDING переписан.
