## Что вышло

- **Маршрут:** совет из трёх ролей → **вердикт с вариантами** → **развилка владельцу** (решение —
  за человеком; совет не решает).
- **Совет:** не созывался полным составом — вместо него **разбор спорного**: варианты по каждой из
  шести развилок с ценой; часть развилок закрывается **фактом** (см. ниже), по трём — нужен выбор
  владельца.
- **Что закрывается без выбора владельца:**
  - **развилка 6 (потолки обхода)** — переигрывать нечего: владелец уже подтвердил потолок 30 с на
    операцию в другом месте нитки, и он не противоречит текущим значениям;
  - **развилка 2 (устаревание карты)** — «карта протухает, если папка менялась позже индекса» —
    технически необходимое правило, а не вкусовое: иначе поиск отдаёт несуществующие файлы.
- **Что остаётся за владельцем (3 развилки, у каждой — варианты и цена):**
  1. **где живёт карта** (машинно-локально — по умолчанию; рядом с папкой — переживает переустановку,
     но нужны права на запись в сетевую папку);
  2. **строить ли карту автоматически** (по умолчанию да + кнопка; вручную — дешевле для сети, но
     оператору придётся думать);
  3. **куда сообщать «индексация не завершилась»** (журнал + предупреждение на экране — по
     умолчанию; файл для отправки или другое место — по выбору).
- **Программист / Критик / Тестер:** не звались — **кода нет**; появятся после решения владельца.
- **Стенд:** не требовался на этом шаге — предмет решения, а не поведения; **полевая приёмка** уже
  описана в пункте (замер на боевой сетевой папке).
- **Открыто:** развилки — владельцу; правки в коде — после ответа.
