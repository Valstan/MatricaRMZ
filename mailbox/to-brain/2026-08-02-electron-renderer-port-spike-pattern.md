# Спайк-паттерн: доказать переносимость Electron-renderer за вечер

## TL;DR

Июльский (адверсариально верифицированный!) вердикт «Android-порт = месяцы, переписать всё» был опровергнут за один вечер: 14 read-only агентов разведки + спайк из 5 файлов показали, что renderer собирается plain-Vite и живёт без Electron — логин-экран отрисовался в браузере. Урок двоякий: (а) есть дешёвый спайк-паттерн для любого Electron-проекта, которому понадобился мобильный/веб-клиент; (б) даже верифицированная оценка «месяцы» может мерить не ту работу — она мерила «переписать офлайн-движок с нуля», а не «перенести хостинг сервисного слоя».

## Как устроено у нас

1. **Инвентаризация связности до кода:** grep-факты «renderer не импортирует electron/node вообще, весь мир — через один инжектированный мост `window.matrica`» + «374 IPC-метода, но import-closure целевых экранов использует ~174, а MVP-рамка владельца — ~100». Оценка сжалась на порядок ещё до первой строчки кода.
2. **Спайк (5 файлов, новый workspace-пакет):** `vite.config.ts` с `root` → `electron-app/src/renderer` (renderer НЕ выносится), свой `index.html`, entry `import './bridge/shim'; import '<renderer>/main.tsx'` (порядок ES-импортов гарантирует мост до гейта), стаб-мост ~15 методов boot-контракта.
3. **Детали стаба, которые сэкономили отладку:** неизвестные МЕТОДЫ известных групп — Proxy «fail soft and loud» (`console.warn` + `{ok:false}`), но пропсы `on*` возвращают `undefined` — иначе existence-guarded подписки (`if (!api.sync.onProgress) return`) получат не-функцию и уронят cleanup. `then` тоже `undefined` (Proxy иначе thenable).
4. **Грабля:** `resolve.dedupe: ['react']` резолвит из root конфига — при root в чужом пакете react надо объявить зависимостью пакета-обёртки, иначе Rollup падает на `react/jsx-runtime`.
5. Верификация — headless-Chrome-скриншот (без Electron, без CDP).

## Почему переносимо

Любой Electron-проект экосистемы (и вообще любой «UI + preload-мост») однажды упирается в «а можно это на планшет/в браузер?». Паттерн отвечает за вечер и десяток агент-часов разведки вместо недель веры в старую оценку. Обратный урок для оценок: «месяцы» часто мерят worst-case архитектуру, а не минимальный жизнеспособный порт — перед большими «нет» стоит гонять дешёвый спайк.
