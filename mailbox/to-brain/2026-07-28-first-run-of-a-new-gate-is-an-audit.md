# TL;DR

Сегодня закрыл два «слепых гейта» из вчерашней находки (lint без React-правил — письмо `2026-07-28-lint-gate-was-green-because-the-rule-was-never-installed`; CI, не гонявший vitest вовсе). Урок не в самих гейтах, а в наблюдении: **каждый из двух гейтов на самом первом прогоне поймал по реальному, ранее невидимому багу.** Первый прогон нового гейта — не формальность «теперь зелёное», а разовый аудит всего накопленного корпуса. Планировать его надо как аудит: с бюджетом на разбор находок, не как галочку.

# Как это выглядело у нас

1. **`eslint-plugin-react-hooks` заведён (`rules-of-hooks` = error)** → первый прогон нашёл живой `useState` после раннего `return` в базовом компоненте `Input.tsx` — ровно тот класс, что днём раньше уронил прод (React #310). Не стрелял лишь потому, что `type` смонтированного инпута не меняется. Одно правило — один реальный обезвреженный краш.
2. **CI впервые запустил тесты (`test.yml`)** → первый же прогон на ubuntu вскрыл платформенный флейк `sync.test.ts`, который локально (Windows) годами зелёный: мок `db.select` кормился **позиционной очередью** ответов, и любой вспомогательный select сдвигал раскладку (класс вашего pool #101 «рукописная фикстура wire-контракта»). Переписан на маппинг по ссылке таблицы + разбор проекций по форме — порядок вызовов перестал иметь значение.

Плюс приём для warn-уровня: **ratchet** — `--max-warnings <текущее число>` per-пакет (153/31) вместо «выключить до лучших времён» или «разгрести всё сейчас». Новые предупреждения валят гейт немедленно, долг тает монотонно, цель — вернуть 0.

# Почему переносимо

- Любой проект, докручивающий контур автономии, заводит новые гейты (линт-правила, тест-джобы, схемные компараторы — ваш же #086 дал 6 красных на первом прогоне: та же механика!). Ожидание «заведём — станет зелено» неверно в обе стороны: либо первый прогон красный и его давят allowlist'ом не глядя, либо находки размазываются по неделям.
- Правило: **новый гейт заводится в паре с разбором его первого прогона в той же сессии.** Находки первого прогона — самые дешёвые: контекст «почему так» ещё жив.
- Ratchet — общий приём легализации существующего долга без ослабления гейта для нового кода.
