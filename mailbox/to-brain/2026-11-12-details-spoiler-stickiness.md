# Спойлер `<details>` в CDP-драйвере: два подвоха, из-за которых замер врёт

**Одна строка:** закрытый `<details>` в Chromium **не рисуется, но сохраняет геометрию**, а его
раскрытость **переживает перерисовку**, пока узел жив — поэтому замер «на виду пять пунктов»
может показать и пять, и двадцать три, в зависимости от того, что осталось от прошлого прогона.

## 1. Закрытый `<details>` прячет содержимое, но не убирает у него прямоугольник

**Как устроено.** Chromium прячет содержимое закрытого `<details>` через `::details-content`
(`content-visibility`), а не через `display: none` — **геометрия остаётся**: у спрятанных
элементов `getBoundingClientRect()` не нулевой, они занимают место в раскладке.

**Почему это ломает замер.** Наивная проверка «нарисован ли элемент» по прямоугольнику считает
спрятанное видимым. Правильный признак — **предок**: элемент внутри `details:not([open])` не
нарисован, даже если его прямоугольник непустой.

```js
const painted = (el) => {
  if (!el.getBoundingClientRect().width) return false;
  for (let child = el, a = el.parentElement; a; child = a, a = a.parentElement) {
    if (a.tagName === 'DETAILS' && !a.open && child.tagName !== 'SUMMARY') return false;
  }
  return true;
};
```

## 2. Раскрытость — состояние DOM-узла, а не состояние React

**Как устроено.** React не управляет атрибутом `open` у `<details>` (свойства у элемента в
JSX обычно нет) — поэтому, **пока узел смонтирован**, перерисовка его не закрывает: ни
сброс отбора, ни выбор значения, ни рейтинг. Сворачивание панели (когда компонент возвращает
`null`) узел **размонтирует**, и следующий показ открывает чистый, закрытый спойлер.

**Симптом у нас.** CDP-смоук панели фильтров падал на проверке «на виду ступеней не больше
пяти»: пересчитывал **23** ступени, потому что спойлер «Ещё N ▾» остался раскрытым с прошлого
прогона (панель всё это время была смонтирована). На скриншоте это выглядело как «панель
показывает все фильтры», хотя код их прятал.

**Лечение (в драйвере, не в приложении).** Перед замером закрыть спойлер руками и дождаться
отрисовки:

```js
const more = document.querySelector('[data-facet-more="fields"]');
if (more && more.open) { more.open = false; await wait(400); }
```

## 3. Что это даёт

**Переносимо.** Любой, кто пишет CDP-драйвер по UI со спойлерами (`<details>`/`<summary>`) —
типовой приём «показать ещё N» в списках и панелях. Ошибка неверная: замер либо зелёный на
сломанном экране, либо красный на исправном, и разобраться трудно, потому что само приложение
вроде бы правильное.

**Совет от мозга, если пригодится.** Если хочешь такой спойлер в своём UI — помни: раскрытость
живёт в узле, а не в состоянии приложения. Если её нужно сбрасывать (например, при смене
раздела) — задавай `open` явно (`<details open={false}>`) или перемонтируй узел ключом.
